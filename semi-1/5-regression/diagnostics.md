# 回帰診断

回帰モデルの妥当性を評価し、問題点を発見するための手法です。

---

## 回帰診断の考え方

回帰診断は「モデルの仮定が成り立っているか」「異常なデータ点がないか」をチェックします。

```
回帰診断で確認すべき4つのポイント

1. 残差の確認
   ┌─────────────────────────────┐
   │ ・ ・   ・    ・ ・         │ ← 良い（ランダム）
   │    ・  ・  ・    ・  ・     │
   │ ・    ・     ・    ・       │
   └─────────────────────────────┘
        予測値 →

2. 外れ値の検出
   ┌─────────────────────────────┐
   │                    ★       │ ← 残差が大きい
   │ ・ ・ ・ ・ ・ ・ ・ ・     │    （外れ値候補）
   └─────────────────────────────┘

3. 高てこ比点（説明変数空間での外れ値）

   x₂ │        ★ ← 高てこ比点
      │           （他の点から離れている）
      │  ・・・・
      │  ・・・・
      └──────────── x₁

4. 影響点（Cook's距離）
   = 残差が大きい + てこ比が高い → 結果に大きな影響

DW = Durbin-Watson（ダービン・ワトソン）検定
VIF = Variance Inflation Factor（分散拡大要因）
```

---

## 1. 残差の種類

### 1.1 通常残差（Raw Residuals）

$$e_i = y_i - \hat{y}_i$$

### 1.2 標準化残差（Standardized Residuals）

$$r_i = \frac{e_i}{\hat{\sigma}\sqrt{1-h_{ii}}}$$

- $\hat{\sigma}$：残差の標準偏差の推定値
- $h_{ii}$：てこ比

### 1.3 スチューデント化残差（Studentized Residuals）

$$t_i = \frac{e_i}{\hat{\sigma}_{(i)}\sqrt{1-h_{ii}}}$$

$\hat{\sigma}_{(i)}$：$i$ 番目の観測を除いて計算した標準偏差

---

## 2. てこ比（Leverage）

### 2.1 定義

ハット行列 $\mathbf{H} = \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top$ の対角成分：

$$h_{ii} = \mathbf{x}_i^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{x}_i$$

### 2.2 性質

- $0 \leq h_{ii} \leq 1$
- $\sum_{i=1}^{n} h_{ii} = p$（パラメータ数）
- 平均：$\bar{h} = p/n$

### 2.3 解釈

- **高いてこ比**：説明変数空間で外れた位置にある
- 目安：$h_{ii} > 2p/n$ で注意

---

## 3. Cook's距離

### 3.1 定義

観測 $i$ を除いたときの予測値の変化：

$$D_i = \frac{(\hat{\mathbf{y}} - \hat{\mathbf{y}}_{(i)})^\top(\hat{\mathbf{y}} - \hat{\mathbf{y}}_{(i)})}{p\hat{\sigma}^2}$$

簡便な計算式：

$$D_i = \frac{r_i^2}{p} \cdot \frac{h_{ii}}{1-h_{ii}}$$

### 3.2 解釈

- 残差（$r_i^2$）とてこ比（$h_{ii}$）の両方を考慮
- 目安：$D_i > 0.5$ で注意、$D_i > 1$ で要検討

---

## 4. 残差プロット

### 4.1 残差 vs 予測値

- **確認すること**：
  - 均一分散性（パターンがない）
  - 非線形性（曲線的パターン）
  - 外れ値

### 4.2 正規Q-Qプロット

- 残差の正規性を確認
- 直線に乗れば正規分布
- 端での逸脱は裾の重さを示す

### 4.3 Scale-Location プロット

- $\sqrt{|r_i|}$ vs $\hat{y}_i$
- 均一分散なら水平な傾向
- 傾きがあれば分散不均一

---

## 5. 自己相関の検定

### 5.1 ダービン・ワトソン比（DW）

$$DW = \frac{\sum_{i=2}^{n}(e_i - e_{i-1})^2}{\sum_{i=1}^{n}e_i^2}$$

### 5.2 近似関係

$$DW \approx 2(1 - \hat{\rho})$$

$\hat{\rho}$：残差の1次自己相関係数

### 5.3 判定

| DW値 | 解釈 |
|-----|------|
| DW ≈ 2 | 自己相関なし |
| DW < 2 | 正の自己相関 |
| DW > 2 | 負の自己相関 |
| 0 < DW < $d_L$ | 正の自己相関あり |
| $d_L$ < DW < $d_U$ | 判定不能 |
| $d_U$ < DW < $4-d_U$ | 自己相関なし |

---

## 6. 多重共線性の診断

### 6.1 VIF（分散拡大要因）

$$\text{VIF}_j = \frac{1}{1-R_j^2}$$

$R_j^2$：$x_j$ を他の説明変数で回帰したときの決定係数

### 6.2 判定基準

| VIF | 解釈 |
|-----|------|
| VIF < 5 | 問題なし |
| 5 ≤ VIF < 10 | 注意 |
| VIF ≥ 10 | 多重共線性あり |

## 7. 例題

### 例題1：てこ比の計算

5つの観測のハット行列対角成分が $h_{11}=0.15$, $h_{22}=0.20$, $h_{33}=0.25$, $h_{44}=0.20$, $h_{55}=0.60$ のとき、パラメータ数と外れ値候補を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

パラメータ数：

$$p = \sum h_{ii} = 0.15 + 0.20 + 0.25 + 0.20 + 0.60 = 1.40$$

実際は $p$ は整数なので、これは近似値。おそらく $p = 1$（切片のみ）か計算誤差。

平均てこ比：$\bar{h} = p/n = 1.4/5 = 0.28$

判定基準：$2p/n = 2 \times 1.4/5 = 0.56$

$h_{55} = 0.60 > 0.56$ → **観測5は高てこ比点**

**答え：** 観測5がてこ比の観点から外れ値候補

</details>

---

### 例題2：Cook's距離

標準化残差 $r_i = 2.5$、てこ比 $h_{ii} = 0.4$、パラメータ数 $p = 3$ のとき、Cook's距離を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$D_i = \frac{r_i^2}{p} \cdot \frac{h_{ii}}{1-h_{ii}}$$

$$= \frac{2.5^2}{3} \cdot \frac{0.4}{1-0.4} = \frac{6.25}{3} \cdot \frac{0.4}{0.6}$$

$$= 2.083 \times 0.667 \approx 1.39$$

**答え：約1.39**

$D > 1$ なので、この観測は回帰結果に大きな影響を与えている。検討が必要。

</details>

---

### 例題3：ダービン・ワトソン比

残差の1次自己相関係数が $\hat{\rho} = 0.3$ のとき、DW比の近似値を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$DW \approx 2(1 - \hat{\rho}) = 2(1 - 0.3) = 2 \times 0.7 = 1.4$$

**答え：約1.4**

DW < 2 なので正の自己相関が疑われる。

</details>

## 8. 重要公式まとめ

| 項目 | 公式 |
|-----|------|
| てこ比 | $h_{ii} = \mathbf{x}_i^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{x}_i$ |
| てこ比の和 | $\sum h_{ii} = p$ |
| Cook's距離 | $D_i = \frac{r_i^2}{p} \cdot \frac{h_{ii}}{1-h_{ii}}$ |
| DW比 | $\frac{\sum(e_i-e_{i-1})^2}{\sum e_i^2} \approx 2(1-\hat{\rho})$ |
| VIF | $1/(1-R_j^2)$ |
