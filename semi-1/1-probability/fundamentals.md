# 確率の基礎

確率論は統計学の土台です。このページでは、条件付き確率からベイズの定理まで、**なぜそう考えるのか**を重視して解説します。

---

## 1. 確率の公理

### なぜ公理が必要？

「確率」を数学的に扱うには、曖昧さのない定義が必要です。コルモゴロフは1933年に、たった3つの公理で確率を定義しました。

### 1.1 コルモゴロフの公理

標本空間 $\Omega$（起こりうる結果の全体）上の確率測度 $P$ は以下を満たす：

| 公理 | 意味 | 直感 |
|-----|------|------|
| **非負性** | $P(A) \geq 0$ | 確率は負にならない |
| **正規性** | $P(\Omega) = 1$ | 何かは必ず起こる |
| **可算加法性** | 排反な事象の和の確率 = 確率の和 | 重複がなければ足せる |

可算加法性を式で書くと：

$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i) \quad \text{（$A_i$ が互いに排反のとき）}$$

### 1.2 公理から導かれる性質

公理からすべての確率の性質が導けます：

| 性質 | 式 | 導出のアイデア |
|-----|-----|--------------|
| 補集合 | $P(A^c) = 1 - P(A)$ | $A$ と $A^c$ は排反で和が $\Omega$ |
| 単調性 | $A \subseteq B \Rightarrow P(A) \leq P(B)$ | $B = A \cup (B \setminus A)$ |
| 加法定理 | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ | 重複を引く |

### 1.3 包除原理

3つ以上の事象の和の確率を求める一般公式：

$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i} P(A_i) - \sum_{i<j} P(A_i \cap A_j) + \sum_{i<j<k} P(A_i \cap A_j \cap A_k) - \cdots$$

**覚え方**：1つずつ足す → 2つの重複を引く → 3つの重複を足す → ...（符号が交互）

## 2. 条件付き確率

### なぜ重要？

現実では「ある情報を知った上で」確率を考えることが多いです：
- 検査が陽性だった。本当に病気の確率は？
- 今日は曇り。雨が降る確率は？
- カードを1枚引いた。次に引くカードの確率は？

**条件付き確率は、情報によって確率が更新される仕組み**を表します。

### 2.1 定義と直感

```
┌─────────────────────────────┐
│           Ω                 │
│    ┌──────────────┐         │
│    │      B       │         │
│    │   ┌─────┐    │         │
│    │   │ A∩B │    │         │
│    │   └─────┘    │         │
│    └──────────────┘         │
└─────────────────────────────┘

P(A|B) = P(A∩B) / P(B)

「Bが起こった」と分かったら、Bの中だけが新しい世界。
その中でAが占める割合が P(A|B)。
```

**定義**：$P(B) > 0$ のとき

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

### 2.2 乗法定理

定義を変形すると：

$$P(A \cap B) = P(A \mid B) \cdot P(B) = P(B \mid A) \cdot P(A)$$

**連鎖律**（3つ以上の事象）：

$$P(A \cap B \cap C) = P(A) \cdot P(B \mid A) \cdot P(C \mid A \cap B)$$

順番に「前の情報を条件にして」掛けていく。

### 2.3 よくある誤解

| 誤解 | 正しい理解 |
|-----|----------|
| $P(A \mid B) = P(B \mid A)$ | 一般に等しくない！（検査の例を参照） |
| 条件付けると確率は下がる | 上がることも下がることもある |
| $P(A \mid B) = P(A \cap B)$ | 分母の $P(B)$ で割ることを忘れずに |

## 3. 独立性

### なぜ重要？

独立性は「一方の情報が他方に影響しない」ことを意味します。
- コインの1回目と2回目は独立
- 同じ人の身長と体重は独立でない

**独立なら計算が簡単になる**（同時確率 = 周辺確率の積）ため、多くの統計モデルで独立性を仮定します。

### 3.1 定義

$A$ と $B$ が**独立** $\Leftrightarrow$

$$P(A \cap B) = P(A) \cdot P(B)$$

**同値な条件**（どれか1つが成り立てば独立）：
- $P(A \mid B) = P(A)$（$B$を知っても$A$の確率は変わらない）
- $P(B \mid A) = P(B)$（$A$を知っても$B$の確率は変わらない）

### 3.2 対独立 vs 相互独立

3つ以上の事象では、2種類の独立性を区別する必要があります：

```
事象 A, B, C について：

【対独立】           【相互独立】
A⊥B, B⊥C, A⊥C       A⊥B, B⊥C, A⊥C に加えて
（2つずつ独立）       A⊥B⊥C（3つ同時も独立）

P(A∩B)=P(A)P(B)     P(A∩B∩C)=P(A)P(B)P(C)
P(B∩C)=P(B)P(C)     も成り立つ
P(A∩C)=P(A)P(C)
```

**重要**：対独立だからといって相互独立とは限らない！

### 3.3 確率変数の独立

確率変数 $X, Y$ が独立 $\Leftrightarrow$ 同時分布が周辺分布の積：

$$f_{X,Y}(x, y) = f_X(x) \cdot f_Y(y) \quad \text{（すべての } x, y \text{ で）}$$

**独立のとき成り立つ便利な性質**：
- $E[XY] = E[X] \cdot E[Y]$
- $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$
- $M_{X+Y}(t) = M_X(t) \cdot M_Y(t)$（積率母関数）

## 4. 全確率の公式

### なぜ重要？

直接 $P(A)$ を求めにくいとき、**場合分け**して考えると楽になることがあります。

### 4.1 分割の概念

```
┌─────────────────────────────────┐
│              Ω                  │
│  ┌─────┬─────┬─────┬─────┐      │
│  │ B₁  │ B₂  │ B₃  │ B₄  │      │
│  └─────┴─────┴─────┴─────┘      │
└─────────────────────────────────┘

B₁, B₂, ... が Ω の「分割」とは：
• 互いに重ならない（排反）
• 全部合わせると Ω になる（網羅的）
```

### 4.2 全確率の公式

$B_1, \ldots, B_n$ が $\Omega$ の分割のとき：

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i) \cdot P(B_i)$$

**考え方**：「$A$が起こる」= 「$B_1$の下で$A$が起こる」or「$B_2$の下で$A$が起こる」or ...

```
                    P(A)
                     │
        ┌────────────┼────────────┐
        ▼            ▼            ▼
    P(A|B₁)·P(B₁) + P(A|B₂)·P(B₂) + P(A|B₃)·P(B₃)
```

## 5. ベイズの定理

### なぜ重要？

ベイズの定理は**「原因」と「結果」の確率を入れ替える**公式です。

- 検査陽性（結果）→ 病気（原因）の確率は？
- メールにNGワード（結果）→ 迷惑メール（原因）の確率は？

**結果から原因を推定する**のがベイズの定理の本質です。

### 5.1 公式の導出

乗法定理から自然に導けます：

$$P(A \cap B) = P(B \mid A) \cdot P(A) = P(A \mid B) \cdot P(B)$$

よって：

$$P(B \mid A) = \frac{P(A \mid B) \cdot P(B)}{P(A)}$$

分母を全確率の公式で展開すると一般形に：

$$P(B_j \mid A) = \frac{P(A \mid B_j) \cdot P(B_j)}{\sum_{i=1}^{n} P(A \mid B_i) \cdot P(B_i)}$$

### 5.2 ベイズの定理の構造

```
              P(A|Bⱼ) · P(Bⱼ)
P(Bⱼ|A) = ─────────────────────
                 P(A)

  事後確率   =   尤度  ×  事前確率
              ─────────────────
                 正規化定数
```

| 用語 | 記号 | 意味 |
|-----|------|------|
| **事前確率** | $P(B_j)$ | データを見る前の信念 |
| **尤度** | $P(A \mid B_j)$ | 「$B_j$が真なら$A$が観測される確率」 |
| **事後確率** | $P(B_j \mid A)$ | データを見た後の信念 |
| **周辺尤度** | $P(A)$ | 正規化のための定数 |

### 5.3 オッズ形式

2つの仮説を比較するとき便利：

$$\frac{P(B_1 \mid A)}{P(B_2 \mid A)} = \frac{P(A \mid B_1)}{P(A \mid B_2)} \cdot \frac{P(B_1)}{P(B_2)}$$

$$\text{事後オッズ} = \text{尤度比} \times \text{事前オッズ}$$

### 5.4 よくある誤解：検査のパラドックス

「感度95%の検査で陽性」→「95%の確率で病気」は**間違い**！

有病率が低いと、陽性でも病気でない可能性が高くなります（例題1参照）。

## 6. 条件付き期待値

### なぜ重要？

条件付き期待値は「情報を得たときの予測値」です。
- 身長を知ったときの体重の予測
- 今日の気温を知ったときの明日の気温の予測

機械学習の回帰問題の理論的基盤になっています。

### 6.1 定義

$$E[X \mid Y=y] = \sum_x x \cdot P(X=x \mid Y=y) \quad \text{（離散）}$$

$$E[X \mid Y=y] = \int x \cdot f_{X \mid Y}(x \mid y) \, dx \quad \text{（連続）}$$

$E[X \mid Y]$ は $Y$ の関数（$Y$ の値によって変わる）。

### 6.2 全期待値の公式（繰り返し期待値の法則）

$$E[X] = E[E[X \mid Y]]$$

**直感**：「$Y$で場合分けした平均」の「全体平均」= 「$X$の平均」

### 6.3 全分散の公式

$$\text{Var}(X) = E[\text{Var}(X \mid Y)] + \text{Var}(E[X \mid Y])$$

```
全体の分散 = グループ内分散の平均 + グループ間の分散
```

**例**：クラス全体のテストの分散 = 各クラス内の分散の平均 + クラス平均点の分散

## 7. 概念のつながり

```
条件付き確率 P(A|B)
      │
      ├──→ 乗法定理 P(A∩B) = P(A|B)P(B)
      │         │
      │         ▼
      │    全確率の公式 P(A) = Σ P(A|Bᵢ)P(Bᵢ)
      │              │
      │              ▼
      └─────→ ベイズの定理（条件付き確率の反転）
                    │
                    ▼
              事後分布の計算（統計的推測）

独立性 ──→ 計算の簡略化、統計モデルの仮定

条件付き期待値 ──→ 回帰分析の理論的基盤
```

## 8. 例題

### 例題1：ベイズの定理（検査のパラドックス）

ある病気の有病率は1%。検査の感度（病気のとき陽性）は95%、特異度（健康のとき陰性）は90%。検査が陽性のとき、実際に病気である確率を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**記号の設定**
- $D$：病気、$D^c$：健康
- $+$：陽性

**与えられた情報**
- $P(D) = 0.01$（有病率）
- $P(+ \mid D) = 0.95$（感度）
- $P(- \mid D^c) = 0.90$（特異度）→ $P(+ \mid D^c) = 0.10$（偽陽性率）

**ベイズの定理を適用**

$$P(D \mid +) = \frac{P(+ \mid D) \cdot P(D)}{P(+ \mid D) \cdot P(D) + P(+ \mid D^c) \cdot P(D^c)}$$

$$= \frac{0.95 \times 0.01}{0.95 \times 0.01 + 0.10 \times 0.99}$$

$$= \frac{0.0095}{0.0095 + 0.099} = \frac{0.0095}{0.1085} \approx 0.0875$$

**答え：約8.75%**

**解釈**：感度95%の検査で陽性でも、病気である確率は約9%しかない。これは有病率が低い（1%）ため、偽陽性の数が真陽性を大きく上回るから。

</details>

### 例題2：全確率の公式

箱Aには赤玉3個、白玉2個。箱Bには赤玉1個、白玉4個。サイコロを振り、1, 2が出たら箱A、それ以外なら箱Bから玉を1個取り出す。赤玉が出る確率を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**分割の設定**
- $P(\text{箱A}) = 2/6 = 1/3$
- $P(\text{箱B}) = 4/6 = 2/3$

**条件付き確率**
- $P(\text{赤} \mid \text{箱A}) = 3/5$
- $P(\text{赤} \mid \text{箱B}) = 1/5$

**全確率の公式**

$$P(\text{赤}) = P(\text{赤} \mid A) \cdot P(A) + P(\text{赤} \mid B) \cdot P(B)$$

$$= \frac{3}{5} \times \frac{1}{3} + \frac{1}{5} \times \frac{2}{3} = \frac{3}{15} + \frac{2}{15} = \frac{5}{15} = \frac{1}{3}$$

**答え：1/3**

</details>

### 例題3：条件付き期待値

$(X, Y)$ の同時分布が $P(X=i, Y=j) = c(i+j)$（$i, j \in \{1, 2\}$）のとき、$E[X \mid Y=1]$ を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**Step 1：正規化定数 $c$ を求める**

$$\sum_{i,j} c(i+j) = c[(1+1)+(1+2)+(2+1)+(2+2)] = c \cdot 12 = 1$$

よって $c = 1/12$

**Step 2：同時分布表を作成**

| | $Y=1$ | $Y=2$ | 周辺 |
|---|---|---|---|
| $X=1$ | 2/12 | 3/12 | 5/12 |
| $X=2$ | 3/12 | 4/12 | 7/12 |
| 周辺 | 5/12 | 7/12 | 1 |

**Step 3：条件付き分布を計算**

$$P(X=1 \mid Y=1) = \frac{P(X=1, Y=1)}{P(Y=1)} = \frac{2/12}{5/12} = \frac{2}{5}$$

$$P(X=2 \mid Y=1) = \frac{3/12}{5/12} = \frac{3}{5}$$

**Step 4：条件付き期待値**

$$E[X \mid Y=1] = 1 \times \frac{2}{5} + 2 \times \frac{3}{5} = \frac{2}{5} + \frac{6}{5} = \frac{8}{5}$$

**答え：8/5 = 1.6**

</details>

## 9. 重要公式まとめ

| 項目 | 公式 |
|-----|------|
| 条件付き確率 | $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$ |
| 乗法定理 | $P(A \cap B) = P(A \mid B) \cdot P(B)$ |
| 独立 | $P(A \cap B) = P(A) \cdot P(B)$ |
| 全確率の公式 | $P(A) = \sum_i P(A \mid B_i) \cdot P(B_i)$ |
| ベイズの定理 | $P(B_j \mid A) = \dfrac{P(A \mid B_j) \cdot P(B_j)}{P(A)}$ |
| 全期待値の公式 | $E[X] = E[E[X \mid Y]]$ |
| 全分散の公式 | $\text{Var}(X) = E[\text{Var}(X \mid Y)] + \text{Var}(E[X \mid Y])$ |
