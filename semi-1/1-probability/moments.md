# 積率と分布の特性値

分布の「形」を数値で表す方法と、確率に関する重要な不等式を学びます。

---

## 1. 積率（モーメント）とは

### なぜ重要？

分布を完全に記述するには確率密度関数が必要ですが、実用上は**いくつかの数値で特徴を要約**できると便利です。

```
分布の特徴づけ：

    平均（位置）    → どこにあるか
    分散（散らばり）→ どれだけばらつくか
    歪度（非対称性）→ 左右対称か
    尖度（尖り）    → 裾が重いか
```

これらはすべて「積率」から計算できます。

### 1.1 原点まわりの積率

$$\mu'_n = E[X^n]$$

- $\mu'_1 = E[X]$：平均（1次の積率）
- $\mu'_2 = E[X^2]$：2乗の期待値

### 1.2 平均まわりの積率（中心積率）

$$\mu_n = E[(X - \mu)^n]$$

平均を基準にすると解釈しやすい：

| 次数 | 記号 | 意味 |
|-----|------|------|
| 1次 | $\mu_1$ | 常に 0（定義より） |
| 2次 | $\mu_2 = \sigma^2$ | **分散**（散らばり） |
| 3次 | $\mu_3$ | 非対称性（歪度の分子） |
| 4次 | $\mu_4$ | 尖り具合（尖度の分子） |

### 1.3 原点積率と中心積率の変換

原点積率から中心積率を計算できます（逆も可）：

$$\mu_2 = \mu'_2 - (\mu'_1)^2$$

これが有名な「$\text{Var}(X) = E[X^2] - (E[X])^2$」の正体です。

---

## 2. 歪度（Skewness）

### なぜ重要？

現実のデータは左右対称とは限りません。所得分布、待ち時間、株価変動など、**非対称な分布**は多く存在します。

### 2.1 定義

$$\gamma_1 = \frac{\mu_3}{\sigma^3} = \frac{E[(X-\mu)^3]}{\sigma^3}$$

3乗しているので、平均からの偏差の**符号が保存**されます。

### 2.2 視覚的理解

```
γ₁ < 0（負の歪み）      γ₁ = 0（対称）       γ₁ > 0（正の歪み）
左に裾が長い            左右対称             右に裾が長い

    ▄▄█                   ▄█▄                   █▄▄
   ▄███                  ▄███▄                  ███▄
  ▄█████                ▄█████▄                █████▄
 ▄███████▄             ▄███████▄             ▄███████
━━━━━━━━━━━━━         ━━━━━━━━━━━━━         ━━━━━━━━━━━━━
    平均←最頻値        最頻値=平均           最頻値→平均
```

### 2.3 代表的な分布の歪度

| 分布 | 歪度 | 特徴 |
|-----|------|------|
| 正規分布 | 0 | 対称の代表 |
| 指数分布 | 2 | 常に正の歪み |
| ポアソン $\text{Poi}(\lambda)$ | $1/\sqrt{\lambda}$ | $\lambda$ 大で対称に近づく |
| 一様分布 | 0 | 対称 |

### 2.4 よくある誤解

| 誤解 | 正しい理解 |
|-----|----------|
| 歪度=0 なら正規分布 | 対称なら歪度=0 だが、逆は不成立 |
| 歪度が大きいほど平均と最頻値が離れる | おおむね正しいが、厳密には別の概念 |

## 3. 尖度（Kurtosis）

### なぜ重要？

**裾の重さ**（極端な値の出やすさ）を測ります。リスク管理や外れ値の分析で重要です。

### 3.1 定義

$$\gamma_2 = \frac{\mu_4}{\sigma^4} = \frac{E[(X-\mu)^4]}{\sigma^4}$$

4乗しているので、平均から離れた値の影響が大きくなります。

### 3.2 正規分布を基準に

正規分布の尖度は 3 なので、**超過尖度**（excess kurtosis）で比較することが多い：

$$\text{超過尖度} = \gamma_2 - 3$$

```
超過尖度 < 0（扁峰）    超過尖度 = 0          超過尖度 > 0（尖峰）
裾が軽い、平坦          正規分布              裾が重い、尖っている

     ▄▄▄▄▄▄▄                ▄▄▄                    ▄
    ██████████             ▄███▄                  ▄█▄
   ████████████           ▄█████▄                ▄███▄
  ██████████████         ▄███████▄             ▄▄█████▄▄
━━━━━━━━━━━━━━━━━━     ━━━━━━━━━━━━━━━━      ━━━━━━━━━━━━━━━
  外れ値が出にくい        正規分布            外れ値が出やすい
```

### 3.3 代表的な分布の尖度

| 分布 | 尖度 | 超過尖度 | 裾の重さ |
|-----|-----|---------|---------|
| 一様分布 | 1.8 | -1.2 | 軽い |
| 正規分布 | 3 | 0 | 基準 |
| 指数分布 | 9 | 6 | 重い |
| t分布 ($\nu=5$) | 9 | 6 | 重い |
| コーシー分布 | 未定義 | — | 極めて重い |

### 3.4 注意点

尖度は「尖り具合」と訳されますが、実際には**裾の重さ**を測っています。ピーク部分より裾の形状に敏感です。

## 4. 共分散と相関

### なぜ重要？

2つの変数の**関連の強さと方向**を測ります。回帰分析やポートフォリオ理論の基礎です。

### 4.1 共分散

$$\text{Cov}(X, Y) = E[(X-\mu_X)(Y-\mu_Y)] = E[XY] - E[X]E[Y]$$

```
共分散の符号：

Cov > 0（正の関連）     Cov = 0              Cov < 0（負の関連）
Xが大きい時Yも大きい    線形関係なし          Xが大きい時Yは小さい

    Y                     Y                     Y
    │    ·  ·             │  ·    ·             │·  ·
    │  ·  ·               │ ·  ·  ·             │ ·  ·
    │·  ·                 │·  ·  ·              │  ·  ·
    └────────X            └────────X            └────────X
```

### 4.2 相関係数

共分散をスケール調整：

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

**性質**：
- $-1 \leq \rho \leq 1$（必ずこの範囲）
- $\lvert \rho \rvert = 1$ ⇔ 完全な線形関係
- $\rho = 0$ ⇔ **無相関**（線形関係がない）

### 4.3 重要な関係式

$$\text{Var}(aX + bY) = a^2\text{Var}(X) + b^2\text{Var}(Y) + 2ab\text{Cov}(X, Y)$$

**独立なら** $\text{Cov}(X, Y) = 0$ なので：

$$\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$$

### 4.4 よくある誤解

| 誤解 | 正しい理解 |
|-----|----------|
| 無相関 = 独立 | 無相関でも独立とは限らない！ |
| 相関が高い = 因果関係 | 相関は因果を意味しない |
| 相関係数は万能 | 非線形な関係は検出できない |

## 5. 確率不等式の全体像

### なぜ重要？

分布の形が分からなくても、平均や分散から**確率の上界・下界**を求められます。

```
不等式の関係：

マルコフの不等式 ──┐
（最も基本的）    │
                  ├──→ チェビシェフの不等式
                  │    （分散を使う）
                  │
イェンセンの不等式（凸関数の性質）

ヘルダーの不等式 ──→ コーシー・シュワルツの不等式
                      （最も実用的）
```

---

## 6. マルコフの不等式

### 6.1 定理

$X \geq 0$ かつ $a > 0$ のとき：

$$P(X \geq a) \leq \frac{E[X]}{a}$$

### 6.2 直感的理解

「平均が小さいのに大きな値が頻繁に出ることはない」

```
例：平均 E[X] = 10 のとき

P(X ≥ 100) ≤ 10/100 = 0.1 = 10%
P(X ≥ 50)  ≤ 10/50  = 0.2 = 20%
P(X ≥ 20)  ≤ 10/20  = 0.5 = 50%
```

### 6.3 証明のアイデア

$$E[X] = \underbrace{E[X \cdot \mathbf{1}_{X \geq a}]}_{\geq a \cdot P(X \geq a)} + \underbrace{E[X \cdot \mathbf{1}_{X < a}]}_{\geq 0}$$

---

## 7. チェビシェフの不等式

### 7.1 定理

任意の確率変数 $X$（$\text{Var}(X) < \infty$）に対し：

$$P(\lvert X - \mu \rvert \geq k\sigma) \leq \frac{1}{k^2}$$

### 7.2 直感的理解

「分散が小さいなら、平均から大きく外れることは稀」

```
k = 2：平均から 2σ 以上離れる確率 ≤ 25%
k = 3：平均から 3σ 以上離れる確率 ≤ 11.1%
k = 4：平均から 4σ 以上離れる確率 ≤ 6.25%

※ 正規分布の場合はもっと小さい（2σ で約5%、3σ で約0.3%）
　 チェビシェフは「どんな分布でも成り立つ」保証
```

### 7.3 証明

マルコフの不等式を $(X - \mu)^2$ に適用：

$$P(\lvert X - \mu \rvert \geq c) = P((X - \mu)^2 \geq c^2) \leq \frac{E[(X-\mu)^2]}{c^2} = \frac{\sigma^2}{c^2}$$

### 7.4 大数の法則との関係

チェビシェフの不等式から**大数の弱法則**を証明できます：

$$P(\lvert \bar{X}_n - \mu \rvert \geq \epsilon) \leq \frac{\sigma^2}{n\epsilon^2} \xrightarrow{n \to \infty} 0$$

---

## 8. イェンセンの不等式

### 8.1 凸関数と凹関数

```
凸関数（下に凸）              凹関数（上に凸）
g(x) = x², eˣ など           g(x) = log x, √x など

      /                           ＿＿
     /                           /    ＼
    /                           /        ＼
   ∪
弦が曲線の上側                  弦が曲線の下側
```

### 8.2 定理

**凸関数**のとき：

$$g(E[X]) \leq E[g(X)]$$

**凹関数**のとき：

$$g(E[X]) \geq E[g(X)]$$

### 8.3 直感的理解

凸関数では、「平均の変換」より「変換の平均」の方が大きい。

```
例：g(x) = x² （凸関数）

       E[X²]
         │
    ┌────┴────┐
    │  (E[X])²  │
    │    │    │
  ──┴────┴────┴──
        E[X]

E[X²] ≥ (E[X])²  ←  これは Var(X) ≥ 0 と同じ！
```

### 8.4 重要な応用

| 関数 | 凸/凹 | 不等式 |
|-----|------|--------|
| $x^2$ | 凸 | $(E[X])^2 \leq E[X^2]$ |
| $\log x$ | 凹 | $\log E[X] \geq E[\log X]$ |
| $e^x$ | 凸 | $e^{E[X]} \leq E[e^X]$ |
| $\sqrt{x}$ | 凹 | $\sqrt{E[X]} \geq E[\sqrt{X}]$ |

---

## 9. ヘルダー・コーシー・シュワルツの不等式

### 9.1 ヘルダーの不等式

$1/p + 1/q = 1$（$p, q > 1$）のとき：

$$E[\lvert XY \rvert] \leq (E[\lvert X \rvert^p])^{1/p} (E[\lvert Y \rvert^q])^{1/q}$$

### 9.2 コーシー・シュワルツの不等式

$p = q = 2$ の特殊ケース（最重要）：

$$\lvert E[XY] \rvert^2 \leq E[X^2] \cdot E[Y^2]$$

または：

$$\lvert E[XY] \rvert \leq \sqrt{E[X^2]} \cdot \sqrt{E[Y^2]}$$

### 9.3 応用例

**相関係数が $[-1, 1]$ に収まることの証明**：

$$\lvert \text{Cov}(X, Y) \rvert = \lvert E[(X-\mu_X)(Y-\mu_Y)] \rvert \leq \sigma_X \sigma_Y$$

よって $\lvert \rho \rvert \leq 1$

## 10. 例題

### 例題1：歪度の計算

$X \sim \text{Exp}(\lambda)$ の歪度を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**Step 1：原点積率を求める**

指数分布の積率母関数 $M_X(t) = \lambda/(\lambda - t)$ より：
- $E[X] = 1/\lambda$
- $E[X^2] = 2/\lambda^2$
- $E[X^3] = 6/\lambda^3$

**Step 2：分散を計算**

$$\sigma^2 = E[X^2] - (E[X])^2 = \frac{2}{\lambda^2} - \frac{1}{\lambda^2} = \frac{1}{\lambda^2}$$

$$\sigma = \frac{1}{\lambda}$$

**Step 3：3次中心積率**

公式 $\mu_3 = E[X^3] - 3E[X]E[X^2] + 2(E[X])^3$ より：

$$\mu_3 = \frac{6}{\lambda^3} - 3 \cdot \frac{1}{\lambda} \cdot \frac{2}{\lambda^2} + 2 \cdot \frac{1}{\lambda^3} = \frac{6 - 6 + 2}{\lambda^3} = \frac{2}{\lambda^3}$$

**Step 4：歪度**

$$\gamma_1 = \frac{\mu_3}{\sigma^3} = \frac{2/\lambda^3}{1/\lambda^3} = 2$$

**答え：$\gamma_1 = 2$**

指数分布は常に正の歪みを持つ（右に裾が長い）。

</details>

### 例題2：チェビシェフの不等式

$E[X] = 100$, $\text{Var}(X) = 25$ のとき、$P(\lvert X - 100 \rvert \geq 15)$ の上界を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$\sigma = \sqrt{25} = 5$

$k\sigma = 15$ より $k = 15/5 = 3$

チェビシェフの不等式：

$$P(\lvert X - 100 \rvert \geq 15) = P(\lvert X - \mu \rvert \geq 3\sigma) \leq \frac{1}{3^2} = \frac{1}{9}$$

**答え：$\leq 1/9 \approx 11.1\%$**

（補足：もし $X$ が正規分布なら、実際の確率は約 0.27% とはるかに小さい）

</details>

---

### 例題3：イェンセンの不等式

$X > 0$ のとき、$E[\sqrt{X}]$ と $\sqrt{E[X]}$ の大小関係を示せ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$g(x) = \sqrt{x}$ の2階微分：

$$g''(x) = -\frac{1}{4}x^{-3/2} < 0 \quad (x > 0)$$

よって $g$ は**凹関数**。

イェンセンの不等式（凹関数版）：

$$g(E[X]) \geq E[g(X)]$$

$$\sqrt{E[X]} \geq E[\sqrt{X}]$$

**答え：$\sqrt{E[X]} \geq E[\sqrt{X}]$**

等号は $X$ が定数（分散が 0）のときのみ成立。

</details>

## 11. 重要公式まとめ

### 積率と特性値

| 項目 | 公式 |
|-----|------|
| 分散 | $\text{Var}(X) = E[X^2] - (E[X])^2$ |
| 歪度 | $\gamma_1 = E[(X-\mu)^3]/\sigma^3$ |
| 尖度 | $\gamma_2 = E[(X-\mu)^4]/\sigma^4$ |
| 相関係数 | $\rho = \text{Cov}(X,Y)/(\sigma_X \sigma_Y)$ |

### 不等式

| 不等式 | 公式 | 条件 |
|-------|------|------|
| マルコフ | $P(X \geq a) \leq E[X]/a$ | $X \geq 0$ |
| チェビシェフ | $P(\lvert X-\mu \rvert \geq k\sigma) \leq 1/k^2$ | — |
| イェンセン（凸） | $g(E[X]) \leq E[g(X)]$ | $g$ が凸 |
| コーシー・シュワルツ | $\lvert E[XY] \rvert^2 \leq E[X^2]E[Y^2]$ | — |
