# 分散分析と実験計画

群間の差を検定する分散分析と効率的な実験設計を学びます。

---

## ANOVA の考え方

**ANOVA**（**A**nalysis **O**f **VA**riance、分散分析）は「変動を分解する」ことで群間の差を検出します。

```
ANOVA の基本的な発想

全体の変動 = 群間の変動 + 群内の変動

    群A        群B        群C
    ●          ○          △
    ●          ○          △
    ●          ○          △
   ─────────────────────────── 全体平均

群間変動：各群の平均が全体平均からどれだけ離れているか
群内変動：各観測値が自分の群の平均からどれだけ離れているか

「群間変動が群内変動に比べて大きければ、群間に差がある」
            ↓
    F = 群間変動/群内変動 を検定に使う
```

---

## 1. 一元配置分散分析

### 1.1 モデル

$$Y_{ij} = \mu + \alpha_i + \epsilon_{ij}$$

- $Y_{ij}$：群 $i$、個体 $j$ の観測値
- $\mu$：全体平均
- $\alpha_i$：群 $i$ の効果（$\sum \alpha_i = 0$）
- $\epsilon_{ij} \sim N(0, \sigma^2)$：誤差

### 1.2 仮説

$$H_0: \alpha_1 = \alpha_2 = \cdots = \alpha_k = 0$$
$$H_1: \text{少なくとも1つの } \alpha_i \neq 0$$

### 1.3 平方和の分解

$$SS_T = SS_A + SS_E$$

| 成分 | 平方和 | 自由度 |
|-----|--------|--------|
| 全体 | $SS_T = \sum_i \sum_j (Y_{ij} - \bar{Y})^2$ | $N - 1$ |
| 群間 | $SS_A = \sum_i n_i (\bar{Y}_i - \bar{Y})^2$ | $k - 1$ |
| 群内 | $SS_E = \sum_i \sum_j (Y_{ij} - \bar{Y}_i)^2$ | $N - k$ |

### 1.4 F検定

$$F = \frac{MS_A}{MS_E} = \frac{SS_A/(k-1)}{SS_E/(N-k)} \sim F_{k-1, N-k}$$

### 1.5 分散分析表

| 要因 | SS | df | MS | F |
|-----|-----|-----|-----|-----|
| 群間 | $SS_A$ | $k-1$ | $MS_A$ | $MS_A/MS_E$ |
| 群内 | $SS_E$ | $N-k$ | $MS_E$ | |
| 全体 | $SS_T$ | $N-1$ | | |

## 2. 二元配置分散分析

### 2.1 繰り返しなしのモデル

$$Y_{ij} = \mu + \alpha_i + \beta_j + \epsilon_{ij}$$

- $\alpha_i$：要因Aの効果
- $\beta_j$：要因Bの効果

### 2.2 繰り返しありのモデル

$$Y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \epsilon_{ijk}$$

- $(\alpha\beta)_{ij}$：交互作用

### 2.3 平方和の分解（繰り返しあり）

$$SS_T = SS_A + SS_B + SS_{AB} + SS_E$$

### 2.4 F検定（繰り返しあり）

| 要因 | df | F |
|-----|-----|-----|
| A | $a - 1$ | $MS_A / MS_E$ |
| B | $b - 1$ | $MS_B / MS_E$ |
| A×B | $(a-1)(b-1)$ | $MS_{AB} / MS_E$ |
| 誤差 | $ab(n-1)$ | |

## 3. 多重比較法

### 3.1 問題

$k$ 群の全てのペアを比較すると $\binom{k}{2}$ 回の検定。
第1種の過誤が増大。

### 3.2 テューキーのHSD法（Honestly Significant Difference）

全てのペアを同時に比較：

$$q = \frac{\bar{Y}_i - \bar{Y}_j}{\sqrt{MS_E / n}}$$

$q$ はスチューデント化された範囲分布に従う。

### 3.3 ダネットの方法

対照群との比較専用。

### 3.4 シェッフェの方法

任意の対比（コントラスト）を検定：

$$L = \sum c_i \bar{Y}_i \quad (\sum c_i = 0)$$

$$F = \frac{L^2}{(k-1) \cdot MS_E \cdot \sum c_i^2/n_i}$$

### 3.5 ボンフェローニ法

各検定の有意水準を $\alpha/m$ にする。

## 4. 実験計画法

### 4.1 完全無作為化計画

被験者をランダムに各処理群に割り当て。

### 4.2 乱塊法（Randomized Block Design）

ブロック（同質な群）内でランダムに処理を割り当て。

**モデル**：

$$Y_{ij} = \mu + \tau_i + \beta_j + \epsilon_{ij}$$

- $\tau_i$：処理効果
- $\beta_j$：ブロック効果

**利点**：ブロック間の変動を除去し、検出力向上。

### 4.3 ラテン方格法

2つのブロック要因（行・列）を同時に統制。

| | B1 | B2 | B3 |
|---|---|---|---|
| A1 | T1 | T2 | T3 |
| A2 | T2 | T3 | T1 |
| A3 | T3 | T1 | T2 |

各処理が各行・各列に1回ずつ出現。

### 4.4 要因計画（Factorial Design）

複数の要因を同時に操作：

- $2^k$ 計画：$k$ 個の2水準要因
- 主効果と交互作用を評価
- 部分実施法：全組み合わせの一部のみ実施

---

## 5. 効果量と検出力

### 5.1 効果量（Effect Size）

**コーエンの $f$**：

$$f = \frac{\sigma_\alpha}{\sigma}$$

$\sigma_\alpha^2 = \sum n_i \alpha_i^2 / N$

**η²（イータ二乗）**：

$$\eta^2 = \frac{SS_A}{SS_T}$$

### 5.2 検出力分析

- サンプルサイズの決定
- 非心F分布を使用
- 効果量、有意水準、サンプルサイズ、検出力の関係

## 6. 例題

### 例題1：一元配置分散分析

3群のデータ：A群(5, 7, 6)、B群(8, 9, 10)、C群(6, 7, 5)。群間に差があるか検定せよ（α=0.05）。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

各群平均：$\bar{Y}_A = 6$, $\bar{Y}_B = 9$, $\bar{Y}_C = 6$

全体平均：$\bar{Y} = (6+9+6)/3 = 7$

$$SS_A = 3[(6-7)^2 + (9-7)^2 + (6-7)^2] = 3[1+4+1] = 18$$

$$SS_E = (1+1+0) + (1+0+1) + (0+1+1) = 2+2+2 = 6$$

$$MS_A = 18/2 = 9, \quad MS_E = 6/6 = 1$$

$$F = 9/1 = 9$$

$F_{2,6,0.05} = 5.14$

$F = 9 > 5.14$ より $H_0$ 棄却。

**答え：群間に有意差あり（F = 9, p < 0.05）**

</details>

---

### 例題2：テューキーのHSD

上記の3群について、どの群間に差があるか多重比較せよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$MS_E = 1$, $n = 3$

標準誤差：$\sqrt{MS_E/n} = \sqrt{1/3} \approx 0.577$

各ペアの差：
- $|A - B| = |6 - 9| = 3$
- $|A - C| = |6 - 6| = 0$
- $|B - C| = |9 - 6| = 3$

$q$ 統計量：
- $q_{AB} = 3/0.577 \approx 5.20$
- $q_{AC} = 0$
- $q_{BC} \approx 5.20$

$q_{3,6,0.05} \approx 4.34$

$q_{AB}$, $q_{BC}$ > 4.34 より有意。

**答え：A-B間、B-C間に有意差あり。A-C間は差なし。**

</details>

---

### 例題3：効果量

$SS_A = 100$, $SS_T = 500$ のとき、$\eta^2$ を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\eta^2 = \frac{SS_A}{SS_T} = \frac{100}{500} = 0.2$$

**答え：$\eta^2 = 0.2$（中程度の効果）**

（コーエンの基準：0.01=小、0.06=中、0.14=大）

</details>

## 7. 重要公式まとめ

| 項目 | 公式 |
|-----|------|
| 群間平方和 | $SS_A = \sum n_i(\bar{Y}_i - \bar{Y})^2$ |
| 群内平方和 | $SS_E = \sum\sum (Y_{ij} - \bar{Y}_i)^2$ |
| F統計量 | $F = MS_A / MS_E$ |
| η² | $SS_A / SS_T$ |
| テューキーHSD | $q = (\bar{Y}_i - \bar{Y}_j) / \sqrt{MS_E/n}$ |
