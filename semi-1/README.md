# 統計検定準1級対策セクション

Stats Senseiの準1級対策セクションの計画書です。

## 概要

統計学実践ワークブック（全32章）をベースに、8カテゴリに再編成して学習コンテンツを提供します。

## ディレクトリ構成

```
/semi-1/
│
├── 1-probability/                # 確率論（4章分）
│   ├── events-probability        # 事象と確率、条件付き確率、ベイズ
│   ├── distributions-mgf         # 確率分布と母関数
│   ├── characteristics           # 分布の特性値、積率

│
├── 2-distributions/              # 確率分布（3章分）
│   ├── discrete                  # 離散型分布
│   ├── continuous                # 連続型分布
│   └── limit-theorems            # 極限定理、漸近理論
│
├── 3-inference/                  # 統計的推測（6章分）
│   ├── estimation-basics         # 推定の基礎
│   ├── interval-estimation       # 区間推定
│   ├── testing-basics            # 検定の基礎
│   ├── normal-tests              # 正規分布の検定
│   ├── general-tests             # 一般の検定
│   └── nonparametric             # ノンパラメトリック法
│
├── 4-stochastic/                 # 確率過程（2章分）
│   ├── markov-chain              # マルコフ連鎖
│   └── stochastic-process        # ポアソン過程、ブラウン運動
│
├── 5-regression/                 # 回帰分析（4章分）
│   ├── multiple-regression       # 重回帰、正則化
│   ├── diagnostics               # 回帰診断

│   └── advanced                  # 生存時間分析など

├── 7-multivariate/               # 多変量解析（5章分）
│   ├── pca                       # 主成分分析
│   ├── discriminant              # 判別分析
│   ├── clustering                # クラスター分析
│   ├── factor-analysis           # 因子分析
│   └── other-methods             # MDS、正準相関など
│
├── 8-advanced/                   # 発展的手法（6章分）

│
├── formulas/                     # 公式集
└── problems/                     # 問題集
```

## 各章の詳細トピック

### 第1章 事象と確率
- 事象と確率
- 条件付き確率とベイズの定理
- 期待値と分散

### 第2章 確率分布と母関数
- 累積分布関数と生存関数
- 同時確率密度関数
- 母関数（モーメント母関数、確率母関数）

### 第3章 分布の特性値
- 確率変数の分布の特性値
- 同時分布の特性値
- 特性値の性質
- データの特性値
- 平均ベクトルと分散共分散行列

### 第4章 変数変換
- 変数変換による確率密度関数の変化（ヤコビアン）
- 確率変数の線形結合の分布
- データの変換

### 第5章 離散型分布
- 離散一様分布、ベルヌーイ分布、二項分布
- 超幾何分布、ポアソン分布
- 幾何分布、負の二項分布、多項分布

### 第6章 連続型分布と標本分布
- 連続一様分布、正規分布、指数分布
- ガンマ分布、ベータ分布、コーシー分布、対数正規分布
- 多変量正規分布、混合正規分布
- カイ二乗分布、t分布、F分布（非心分布を含む）

### 第7章 極限定理、漸近理論
- 確率変数の収束、大数の弱法則
- 確率分布の収束、少数法則
- 中心極限定理、極値分布
- 分布収束の性質、デルタ法

### 第8章 統計的推定の基礎
- 統計量、各種推定法
- 点推定の性質（不偏性、有効性、一致性）
- 漸近的な性質、リサンプリング法

### 第9章 区間推定
- 区間推定の基礎
- 分散の区間推定、分散の比の区間推定
- 多項分布の信頼区間

### 第10章 検定の基礎と検定法の導出
- 統計的仮説検定の考え方
- 検定法の導出（尤度比検定など）
- P-値、検定の過誤
- サンプルサイズ設計、抜取検査

### 第11章 正規分布に関する検定
- 1標本・2標本の平均の検定
- 分散の検定

### 第12章 一般の分布に関する検定法
- 母比率の検定、ポアソン分布に関する検定
- 適合度検定、尤度比検定

### 第13章 ノンパラメトリック法
- ウィルコクソンの順位和検定、並べ替え検定
- 符号付き順位検定、符号検定
- クラスカル・ウォリス検定、順位相関係数

### 第14章 マルコフ連鎖
- 離散的で有限な状態空間
- 推移確率の性質、定常分布
- パラメータ推定

### 第15章 確率過程の基礎
- 独立定常増分
- ブラウン運動、ポアソン過程
- 複合ポアソン過程

### 第16章 重回帰分析
- 重回帰分析の検定
- 正則化（リッジ、LASSO）

### 第17章 回帰診断法

- leverage（てこ比）とCookの距離

### 第18章 質的回帰
- ロジスティック回帰モデル、プロビットモデル
- ポアソン回帰モデル

### 第19章 回帰分析その他

### 第21章 標本調査法

### 第23章 判別分析

### 第24章 クラスター分析

### 第25章 因子分析・グラフィカルモデル

### 第26章 その他の多変量解析手法

- 2元・3元分割表

### 第29章 不完全データの統計処理
- 削除法と補完法
- 正規分布における推測
- EMアルゴリズム

### 第30章 モデル選択

### 第31章 ベイズ法
- ベイズ法によるパラメータ推測
- 点推定、区間推定
