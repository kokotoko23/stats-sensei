# 離散型分布

2級レベルより発展的な離散型確率分布を学びます。

---

## 離散分布を学ぶ意味

離散型分布は「数える」データに対応します。製品の不良品数、来店客数、アンケートの回答パターンなど、実務で頻繁に登場します。

```
離散分布の使い分け

状況                           → 適切な分布
────────────────────────────────────────────
復元抽出（独立試行）            → 二項分布
非復元抽出（有限母集団）        → 超幾何分布
成功まで待つ                    → 幾何分布・負の二項分布
単位時間あたりの発生数          → ポアソン分布
複数カテゴリへの分類            → 多項分布
```

---

## 1. 基本的な離散分布（復習）

**PMF** = **P**robability **M**ass **F**unction（確率質量関数）

| 分布 | 記号 | PMF | 期待値 | 分散 |
|-----|------|-----|--------|------|
| ベルヌーイ | $\text{Ber}(p)$ | $p^x(1-p)^{1-x}$ | $p$ | $p(1-p)$ |
| 二項 | $\text{Bin}(n,p)$ | $\binom{n}{x}p^x(1-p)^{n-x}$ | $np$ | $np(1-p)$ |
| ポアソン | $\text{Poi}(\lambda)$ | $e^{-\lambda}\frac{\lambda^x}{x!}$ | $\lambda$ | $\lambda$ |
| 幾何 | $\text{Geo}(p)$ | $(1-p)^{x-1}p$ | $1/p$ | $(1-p)/p^2$ |

## 2. 超幾何分布

### なぜ超幾何分布が必要か

二項分布は「復元抽出」または「無限母集団」を仮定します。しかし実際の品質検査などでは、検査した製品を戻さない（非復元抽出）ため、毎回の抽出で確率が変化します。

```
超幾何分布の典型的な場面

箱の中に10個のボール：●●●○○○○○○○（●=赤3個、○=白7個）

2個を取り出す（戻さない）

1個目で●を引いた場合：
  残り：●●○○○○○○○（9個中、赤2個）
  2個目で●を引く確率 = 2/9（≠ 3/10）

→ 非復元抽出では確率が変化する！
→ 超幾何分布が必要
```

### 2.1 設定

$N$ 個の対象中、$K$ 個が「成功」（特定の属性を持つ）。
$n$ 個を非復元抽出したとき、成功の数 $X$。

### 2.2 確率関数

$$P(X = x) = \frac{\binom{K}{x}\binom{N-K}{n-x}}{\binom{N}{n}}$$

**直感的理解**：

```
分子：「成功 K 個から x 個選ぶ」×「失敗 N-K 個から n-x 個選ぶ」
分母：「全 N 個から n 個選ぶ」（全パターン数）

     成功からx個   失敗からn-x個
         ↓             ↓
P(X=x) = C(K,x)  ×  C(N-K,n-x)
         ─────────────────────
              C(N,n)
                ↑
          全体からn個選ぶ方法
```

範囲：$\max(0, n+K-N) \leq x \leq \min(n, K)$

### 2.3 期待値と分散

$$E[X] = \frac{nK}{N}$$

$$\text{Var}(X) = \frac{nK(N-K)(N-n)}{N^2(N-1)}$$

### 2.4 二項分布との関係

$N \to \infty$、$K/N \to p$ のとき：

$$\text{Hypergeometric}(N, K, n) \to \text{Bin}(n, p)$$

**有限母集団補正**（FPC: Finite Population Correction）：

$$\text{Var}(X)_{\text{超幾何}} = \text{Var}(X)_{\text{二項}} \times \frac{N-n}{N-1}$$

```
有限母集団補正の直感

・母集団が大きい（N >> n）→ 補正係数 ≈ 1（二項分布とほぼ同じ）
・母集団の大部分を抽出（n ≈ N）→ 補正係数 ≈ 0（分散が小さい）

例：100個中10個抽出 → (100-10)/(100-1) ≈ 0.91
   100個中90個抽出 → (100-90)/(100-1) ≈ 0.10

たくさん調べるほど、不確実性が減る！
```

## 3. 負の二項分布

### 負の二項分布の考え方

二項分布は「n回試行で成功は何回か」を問います。負の二項分布は逆に「r回成功するまでに何回試行が必要か」を問います。

```
二項分布 vs 負の二項分布

二項分布：
  「10回コインを投げて、表が出る回数は？」
  → 回数 n を固定、成功数 X が確率変数

負の二項分布：
  「表が3回出るまで、何回コインを投げる？」
  → 成功数 r を固定、回数 X が確率変数

時系列で見ると：
試行: 1  2  3  4  5  6  7  8  9  ...
結果: ×  ○  ×  ×  ○  ×  ×  ×  ○ ← 3回目の成功！
                              ↑
                          X = 9（9回目で終了）
```

### 3.1 定義

成功確率 $p$ の独立試行で、$r$ 回目の成功までに要する試行回数 $X$。

### 3.2 確率関数

$$P(X = x) = \binom{x-1}{r-1} p^r (1-p)^{x-r}, \quad x = r, r+1, \ldots$$

**直感的理解**：

```
x回目でr回目の成功が起きる確率

・最後（x回目）は必ず成功      → p
・それまでの x-1 回で r-1 回成功 → C(x-1, r-1) × p^(r-1) × (1-p)^(x-r)

合わせて：C(x-1, r-1) × p^r × (1-p)^(x-r)
```

または、失敗回数 $Y = X - r$ で表すと：

$$P(Y = y) = \binom{r+y-1}{y} p^r (1-p)^y, \quad y = 0, 1, 2, \ldots$$

**注意**：教科書によって「試行回数」か「失敗回数」かの定義が異なります。問題文をよく確認してください。

### 3.3 期待値と分散

$$E[X] = \frac{r}{p}, \quad \text{Var}(X) = \frac{r(1-p)}{p^2}$$

失敗回数 $Y$ の場合：

$$E[Y] = \frac{r(1-p)}{p}, \quad \text{Var}(Y) = \frac{r(1-p)}{p^2}$$

### 3.4 幾何分布との関係

$r = 1$ のとき幾何分布。

### 3.5 モーメント母関数

$$M_Y(t) = \left(\frac{p}{1 - (1-p)e^t}\right)^r$$

### 3.6 ポアソンとの関係

$r \to \infty$、$(1-p)/p \to \lambda/r$ のとき：

$$\text{NB}(r, p) \to \text{Poi}(\lambda)$$

## 4. 多項分布

### 多項分布の考え方

二項分布は「成功/失敗」の2択でしたが、多項分布は3択以上への一般化です。

```
二項分布 → 多項分布への拡張

二項：コイン投げ（表/裏の2択）
多項：サイコロ投げ（1〜6の6択）
     アンケート（賛成/反対/どちらでもない の3択）

例：サイコロを10回投げたときの各目の出現回数
    (X₁, X₂, X₃, X₄, X₅, X₆) = (2, 1, 3, 0, 2, 2)
                                ↑ 合計 = 10

多項分布 = 二項分布の多次元版
```

### 4.1 定義

$k$ 個のカテゴリへの分類。各カテゴリの確率 $p_1, \ldots, p_k$（$\sum p_i = 1$）。
$n$ 回の独立試行で各カテゴリの度数 $(X_1, \ldots, X_k)$。

### 4.2 確率関数

$$P(X_1 = x_1, \ldots, X_k = x_k) = \frac{n!}{x_1! \cdots x_k!} p_1^{x_1} \cdots p_k^{x_k}$$

**多項係数**：$\frac{n!}{x_1! \cdots x_k!}$ は、n回の試行をカテゴリに振り分ける方法の数。

条件：$\sum x_i = n$

### 4.3 周辺分布

$$X_i \sim \text{Bin}(n, p_i)$$

### 4.4 期待値・分散・共分散

$$E[X_i] = np_i$$

$$\text{Var}(X_i) = np_i(1-p_i)$$

$$\text{Cov}(X_i, X_j) = -np_i p_j \quad (i \neq j)$$

**共分散が負になる理由**：$\sum X_i = n$（固定）なので、あるカテゴリの度数が増えれば他のカテゴリは減らざるを得ない。

### 4.5 条件付き分布

$X_1 = x_1$ が与えられたとき、$(X_2, \ldots, X_k)$ は：

$$\text{Multinomial}\left(n - x_1; \frac{p_2}{1-p_1}, \ldots, \frac{p_k}{1-p_1}\right)$$

## 5. ポアソン分布の応用

### 5.1 ポアソン過程との関係

単位時間あたりの発生率 $\lambda$ のポアソン過程で、時間 $t$ 内の発生回数：

$$N(t) \sim \text{Poi}(\lambda t)$$

### 5.2 ポアソン近似（少数の法則）

$n$ が大きく、$p$ が小さく、$np = \lambda$ のとき：

$$\text{Bin}(n, p) \approx \text{Poi}(\lambda)$$

### 5.3 条件付きポアソン

$X \sim \text{Poi}(\lambda_1)$, $Y \sim \text{Poi}(\lambda_2)$ が独立のとき：

$$X \mid X + Y = n \sim \text{Bin}\left(n, \frac{\lambda_1}{\lambda_1 + \lambda_2}\right)$$

### 5.4 ポアソンの加法性

$$\text{Poi}(\lambda_1) + \text{Poi}(\lambda_2) \sim \text{Poi}(\lambda_1 + \lambda_2)$$

## 6. その他の離散分布

### 6.1 離散一様分布

$$P(X = x) = \frac{1}{n}, \quad x = 1, 2, \ldots, n$$

$$E[X] = \frac{n+1}{2}, \quad \text{Var}(X) = \frac{n^2 - 1}{12}$$

### 6.2 ベータ二項分布

$$P(X = x) = \binom{n}{x} \frac{B(x + \alpha, n - x + \beta)}{B(\alpha, \beta)}$$

二項分布のパラメータ $p$ がベータ分布に従うとき。

### 6.3 ポアソン・ガンマ（負の二項）

ポアソン分布のパラメータ $\lambda$ がガンマ分布に従うとき、周辺分布は負の二項分布。

## 7. 例題

### 例題1：超幾何分布

10個の製品中3個が不良品。4個を非復元抽出したとき、不良品が1個だけ含まれる確率を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$N = 10$, $K = 3$（不良品）, $n = 4$

$$P(X = 1) = \frac{\binom{3}{1}\binom{7}{3}}{\binom{10}{4}}$$

$$= \frac{3 \times 35}{210} = \frac{105}{210} = \frac{1}{2}$$

**答え：1/2（50%）**

</details>

---

### 例題2：負の二項分布

成功確率0.3で、3回成功するまでに平均何回の試行が必要か。また、その分散を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$r = 3$, $p = 0.3$

$$E[X] = \frac{r}{p} = \frac{3}{0.3} = 10$$

$$\text{Var}(X) = \frac{r(1-p)}{p^2} = \frac{3 \times 0.7}{0.09} = \frac{2.1}{0.09} = \frac{70}{3} \approx 23.33$$

**答え：期待値 10回、分散 70/3 ≈ 23.33**

</details>

---

### 例題3：多項分布の共分散

サイコロを60回投げる。1の目の回数を $X_1$、2の目の回数を $X_2$ とするとき、$\text{Cov}(X_1, X_2)$ を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$n = 60$, $p_1 = p_2 = 1/6$

$$\text{Cov}(X_1, X_2) = -np_1 p_2 = -60 \times \frac{1}{6} \times \frac{1}{6}$$

$$= -\frac{60}{36} = -\frac{5}{3} \approx -1.67$$

**答え：$-5/3 \approx -1.67$**

（負の共分散：一方が増えれば他方が減る傾向）

</details>

## 8. よくある誤解

### 誤解1：超幾何分布と二項分布の混同

```
✗ 誤り：「抽出なら常に二項分布」

✓ 正しい：
  ・復元抽出 or 母集団が十分大きい → 二項分布
  ・非復元抽出 かつ 母集団が小さい → 超幾何分布

目安：n/N < 0.05（抽出率5%未満）なら二項分布で近似可能
```

### 誤解2：負の二項分布の定義

```
✗ 誤り：負の二項分布の定義は1つ

✓ 正しい：少なくとも2つの定義が広く使われる
  ・試行回数 X（成功 r 回までの総試行数）
  ・失敗回数 Y = X - r（成功 r 回までの失敗数）

問題文で何を求めているか必ず確認！
```

### 誤解3：多項分布の周辺分布

```
✗ 誤り：Xi と Xj は独立

✓ 正しい：周辺分布は各々二項分布だが、互いに独立ではない
         ∑Xi = n という制約があるため

これが Cov(Xi, Xj) < 0 となる原因
```

## 9. 分布間の関係

```
離散分布の関係図

                    ベルヌーイ Ber(p)
                         │
            ┌────────────┼────────────┐
            ↓            ↓            ↓
    幾何 Geo(p)    二項 Bin(n,p)   多項 Multi
    「初成功まで」  「n回中の成功数」  「k択への分類」
            │            │
            ↓            ↓
    負の二項 NB(r,p)   ポアソン Poi(λ)
    「r回成功まで」    「np→λで近似」
                         │
                         ↓
                    超幾何 → 二項（N→∞で近似）
                    「非復元抽出」
```

**近似関係まとめ**：

| 元の分布 | 条件 | 近似先 |
|---------|------|--------|
| 超幾何 | $N \to \infty$, $K/N \to p$ | 二項 |
| 二項 | $n$ 大, $p$ 小, $np = \lambda$ | ポアソン |
| 負の二項 | $r \to \infty$, $(1-p)/p \to \lambda/r$ | ポアソン |

## 10. 重要公式まとめ

| 分布 | 期待値 | 分散 |
|-----|--------|------|
| 超幾何 $H(N, K, n)$ | $nK/N$ | $nK(N-K)(N-n)/(N^2(N-1))$ |
| 負の二項 $\text{NB}(r, p)$ | $r/p$ | $r(1-p)/p^2$ |
| 多項 $X_i$ | $np_i$ | $np_i(1-p_i)$ |
| 多項共分散 | — | $\text{Cov}(X_i, X_j) = -np_ip_j$ |
