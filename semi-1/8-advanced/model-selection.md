# モデル選択

最適なモデルを選択する方法を学びます。

---

## 1. モデル選択の必要性

### 1.1 バイアス・バリアンストレードオフ

$$\text{MSE} = \text{Bias}^2 + \text{Variance}$$

- 複雑なモデル：低バイアス、高バリアンス
- 単純なモデル：高バイアス、低バリアンス

### 1.2 過学習（Overfitting）

訓練データに適合しすぎて、新しいデータへの予測性能が低下。

---

## 2. 情報量基準

### 2.1 赤池情報量基準（AIC）

$$\text{AIC} = -2\ell(\hat{\theta}) + 2k$$

- $\ell(\hat{\theta})$：最大対数尤度
- $k$：パラメータ数

**小さいほど良いモデル**。

### 2.2 AICの導出

カルバック・ライブラー情報量の漸近不偏推定量。

$$\text{KL}(f \| g) = \int f(x) \log \frac{f(x)}{g(x)} dx$$

### 2.3 修正AIC（AICc）

小標本補正：

$$\text{AIC}_c = \text{AIC} + \frac{2k(k+1)}{n-k-1}$$

$n$ が小さいときに使用。

### 2.4 ベイズ情報量基準（BIC）

$$\text{BIC} = -2\ell(\hat{\theta}) + k \log n$$

AICより複雑なモデルにペナルティ（$n \geq 8$ のとき）。

### 2.5 AIC vs BIC

| 基準 | 目的 | ペナルティ |
|-----|------|----------|
| AIC | 予測精度の最大化 | $2k$ |
| BIC | 真のモデルの選択 | $k \log n$ |

BICは一致性（$n \to \infty$ で真のモデルを選ぶ）を持つ。

---

## 3. 交差検証（Cross-Validation）

### 3.1 ホールドアウト法

データを訓練セットとテストセットに分割。

### 3.2 k分割交差検証（k-fold CV）

1. データを $k$ 個に分割
2. $k-1$ 個で訓練、1個でテスト
3. $k$ 回繰り返して平均

$$\text{CV}_k = \frac{1}{k} \sum_{i=1}^k \text{MSE}_i$$

### 3.3 Leave-One-Out（LOO）

$k = n$ の交差検証。

$$\text{CV}_{\text{LOO}} = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_{-i})^2$$

$\hat{y}_{-i}$：$i$ 番目を除いて訓練したモデルでの予測

### 3.4 一般化交差検証（GCV）

線形モデルでのLOOの近似：

$$\text{GCV} = \frac{1}{n} \sum_{i=1}^n \left(\frac{y_i - \hat{y}_i}{1 - h_{ii}}\right)^2$$

$h_{ii}$：ハット行列の対角要素

---

## 4. 変数選択

### 4.1 全探索

$p$ 個の変数から最適な部分集合を選ぶ。

$2^p$ 個のモデルを比較（計算コスト大）。

### 4.2 ステップワイズ法

| 方法 | 手順 |
|-----|------|
| 前進選択法 | 変数を1つずつ追加 |
| 後退消去法 | 変数を1つずつ除去 |
| 変数増減法 | 追加と除去を組み合わせ |

### 4.3 正則化による選択

- **LASSO**：$L_1$ 正則化で係数を0に
- **Elastic Net**：$L_1$ と $L_2$ の組み合わせ

---

## 5. モデルの評価指標

### 5.1 回帰モデル

| 指標 | 定義 |
|-----|------|
| MSE | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ |
| RMSE | $\sqrt{\text{MSE}}$ |
| MAE | $\frac{1}{n}\sum\|y_i - \hat{y}_i\|$ |
| $R^2$ | $1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}}$ |
| 調整 $R^2$ | $1 - (1-R^2)\frac{n-1}{n-k-1}$ |

### 5.2 分類モデル

| 指標 | 定義 |
|-----|------|
| 正確度 | $(TP + TN) / N$ |
| 感度 | $TP / (TP + FN)$ |
| 特異度 | $TN / (TN + FP)$ |
| AUC | ROC曲線下の面積 |

## 6. 例題

### 例題1：AICの計算

3つのモデルの対数尤度とパラメータ数：
- モデルA：$\ell = -100$, $k = 3$
- モデルB：$\ell = -98$, $k = 5$
- モデルC：$\ell = -95$, $k = 8$

AICが最小のモデルを選べ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\text{AIC}_A = -2(-100) + 2(3) = 200 + 6 = 206$$

$$\text{AIC}_B = -2(-98) + 2(5) = 196 + 10 = 206$$

$$\text{AIC}_C = -2(-95) + 2(8) = 190 + 16 = 206$$

3つとも同じAIC！

**答え：どれも同等（AIC = 206）**

</details>

---

### 例題2：BICの比較

$n = 100$ のとき、上記のモデルのBICを計算し、最適なモデルを選べ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$\log 100 = 4.605$

$$\text{BIC}_A = 200 + 3 \times 4.605 = 200 + 13.82 = 213.82$$

$$\text{BIC}_B = 196 + 5 \times 4.605 = 196 + 23.03 = 219.03$$

$$\text{BIC}_C = 190 + 8 \times 4.605 = 190 + 36.84 = 226.84$$

**答え：モデルA（BIC = 213.82で最小）**

BICは複雑なモデルに重いペナルティ。

</details>

---

### 例題3：交差検証

5分割CVの結果がMSE = {2.1, 2.3, 2.0, 2.4, 2.2}のとき、CVスコアを求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\text{CV}_5 = \frac{1}{5}(2.1 + 2.3 + 2.0 + 2.4 + 2.2) = \frac{11.0}{5} = 2.2$$

**答え：CV = 2.2**

</details>

## 7. 重要公式まとめ

| 項目 | 公式 |
|-----|------|
| AIC | $-2\ell(\hat{\theta}) + 2k$ |
| BIC | $-2\ell(\hat{\theta}) + k\log n$ |
| AICc | $\text{AIC} + 2k(k+1)/(n-k-1)$ |
| k-fold CV | $\frac{1}{k}\sum \text{MSE}_i$ |
| 調整$R^2$ | $1 - (1-R^2)(n-1)/(n-k-1)$ |
