# シミュレーション

計算機を用いた統計的手法を学びます。

---

## 1. モンテカルロ法

### 1.1 基本原理

大数の法則を利用した数値計算：

$$\int g(x) f(x) dx = E_f[g(X)] \approx \frac{1}{n} \sum_{i=1}^n g(X_i)$$

$X_i \sim f(x)$

### 1.2 モンテカルロ積分

$$I = \int_a^b g(x) dx = (b-a) \int_a^b g(x) \frac{1}{b-a} dx$$

$$\approx \frac{b-a}{n} \sum_{i=1}^n g(U_i)$$

$U_i \sim \text{Uniform}(a, b)$

### 1.3 標準誤差

$$\text{SE}(\hat{I}) = \frac{s}{\sqrt{n}}$$

$s$：$g(U_i)$ の標本標準偏差

## 2. 乱数生成法

### 2.1 逆関数法

累積分布関数 $F(x)$ の逆関数を利用：

1. $U \sim \text{Uniform}(0, 1)$ を生成
2. $X = F^{-1}(U)$ とする

例：指数分布（$F(x) = 1 - e^{-\lambda x}$）

$$X = -\frac{1}{\lambda} \log(1 - U) = -\frac{1}{\lambda} \log U$$

### 2.2 棄却法（Accept-Reject法）

目標密度 $f(x)$、提案密度 $g(x)$、上界 $M \geq f(x)/g(x)$

1. $Y \sim g(y)$、$U \sim \text{Uniform}(0, 1)$ を生成
2. $U \leq \frac{f(Y)}{M \cdot g(Y)}$ なら $X = Y$ を採択
3. そうでなければ1に戻る

### 2.3 ボックス・ミュラー法

標準正規乱数の生成：

$$U_1, U_2 \sim \text{Uniform}(0, 1)$$

$$Z_1 = \sqrt{-2\log U_1} \cos(2\pi U_2)$$

$$Z_2 = \sqrt{-2\log U_1} \sin(2\pi U_2)$$

$Z_1, Z_2 \sim N(0, 1)$ は独立。

## 3. ブートストラップ法

### 3.1 基本原理

復元抽出による再標本化で、推定量の分布を近似。

### 3.2 ノンパラメトリック・ブートストラップ

1. 元データ $\{x_1, \ldots, x_n\}$ から復元抽出で大きさ $n$ の標本を作成
2. ブートストラップ統計量 $\hat{\theta}^*$ を計算
3. $B$ 回繰り返し、$\{\hat{\theta}^*_1, \ldots, \hat{\theta}^*_B\}$ を得る

### 3.3 ブートストラップ標準誤差

$$\text{SE}_{\text{boot}} = \sqrt{\frac{1}{B-1} \sum_{b=1}^B (\hat{\theta}^*_b - \bar{\theta}^*)^2}$$

### 3.4 ブートストラップ信頼区間

**パーセンタイル法**：

$$[\hat{\theta}^*_{\alpha/2}, \hat{\theta}^*_{1-\alpha/2}]$$

$\hat{\theta}^*_\alpha$：ブートストラップ分布の $\alpha$ 分位点

**BCa法**（バイアス補正・加速法）：

バイアスと歪みを補正した信頼区間。

### 3.5 パラメトリック・ブートストラップ

推定されたパラメトリックモデルからシミュレーション。

## 4. ジャックナイフ法

### 4.1 定義

$i$ 番目の観測値を除いた推定量：

$$\hat{\theta}_{-i} = \hat{\theta}(x_1, \ldots, x_{i-1}, x_{i+1}, \ldots, x_n)$$

### 4.2 ジャックナイフ推定量

$$\hat{\theta}_{\text{jack}} = n\hat{\theta} - (n-1)\bar{\theta}_{(-)}$$

$$\bar{\theta}_{(-)} = \frac{1}{n} \sum_{i=1}^n \hat{\theta}_{-i}$$

### 4.3 ジャックナイフ分散推定

$$\hat{V}_{\text{jack}} = \frac{n-1}{n} \sum_{i=1}^n (\hat{\theta}_{-i} - \bar{\theta}_{(-)})^2$$

### 4.4 バイアス推定

$$\text{Bias}_{\text{jack}} = (n-1)(\bar{\theta}_{(-)} - \hat{\theta})$$

---

## 5. 置換検定

### 5.1 原理

帰無仮説のもとで、グループラベルを並べ替えても分布は同じ。

### 5.2 手順

1. 観測された検定統計量 $T_{\text{obs}}$ を計算
2. すべてのラベルの置換（または多数の無作為置換）に対して $T$ を計算
3. p値 = $\frac{\#\{T \geq T_{\text{obs}}\}}{\text{総置換数}}$

### 5.3 特徴

- 分布の仮定不要
- 正確なp値
- 小標本でも有効

## 6. 分散減少法

### 6.1 対照変量法

$E[Z]$ が既知で $\text{Cov}(X, Z)$ が大きいとき：

$$X^* = X - c(Z - E[Z])$$

最適 $c = \text{Cov}(X, Z) / \text{Var}(Z)$

### 6.2 層化サンプリング

標本空間を層に分けてサンプリング。

### 6.3 重点サンプリング

$$E_f[g(X)] = E_h\left[g(X) \frac{f(X)}{h(X)}\right]$$

$h(x)$ を工夫して分散を減少。

## 7. 例題

### 例題1：逆関数法

一様乱数 $U = 0.3$ から指数分布（$\lambda = 2$）の乱数を生成せよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$X = -\frac{1}{\lambda} \log U = -\frac{1}{2} \log 0.3$$

$$= -0.5 \times (-1.204) = 0.602$$

**答え：X ≈ 0.602**

</details>

---

### 例題2：ブートストラップ標準誤差

データ {2, 4, 6} の平均のブートストラップ標準誤差を3回の再標本化で推定する。ブートストラップ標本と平均が以下のとき、SEを計算せよ。

- 標本1: {2, 2, 6} → 平均 3.33
- 標本2: {4, 4, 4} → 平均 4.00
- 標本3: {2, 6, 6} → 平均 4.67

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\bar{\theta}^* = \frac{3.33 + 4.00 + 4.67}{3} = 4.00$$

$$\text{SE}_{\text{boot}} = \sqrt{\frac{(3.33-4)^2 + (4-4)^2 + (4.67-4)^2}{2}}$$

$$= \sqrt{\frac{0.449 + 0 + 0.449}{2}} = \sqrt{0.449} \approx 0.67$$

**答え：SE ≈ 0.67**

</details>

---

### 例題3：置換検定

群A = {3, 5}、群B = {7, 9} で平均差の置換検定のp値を求めよ（片側、A < B）。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

観測された差：$\bar{B} - \bar{A} = 8 - 4 = 4$

全置換（$\binom{4}{2} = 6$ 通り）：

| A | B | 差 |
|---|---|---|
| {3,5} | {7,9} | 4 |
| {3,7} | {5,9} | 2 |
| {3,9} | {5,7} | 0 |
| {5,7} | {3,9} | 2 |
| {5,9} | {3,7} | 0 |
| {7,9} | {3,5} | -4 |

差 ≥ 4 となるのは1通り。

$$p = \frac{1}{6} \approx 0.167$$

**答え：p ≈ 0.167**

</details>
