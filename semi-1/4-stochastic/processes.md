# 確率過程の基礎

連続時間の重要な確率過程を学びます。

---

## 1. 確率過程の定義

### 1.1 定義

確率過程 $\{X(t)\}_{t \in T}$ は、添字集合 $T$（通常は時間）で定義された確率変数の族。

### 1.2 分類

| 状態空間 | 時間 | 例 |
|---------|-----|-----|
| 離散 | 離散 | マルコフ連鎖 |
| 離散 | 連続 | ポアソン過程 |
| 連続 | 離散 | 時系列（AR, MA） |
| 連続 | 連続 | ブラウン運動 |

### 1.3 標本路（サンプルパス）

固定した $\omega$ に対する $X(t, \omega)$ の軌跡。

---

## 2. ポアソン過程

### 2.1 定義

計数過程 $\{N(t)\}_{t \geq 0}$ がレート $\lambda$ のポアソン過程：

1. $N(0) = 0$
2. **独立増分**：重ならない区間の増分は独立
3. **定常増分**：$N(t+s) - N(s) \sim \text{Poi}(\lambda t)$

### 2.2 基本性質

$$P(N(t) = k) = e^{-\lambda t} \frac{(\lambda t)^k}{k!}$$

$$E[N(t)] = \lambda t, \quad \text{Var}(N(t)) = \lambda t$$

### 2.3 到着間隔

$T_n$：第 $n-1$ 番目と第 $n$ 番目のイベント間の時間

$$T_n \sim \text{Exp}(\lambda)$$（独立同分布）

### 2.4 待ち時間（到着時刻）

$S_n = T_1 + T_2 + \cdots + T_n$：$n$ 番目のイベントの時刻

$$S_n \sim \Gamma(n, \lambda)$$

### 2.5 条件付き分布

$N(t) = n$ が与えられたとき、$n$ 個のイベントの時刻は $(0, t)$ 上の一様分布の順序統計量と同分布：

$$(S_1, \ldots, S_n | N(t) = n) \overset{d}{=} (U_{(1)}, \ldots, U_{(n)}) \cdot t$$

$U_i \sim \text{Uniform}(0, 1)$

---

## 3. ポアソン過程の拡張

### 3.1 合成ポアソン過程

$$S(t) = \sum_{i=1}^{N(t)} X_i$$

- $N(t)$：レート $\lambda$ のポアソン過程
- $X_i$：独立同分布の確率変数

**期待値**：$E[S(t)] = \lambda t \cdot E[X]$

**分散**：$\text{Var}(S(t)) = \lambda t \cdot E[X^2]$

### 3.2 非斉次ポアソン過程

強度関数 $\lambda(t)$ が時間依存：

$$P(N(t) - N(s) = k) = e^{-\Lambda(s,t)} \frac{\Lambda(s,t)^k}{k!}$$

$$\Lambda(s, t) = \int_s^t \lambda(u) du$$

### 3.3 マーキングと分割

レート $\lambda$ のポアソン過程で、各イベントを確率 $p$ で Type A、$1-p$ で Type B に分類すると：

- Type A：レート $\lambda p$ のポアソン過程
- Type B：レート $\lambda(1-p)$ のポアソン過程
- 両者は独立

---

## 4. ブラウン運動（ウィーナー過程）

### 4.1 定義

確率過程 $\{W(t)\}_{t \geq 0}$ が標準ブラウン運動：

1. $W(0) = 0$
2. **独立増分**：重ならない区間の増分は独立
3. **正規増分**：$W(t) - W(s) \sim N(0, t-s)$（$t > s$）
4. 標本路はほとんど確実に連続

### 4.2 基本性質

$$E[W(t)] = 0$$

$$\text{Var}(W(t)) = t$$

$$\text{Cov}(W(s), W(t)) = \min(s, t)$$

### 4.3 標本路の性質

- ほとんど確実に連続
- どの点でも微分不可能（ほとんど確実に）
- 無限変動（有限区間で）

### 4.4 ドリフト付きブラウン運動

$$X(t) = \mu t + \sigma W(t)$$

$$X(t) \sim N(\mu t, \sigma^2 t)$$

### 4.5 幾何ブラウン運動

$$S(t) = S(0) \exp\left(\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W(t)\right)$$

株価モデルなどに使用。

---

## 5. マルチンゲール

### 5.1 定義

確率過程 $\{X_n\}$ がマルチンゲール：

$$E[X_{n+1} | X_1, \ldots, X_n] = X_n$$

### 5.2 ブラウン運動のマルチンゲール性

$W(t)$ はマルチンゲール：

$$E[W(t) | W(s), s \leq u] = W(u) \quad (u < t)$$

### 5.3 オプショナル・サンプリング定理

停止時刻 $\tau$ に対し、一定の条件下で：

$$E[X_\tau] = E[X_0]$$

## 6. 待ち行列理論の基礎

### 6.1 M/M/1待ち行列

- 到着：レート $\lambda$ のポアソン過程
- サービス時間：レート $\mu$ の指数分布
- サーバー数：1

### 6.2 安定条件

利用率 $\rho = \lambda/\mu < 1$

### 6.3 定常分布

システム内の顧客数 $N$：

$$P(N = n) = (1 - \rho)\rho^n, \quad n = 0, 1, 2, \ldots$$

$$E[N] = \frac{\rho}{1-\rho}$$

### 6.4 リトルの公式

$$L = \lambda W$$

- $L$：システム内の平均顧客数
- $W$：平均滞在時間

## 7. 例題

### 例題1：ポアソン過程

1時間あたり平均5人が来店するとき、30分間に2人以上来る確率を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$\lambda = 5$/時間、$t = 0.5$時間より $\lambda t = 2.5$

$$P(N \geq 2) = 1 - P(N = 0) - P(N = 1)$$

$$= 1 - e^{-2.5} - 2.5 e^{-2.5}$$

$$= 1 - 3.5 e^{-2.5} = 1 - 3.5 \times 0.0821 \approx 1 - 0.287 = 0.713$$

**答え：約71.3%**

</details>

---

### 例題2：ブラウン運動

$W(t)$ を標準ブラウン運動とするとき、$\text{Cov}(W(2), W(5))$ を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\text{Cov}(W(s), W(t)) = \min(s, t) = \min(2, 5) = 2$$

**答え：2**

</details>

---

### 例題3：M/M/1待ち行列

到着率 $\lambda = 4$/時間、サービス率 $\mu = 5$/時間のとき、システム内の平均顧客数を求めよ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

利用率：$\rho = \lambda/\mu = 4/5 = 0.8$

$$E[N] = \frac{\rho}{1-\rho} = \frac{0.8}{0.2} = 4$$

**答え：平均4人**

</details>

## 8. 重要公式まとめ

| 項目 | 公式 |
|-----|------|
| ポアソン過程 | $N(t) \sim \text{Poi}(\lambda t)$ |
| 到着間隔 | $T_n \sim \text{Exp}(\lambda)$ |
| 待ち時間 | $S_n \sim \Gamma(n, \lambda)$ |
| ブラウン運動共分散 | $\text{Cov}(W(s), W(t)) = \min(s, t)$ |
| M/M/1平均顧客数 | $E[N] = \rho/(1-\rho)$ |
| リトルの公式 | $L = \lambda W$ |
