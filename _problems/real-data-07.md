## 問題1：売上予測の評価

売上予測モデルの性能を評価する指標として、MAPE（平均絶対パーセント誤差）を計算してください。

| 実績 | 予測 |
|------|------|
| 100 | 95 |
| 200 | 210 |
| 150 | 140 |
| 180 | 190 |

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**MAPE（Mean Absolute Percentage Error）：**

$$MAPE = \frac{1}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right| \times 100\%$$

各誤差率：
- |100-95|/100 = 5%
- |200-210|/200 = 5%
- |150-140|/150 = 6.67%
- |180-190|/180 = 5.56%

$$MAPE = \frac{5 + 5 + 6.67 + 5.56}{4} = 5.56\%$$

**答え：MAPE = 5.56%**

一般に MAPE < 10% は良好な予測。

</details>

## 問題2：価格弾力性

価格を10%上げたら、販売数量が20%減少しました。価格弾力性はいくらですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**価格弾力性（PED）：**

$$PED = \frac{\%需要変化}{\%価格変化} = \frac{-20\%}{10\%} = -2$$

**答え：価格弾力性 = -2（絶対値で2）**

**解釈：**
- |PED| > 1 なので弾力的
- 価格1%上昇で需要2%減少
- 価格上げると売上（価格×数量）は減少する可能性

**ビジネスへの示唆：**
弾力的な商品は値下げで売上増、値上げで売上減になりやすい

</details>

## 問題3：顧客生涯価値（LTV）

月額サブスクリプションの顧客データ：
- 月額料金：1,000円
- 平均継続期間：18ヶ月
- 粗利率：60%

LTVを計算してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**LTV（Life Time Value）：**

$$LTV = 月額料金 \times 継続期間 \times 粗利率$$

$$LTV = 1,000 \times 18 \times 0.6 = 10,800円$$

**答え：LTV = 10,800円**

**活用法：**
- CAC（顧客獲得コスト）と比較
- LTV/CAC > 3 が健全な目安
- セグメント別LTVでマーケティング戦略立案

</details>

## 問題4：NPS（ネットプロモータースコア）

100人の顧客調査結果：
- 推奨者（9-10点）：45人
- 中立者（7-8点）：35人
- 批判者（0-6点）：20人

NPSを計算してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**NPS = 推奨者の割合 - 批判者の割合**

$$NPS = 45\% - 20\% = +25$$

**答え：NPS = +25**

**解釈基準：**
- 0以上：良好
- 50以上：優秀
- 70以上：世界クラス

**注意点：**
- 業界平均との比較が重要
- 経時変化をトラッキング
- セグメント別に分析

</details>

## 問題5：ファネル分析

ECサイトのコンバージョンファネル：
- サイト訪問：10,000人
- 商品ページ閲覧：3,000人
- カート追加：600人
- 購入完了：300人

各ステップの離脱率と全体CVRは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**各ステップの離脱率：**
1. 訪問→商品ページ：(10000-3000)/10000 = 70%
2. 商品→カート：(3000-600)/3000 = 80%
3. カート→購入：(600-300)/600 = 50%

**全体CVR：**
$$CVR = \frac{300}{10000} = 3\%$$

**改善ポイント：**
- 商品ページへの誘導（70%離脱）が最大のボトルネック
- カート離脱（50%）も改善余地あり

</details>

## 問題6：パレート分析

売上データを分析したところ、上位20%の商品が全体売上の78%を占めていました。これは80:20の法則に従っていますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**パレートの法則（80:20の法則）：**
「結果の80%は原因の20%から生じる」

**分析結果：**
- 上位20%の商品 → 売上の78%
- ほぼ80:20の法則に従っている

**ビジネス示唆：**
- 上位商品に注力することで効率的な売上維持
- ただし、残り20%の売上も無視できない
- ロングテール戦略との組み合わせを検討

**注意：**
80:20は経験則であり、正確に80:20になるわけではない

</details>

## 問題7：季節調整

月次売上に明確な季節パターンがあります。前年同月比と季節調整済み前月比のどちらを使うべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**使い分け：**

**前年同月比（YoY）：**
- 季節性を自動的に除去
- 成長トレンドを見るのに適切
- 1年前との比較で変化を評価

**季節調整済み前月比（MoM SA）：**
- 直近の変化をキャッチ
- トレンドの転換点を早期発見
- 政策効果など短期変動の分析

**推奨：両方を併用**
- YoYで長期トレンド確認
- MoM SAで直近の動き確認
- 両者が整合的かチェック

</details>

## 問題8：コホート分析

2024年1月獲得ユーザーの月次リテンション：
- 1ヶ月目：100%（獲得時）
- 2ヶ月目：60%
- 3ヶ月目：45%
- 4ヶ月目：40%

4ヶ月目以降のリテンションが安定すると仮定して、LTVを推定してください（ARPU = 500円/月）。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**累積利用月数の推定：**

リテンション40%で安定と仮定すると、残存ユーザーの平均寿命 = 1/解約率 = 1/0.6 ≈ 1.67ヶ月

**累積リテンション：**
$$1 + 0.6 + 0.45 + 0.40 \times \frac{1}{1-0.40}$$
$$= 1 + 0.6 + 0.45 + 0.67 = 2.72ヶ月相当$$

より正確には：
$$LTV = ARPU \times \sum_{t=1}^{\infty} リテンション率_t$$

**概算LTV：**
$$LTV ≈ 500 \times 2.7 = 1,350円$$

</details>

## 問題9：統計的品質管理

製造ラインの管理図で、7点連続で中心線の上側にあります。これは「管理状態」と言えますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**答え：管理状態とは言えない（異常シグナル）**

**ウェスタン・エレクトリック・ルール：**
1. 1点が3σを超える
2. 連続9点が中心線の同じ側
3. 連続6点が増加または減少
4. **連続7点が中心線の同じ側** ← 今回のケース

7点連続は「ラン」と呼ばれる異常パターン。

**対応：**
- 工程の調査が必要
- 系統的な変化（シフト）の可能性
- 材料、設定、環境の変化をチェック

</details>

## 問題10：統計的有意性と実務的有意性

A/Bテストで、コンバージョン率がAグループ2.0%、Bグループ2.1%で、p=0.03でした。Bを採用すべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**統計的有意性：** あり（p < 0.05）

**実務的有意性：** 要検討

**考慮すべき点：**

1. **効果の大きさ**
   - 0.1ポイントの差（5%の相対的改善）
   - 月間100万訪問なら1,000件の追加CV

2. **信頼区間**
   - 差の95%CIを確認
   - 0.05%〜0.15%なら効果は小さい可能性

3. **実装コスト**
   - Bの実装・維持コストは？
   - コストに見合う効果か？

**答え：効果は統計的に有意だが、ビジネスインパクトとコストを考慮して判断**

</details>

## 問題11：外れ値の扱い

顧客購買データに、平均の10倍の購入額の顧客がいます。どう扱いますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**確認事項：**
1. データ入力ミスでないか
2. 実際の大口顧客か
3. 特殊な一回限りの取引か

**対処方法：**

**1. 削除しない場合**
- 実態を反映した重要データ
- 平均ではなく中央値を使用
- セグメント別に分析

**2. 処理する場合**
- ウィンソライズ（上限設定）
- 対数変換
- 別セグメントとして分析

**推奨：**
- まず除外せず分析
- 外れ値の影響を確認
- ビジネス文脈で判断

</details>

## 問題12：サンプルサイズの決定

新製品のテスト販売で、購入意向率を±5%の精度で推定したい。必要なサンプルサイズは？（信頼水準95%、購入意向は50%と想定）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**比率の推定に必要なサンプルサイズ：**

$$n = \frac{z^2 \times p(1-p)}{E^2}$$

- z = 1.96（95%信頼水準）
- p = 0.5（最も保守的な仮定）
- E = 0.05（許容誤差）

$$n = \frac{1.96^2 \times 0.5 \times 0.5}{0.05^2} = \frac{0.9604}{0.0025} = 384.16$$

**答え：385人以上**

**補足：**
- p=0.5は最大のサンプルサイズを与える
- 実際のpが0.5から離れていれば、より少なくて済む
- 回収率を考慮して多めに配布

</details>
