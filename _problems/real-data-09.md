# 統計分析の実務問題

実際のビジネスや研究で直面する統計の問題です。

## 問題1：異常検知

工場の生産データで異常を検知したい。どのような方法がありますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**統計的手法：**

1. **管理図（シューハート管理図）**
   - UCL/LCL = μ ± 3σ
   - 連続パターンのルール

2. **外れ値検出**
   - IQR法：Q1-1.5×IQR 〜 Q3+1.5×IQR
   - Zスコア：|z| > 3

3. **多変量手法**
   - マハラノビス距離
   - 主成分分析

**考慮点：**
- 偽陽性と偽陰性のバランス
- 時系列の場合は過去のパターンを考慮

</details>

## 問題2：サンプルサイズの決定

新製品のA/Bテストを計画。どのようにサンプルサイズを決めますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**必要な情報：**
1. **期待する効果量**（最小検出したい差）
2. **ベースラインの値**
3. **有意水準**（通常5%）
4. **検出力**（通常80%）

**計算例（コンバージョン率）：**
- ベースライン：5%
- 検出したい差：20%の相対的改善（5%→6%）

$$n = \frac{2 \times (z_{\alpha/2} + z_{\beta})^2 \times p(1-p)}{\delta^2}$$

**ツール：**
- オンライン計算機
- G*Power

</details>

## 問題3：欠損値の処理

データの20%が欠損。どう対処しますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**方法と特徴：**

1. **完全ケース分析**
   - 欠損のある行を除外
   - 欠損がランダムなら問題少
   - サンプルサイズ減少

2. **平均値代入**
   - 単純だが分散を過小評価
   - 推奨されない

3. **多重代入法**
   - 複数の代入値を生成
   - 不確実性を考慮
   - 推奨される方法

4. **最尤法**
   - 欠損を含めてモデル推定

**重要：**
欠損のメカニズム（MCAR, MAR, MNAR）を考慮

</details>

## 問題4：因果推論のデザイン

ランダム化が不可能な場合、因果効果を推定する方法は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**準実験デザイン：**

1. **傾向スコアマッチング**
   - 処置群と対照群を類似させる
   - 観測された共変量で調整

2. **差の差法（DID）**
   - 処置前後と群の交互作用
   - 平行トレンドの仮定が必要

3. **回帰不連続デザイン**
   - カットオフ周辺での効果推定
   - 操作の余地がないことが重要

4. **操作変数法**
   - 内生性の問題を解決
   - 良い操作変数を見つけることが難しい

</details>

## 問題5：多重検定の調整

10個の仮説を同時に検定する研究。どう対処すべきか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**方法：**

1. **ボンフェローニ補正**
   - α' = 0.05/10 = 0.005
   - 保守的すぎる場合あり

2. **Holm法**
   - ボンフェローニより強力
   - 逐次的に閾値を調整

3. **FDR制御（Benjamini-Hochberg）**
   - 偽発見率を制御
   - 多くの検定がある場合に有用

4. **事前に検定数を減らす**
   - 主要な仮説を絞る
   - 探索的分析と確認的分析を分ける

</details>

## 問題6：検出力分析（事後）

実験結果が有意でなかった。検出力が不足していたか確認する方法は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**事後検出力分析：**
観測された効果量で検出力を計算

**問題点：**
- 事後検出力は観測されたp値と直接関係
- p > 0.05 なら事後検出力は必ず < 50%
- 解釈に注意が必要

**より有用なアプローチ：**
- 信頼区間を報告
- 効果量の信頼区間を確認
- 「差がない」ことの根拠には同等性検定

</details>

## 問題7：外部妥当性

臨床試験の結果を一般集団に適用できるか、どう判断しますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**確認ポイント：**

1. **サンプルの代表性**
   - 除外基準は厳しすぎないか
   - 参加者の特性は一般集団と類似か

2. **設定の類似性**
   - 実験環境と実際の環境の違い
   - 介入の実施可能性

3. **効果の修飾要因**
   - サブグループ分析の結果
   - 交互作用の有無

4. **複製研究**
   - 異なる集団での再現性

</details>

## 問題8：ベイズ統計の利点

頻度論的アプローチとベイズ的アプローチの違いは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**頻度論：**
- パラメータは固定値
- 長期的な繰り返しでの性質
- p値、信頼区間

**ベイズ：**
- パラメータは確率分布
- 事前情報を組み込める
- 事後分布、信用区間

**ベイズの利点：**
1. 直感的な確率解釈
2. 事前知識の活用
3. 逐次的な更新が可能
4. 小標本でも使用可能

**課題：**
事前分布の選択が主観的になりうる

</details>

## 問題9：データ品質の確認

分析を始める前に確認すべきデータ品質のポイントは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**チェックリスト：**

1. **欠損値**
   - パターン、割合、メカニズム

2. **外れ値**
   - 入力ミスか実際の値か

3. **データ型**
   - 数値が文字列になっていないか

4. **重複**
   - 同じレコードが複数ないか

5. **整合性**
   - 矛盾するデータがないか
   - 日付の順序は正しいか

6. **分布**
   - 予想と大きく異なっていないか

</details>

## 問題10：結果の報告

統計分析の結果報告で含めるべき要素は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**必須要素：**

1. **記述統計**
   - サンプルサイズ
   - 平均、標準偏差（または中央値、IQR）

2. **検定結果**
   - 検定統計量
   - p値
   - 自由度

3. **効果量**
   - Cohen's d, η², r など
   - 95%信頼区間

4. **図表**
   - 可視化による補完

5. **仮定の確認**
   - 前提条件の検証結果

**APA形式の例：**
t(58) = 2.45, p = .017, d = 0.64, 95% CI [0.12, 1.16]

</details>

## 問題12：機械学習との統合

統計モデルと機械学習モデルの使い分けは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**統計モデルが適切な場合：**
- 解釈性が重要
- 因果推論が目的
- 小標本
- 理論的背景がある

**機械学習が適切な場合：**
- 予測精度が最重要
- 大量のデータ
- 複雑な非線形関係
- 変数選択が難しい

**融合的アプローチ：**
- 機械学習で変数選択、統計モデルで推論
- LASSO回帰（両者の特徴を持つ）

</details>

## 問題13：倫理的考慮

統計分析における倫理的な注意点は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**注意点：**

1. **チェリーピッキングの回避**
   - 都合の良い結果だけを報告しない

2. **誤解を招く可視化の回避**
   - 軸の操作、3Dグラフなど

3. **過大解釈の回避**
   - 相関を因果と混同しない

4. **プライバシー保護**
   - 個人が特定されないように

5. **再現可能性**
   - 方法論の透明な報告

6. **利益相反の開示**
   - 資金源、関係の明示

</details>
