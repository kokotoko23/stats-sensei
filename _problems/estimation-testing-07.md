## 問題1：1標本t検定

ある製品の重量について、10個のサンプルを測定したところ、平均505g、標準偏差8gでした。規格値500gと差があるか検定してください（α=0.05）。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**仮説：**
- H₀: μ = 500
- H₁: μ ≠ 500

**t統計量：**
$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} = \frac{505-500}{8/\sqrt{10}} = \frac{5}{2.53} = 1.98$$

**判定：**
- df = 9, t₀.₀₂₅,₉ = 2.262
- |t| = 1.98 < 2.262

**答え：有意水準5%で差があるとは言えない**

</details>

## 問題2：対応のあるt検定

6人のダイエット前後の体重（kg）：

| 被験者 | 前 | 後 |
|-------|----|----|
| A | 70 | 67 |
| B | 65 | 64 |
| C | 80 | 76 |
| D | 75 | 74 |
| E | 68 | 66 |
| F | 72 | 70 |

ダイエットは効果があったか？（α=0.05）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**差の計算：**
d = 前 - 後 = 3, 1, 4, 1, 2, 2

**差の統計量：**
- d̄ = 13/6 = 2.17
- sd = 1.17

**t統計量：**
$$t = \frac{\bar{d}}{s_d/\sqrt{n}} = \frac{2.17}{1.17/\sqrt{6}} = \frac{2.17}{0.48} = 4.52$$

**判定：**
- df = 5, t₀.₀₂₅,₅ = 2.571
- t = 4.52 > 2.571

**答え：ダイエットは有意に効果があった**

</details>

## 問題3：2標本t検定（等分散）

2つのグループの成績：
- グループA：n=15, x̄=75, s=10
- グループB：n=15, x̄=70, s=12

成績に差があるか？（等分散を仮定、α=0.05）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**プールした分散：**
$$s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}$$
$$= \frac{14 \times 100 + 14 \times 144}{28} = \frac{3416}{28} = 122$$

**t統計量：**
$$t = \frac{\bar{x}_1 - \bar{x}_2}{s_p\sqrt{1/n_1 + 1/n_2}} = \frac{75-70}{11.05 \times \sqrt{2/15}}$$
$$= \frac{5}{4.03} = 1.24$$

**判定：**
- df = 28, t₀.₀₂₅,₂₈ ≈ 2.048
- |t| = 1.24 < 2.048

**答え：差があるとは言えない**

</details>

## 問題4：Welchのt検定

等分散を仮定しない場合の2標本t検定。データは前問と同じ。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**Welchのt統計量：**
$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$$
$$= \frac{75-70}{\sqrt{100/15 + 144/15}} = \frac{5}{\sqrt{16.27}} = \frac{5}{4.03} = 1.24$$

**Welch-Satterthwaiteの自由度：**
$$df = \frac{(s_1^2/n_1 + s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}}$$

計算すると df ≈ 27.1

**答え：結果はほぼ同じ（差があるとは言えない）**

</details>

## 問題5：比率の検定

製品の不良率が3%以下と主張されている。200個中10個が不良だった。主張は正しいか？（α=0.05、片側）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**仮説：**
- H₀: p ≤ 0.03
- H₁: p > 0.03

**標本比率：**
p̂ = 10/200 = 0.05

**z統計量：**
$$z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}} = \frac{0.05-0.03}{\sqrt{0.03 \times 0.97/200}}$$
$$= \frac{0.02}{0.0121} = 1.65$$

**判定：**
- z₀.₀₅ = 1.645
- z = 1.65 > 1.645（わずかに超える）

**答え：有意水準5%で主張は棄却（不良率は3%を超える可能性）**

</details>

## 問題6：カイ二乗適合度検定

サイコロを60回振った結果：

| 目 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 度数 | 8 | 12 | 15 | 7 | 10 | 8 |

このサイコロは公正か？（α=0.05）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

期待度数 = 60/6 = 10（各目）

**カイ二乗統計量：**
$$\chi^2 = \sum \frac{(O-E)^2}{E}$$
$$= \frac{(8-10)^2}{10} + \frac{(12-10)^2}{10} + \frac{(15-10)^2}{10} + \frac{(7-10)^2}{10} + \frac{(10-10)^2}{10} + \frac{(8-10)^2}{10}$$
$$= 0.4 + 0.4 + 2.5 + 0.9 + 0 + 0.4 = 4.6$$

**判定：**
- df = 6-1 = 5
- χ²₀.₀₅,₅ = 11.07
- χ² = 4.6 < 11.07

**答え：公正でないとは言えない**

</details>

## 問題7：カイ二乗独立性検定

喫煙習慣と肺疾患の関係：

| | 肺疾患あり | 肺疾患なし |
|---|---|---|
| 喫煙者 | 40 | 60 |
| 非喫煙者 | 20 | 80 |

関連があるか？（α=0.05）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**期待度数の計算：**
- 喫煙×疾患あり：100×60/200 = 30
- 喫煙×疾患なし：100×140/200 = 70
- 非喫煙×疾患あり：100×60/200 = 30
- 非喫煙×疾患なし：100×140/200 = 70

**カイ二乗統計量：**
$$\chi^2 = \frac{(40-30)^2}{30} + \frac{(60-70)^2}{70} + \frac{(20-30)^2}{30} + \frac{(80-70)^2}{70}$$
$$= 3.33 + 1.43 + 3.33 + 1.43 = 9.52$$

**判定：**
- df = (2-1)(2-1) = 1
- χ²₀.₀₅,₁ = 3.84
- χ² = 9.52 > 3.84

**答え：喫煙と肺疾患には関連がある**

</details>

## 問題8：マクネマー検定

同じ100人に対して、広告前後で製品認知度を調査：

| | 後：認知 | 後：非認知 |
|---|---|---|
| 前：認知 | 30 | 5 |
| 前：非認知 | 25 | 40 |

広告は効果があったか？（α=0.05）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**マクネマー検定：**
変化したペア（b=5, c=25）に注目

$$\chi^2 = \frac{(|b-c|-1)^2}{b+c} = \frac{(|5-25|-1)^2}{30} = \frac{361}{30} = 12.03$$

**判定：**
- χ²₀.₀₅,₁ = 3.84
- χ² = 12.03 > 3.84

**答え：広告は認知度向上に効果があった**

</details>

## 問題9：F検定（等分散性）

2群の分散が等しいか検定：
- グループA：s₁² = 16, n₁ = 21
- グループB：s₂² = 9, n₂ = 16

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**F統計量：**
$$F = \frac{s_1^2}{s_2^2} = \frac{16}{9} = 1.78$$

**判定：**
- df₁ = 20, df₂ = 15
- F₀.₀₂₅,₂₀,₁₅ ≈ 2.76
- F = 1.78 < 2.76

**答え：等分散の仮定は棄却されない**

</details>

## 問題10：符号検定

新薬が旧薬より効果があるか。15人中12人で新薬が優位だった。（α=0.05、片側）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**符号検定（二項検定）：**
- H₀: p = 0.5（優劣は半々）
- H₁: p > 0.5

$$P(X \geq 12) = \sum_{k=12}^{15} \binom{15}{k} 0.5^{15}$$
$$= \binom{15}{12} + \binom{15}{13} + \binom{15}{14} + \binom{15}{15}$$
$$= (455 + 105 + 15 + 1) \times 0.5^{15} = 0.0176$$

**判定：**
p = 0.0176 < 0.05

**答え：新薬が有意に優位**

</details>

## 問題11：ウィルコクソン順位和検定

2群の非正規データ：
- A群：3, 5, 7, 8, 9（n=5）
- B群：1, 2, 4, 6, 10（n=5）

差があるか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**順位付け：**
1(B), 2(B), 3(A), 4(B), 5(A), 6(B), 7(A), 8(A), 9(A), 10(B)

**A群の順位和：**
W = 3 + 5 + 7 + 8 + 9 = 32

**期待値と分散：**
- E[W] = n₁(n₁+n₂+1)/2 = 5×11/2 = 27.5
- Var(W) = n₁n₂(n₁+n₂+1)/12 = 22.92

**z近似：**
$$z = \frac{32 - 27.5}{\sqrt{22.92}} = \frac{4.5}{4.79} = 0.94$$

**答え：差があるとは言えない（|z|<1.96）**

</details>

## 問題12：検出力分析

効果量d=0.5を検出するのに必要なサンプルサイズは？（α=0.05、検出力80%、両側）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**公式：**
$$n = 2 \times \left(\frac{z_{1-\alpha/2} + z_{1-\beta}}{d}\right)^2$$

- z₀.₉₇₅ = 1.96
- z₀.₈ = 0.84
- d = 0.5

$$n = 2 \times \left(\frac{1.96 + 0.84}{0.5}\right)^2 = 2 \times (5.6)^2 = 62.7$$

**答え：各群約64人（合計128人）**

</details>
