## 問題1：標準正規分布表の読み方

標準正規分布で、以下の確率を求めてください。

(1) P(Z < 1.5)
(2) P(Z > 2.0)
(3) P(-1.96 < Z < 1.96)

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) P(Z < 1.5)**
標準正規分布表より：**0.9332**

**(2) P(Z > 2.0)**
P(Z > 2.0) = 1 - P(Z < 2.0) = 1 - 0.9772 = **0.0228**

**(3) P(-1.96 < Z < 1.96)**
P(Z < 1.96) - P(Z < -1.96) = 0.9750 - 0.0250 = **0.95**

</details>

## 問題2：z値の逆算

標準正規分布で、以下の条件を満たすzを求めてください。

(1) P(Z < z) = 0.90
(2) P(Z > z) = 0.05
(3) P(-z < Z < z) = 0.99

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) P(Z < z) = 0.90**
z = **1.28**

**(2) P(Z > z) = 0.05**
P(Z < z) = 0.95 より z = **1.645**

**(3) P(-z < Z < z) = 0.99**
両側で0.005ずつ → z = **2.576**

</details>

## 問題3：正規分布の標準化

X〜N(100, 225)のとき、P(85 < X < 115)は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

σ = √225 = 15

$$z_1 = \frac{85 - 100}{15} = -1.0$$

$$z_2 = \frac{115 - 100}{15} = 1.0$$

P(-1 < Z < 1) = 0.8413 - 0.1587 = **0.6826**

**答え：約68.3%**

</details>

## 問題4：指数分布

機械の故障までの時間が平均500時間の指数分布に従います。1000時間故障しない確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

λ = 1/500 = 0.002

$$P(X > 1000) = e^{-\lambda \times 1000} = e^{-2} \approx 0.135$$

**答え：約13.5%**

</details>

## 問題5：指数分布のメモリレス性

問題4の機械が既に300時間稼働しています。さらに500時間故障しない確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

指数分布のメモリレス性より：

$$P(X > 800 | X > 300) = P(X > 500) = e^{-0.002 \times 500} = e^{-1} \approx 0.368$$

**答え：約36.8%**

過去の稼働時間に関係なく、あと500時間故障しない確率は常に同じ。

</details>

## 問題6：一様分布

バスが0分から30分の間で一様に到着します。10分以上待つ確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

X〜U(0, 30)

$$P(X > 10) = \frac{30 - 10}{30 - 0} = \frac{20}{30} = \frac{2}{3}$$

**答え：2/3（約66.7%）**

</details>

## 問題7：正規分布の線形結合

X〜N(50, 16)、Y〜N(30, 9)が独立のとき、2X - 3Yの分布は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**期待値：**
$$E[2X - 3Y] = 2 \times 50 - 3 \times 30 = 100 - 90 = 10$$

**分散：**
$$Var(2X - 3Y) = 4 \times 16 + 9 \times 9 = 64 + 81 = 145$$

**答え：2X - 3Y 〜 N(10, 145)**

標準偏差 = √145 ≈ 12.04

</details>

## 問題11：標本平均の分布

母集団N(60, 100)から25個のサンプルを抽出したとき、標本平均が65以上になる確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\bar{X} \sim N\left(60, \frac{100}{25}\right) = N(60, 4)$$

標準誤差 = 2

$$z = \frac{65 - 60}{2} = 2.5$$

P(Z > 2.5) ≈ **0.0062**

**答え：約0.6%**

</details>

## 問題12：総合問題

製品Aと製品Bの重量が独立に以下の正規分布に従います：
- A：N(100, 25)
- B：N(90, 16)

AとBを1個ずつ選んだとき、Aの重量がBより少なくとも15g重い確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

D = A - B を考える

$$E[D] = 100 - 90 = 10$$
$$Var(D) = 25 + 16 = 41$$
$$\sigma_D = \sqrt{41} \approx 6.40$$

P(D ≥ 15)を求める：

$$z = \frac{15 - 10}{6.40} = 0.78$$

P(Z > 0.78) ≈ 0.218

**答え：約21.8%**

</details>
