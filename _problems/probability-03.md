# 確率の計算問題（発展編）

条件付き確率とベイズの定理を中心とした発展的な問題です。

---

## 問題1：条件付き確率の基本

袋の中に赤玉3個、白玉7個が入っています。1個取り出して色を確認せずに脇に置き、2個目を取り出したところ白玉でした。最初に取り出した玉が赤である確率を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

ベイズの定理を使用：

$P(1個目が赤 | 2個目が白)$

**事前確率：**
- $P(1個目が赤) = \frac{3}{10}$
- $P(1個目が白) = \frac{7}{10}$

**尤度：**
- $P(2個目が白 | 1個目が赤) = \frac{7}{9}$
- $P(2個目が白 | 1個目が白) = \frac{6}{9}$

**2個目が白の確率：**
$$P(2個目が白) = \frac{3}{10} \times \frac{7}{9} + \frac{7}{10} \times \frac{6}{9} = \frac{21}{90} + \frac{42}{90} = \frac{63}{90} = \frac{7}{10}$$

**ベイズの定理：**
$$P(1個目が赤 | 2個目が白) = \frac{\frac{3}{10} \times \frac{7}{9}}{\frac{7}{10}} = \frac{\frac{21}{90}}{\frac{7}{10}} = \frac{21}{90} \times \frac{10}{7} = \frac{1}{3}$$

**答え：1/3**

</details>

## 問題2：独立性の判定

サイコロを2回振ります。以下の事象は独立ですか？

(1) A：1回目が偶数、B：2回目が偶数
(2) A：1回目が6、B：2回の合計が7以上
(3) A：1回目が3以下、B：2回の合計が8以上

<details markdown="1">
<summary>解答を見る</summary>

### 解答

独立の条件：$P(A \cap B) = P(A) \times P(B)$

**(1) 1回目が偶数、2回目が偶数**

- $P(A) = \frac{1}{2}$、$P(B) = \frac{1}{2}$
- $P(A \cap B) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$（別々の試行なので）
- $P(A) \times P(B) = \frac{1}{4}$ ✓

**答え：独立**

**(2) 1回目が6、合計が7以上**

- $P(A) = \frac{1}{6}$
- $P(B) = P(合計7以上) = \frac{21}{36} = \frac{7}{12}$
- $P(A \cap B) = P(1回目が6かつ合計7以上) = \frac{6}{36} = \frac{1}{6}$（1回目が6なら2回目は何でもOK）
- $P(A) \times P(B) = \frac{1}{6} \times \frac{7}{12} = \frac{7}{72}$

$\frac{1}{6} = \frac{12}{72} \neq \frac{7}{72}$

**答え：独立でない**

**(3) 1回目が3以下、合計が8以上**

- $P(A) = \frac{1}{2}$
- $P(B) = \frac{15}{36} = \frac{5}{12}$
- $P(A \cap B)$：1回目が1,2,3のとき合計8以上になる場合を数える
  - 1回目=1：2回目=なし（最大7）→ 0通り
  - 1回目=2：2回目=6 → 1通り
  - 1回目=3：2回目=5,6 → 2通り
  - 合計3通り → $\frac{3}{36} = \frac{1}{12}$
- $P(A) \times P(B) = \frac{1}{2} \times \frac{5}{12} = \frac{5}{24}$

$\frac{1}{12} = \frac{2}{24} \neq \frac{5}{24}$

**答え：独立でない**

</details>

## 問題3：全確率の定理

3つの工場A, B, Cがある製品を生産しています。生産比率と不良率は：

| 工場 | 生産比率 | 不良率 |
|------|---------|--------|
| A | 50% | 2% |
| B | 30% | 3% |
| C | 20% | 5% |

(1) 全製品の不良率
(2) 不良品が見つかったとき、工場Aで作られた確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 全体の不良率**

全確率の定理：
$$P(不良) = P(A) \times P(不良|A) + P(B) \times P(不良|B) + P(C) \times P(不良|C)$$

$$= 0.5 \times 0.02 + 0.3 \times 0.03 + 0.2 \times 0.05$$
$$= 0.01 + 0.009 + 0.01 = 0.029$$

**答え：2.9%**

**(2) ベイズの定理**

$$P(A|不良) = \frac{P(A) \times P(不良|A)}{P(不良)} = \frac{0.5 \times 0.02}{0.029} = \frac{0.01}{0.029} \approx 0.345$$

**答え：約34.5%**

</details>

## 問題4：検査の精度

ある病気の有病率は1%です。検査の感度（病気の人が陽性になる確率）は95%、特異度（健康な人が陰性になる確率）は90%です。

(1) 陽性と判定された人が実際に病気である確率
(2) この検査結果をどう解釈すべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 陽性的中率**

- $P(病気) = 0.01$、$P(健康) = 0.99$
- $P(陽性|病気) = 0.95$（感度）
- $P(陽性|健康) = 1 - 0.90 = 0.10$（偽陽性率）

$$P(陽性) = 0.01 \times 0.95 + 0.99 \times 0.10 = 0.0095 + 0.099 = 0.1085$$

$$P(病気|陽性) = \frac{0.01 \times 0.95}{0.1085} = \frac{0.0095}{0.1085} \approx 0.088$$

**答え：約8.8%**

**(2) 解釈**

陽性と判定されても、実際に病気である確率は約9%に過ぎません。

**理由：**
- 有病率が低い（1%）ため、健康な人の方が圧倒的に多い
- 健康な人の10%が偽陽性 → 多くの偽陽性が発生
- 「検査精度が高い」と「陽性的中率が高い」は別の概念

**対策：**
- 陽性の場合は再検査を行う
- 事前確率を上げる（症状のある人だけ検査するなど）

</details>

## 問題5：誕生日問題

n人のグループで、少なくとも2人が同じ誕生日である確率が50%を超えるのは、n が最小でいくつのときですか？（1年=365日、うるう年は考えない）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

全員の誕生日が異なる確率を計算：

$$P(全員異なる) = \frac{365}{365} \times \frac{364}{365} \times \frac{363}{365} \times \cdots \times \frac{365-n+1}{365}$$

$$= \frac{365!}{(365-n)! \times 365^n}$$

少なくとも2人が同じ：$P(同じ) = 1 - P(全員異なる) > 0.5$

計算結果：
- n=22: P ≈ 0.476
- n=23: P ≈ 0.507
- n=50: P ≈ 0.970

**答え：n = 23人**

23人いれば、同じ誕生日のペアがいる確率が50%を超えます。これは直感に反する結果で、「誕生日のパラドックス」と呼ばれます。

</details>

## 問題6：くじ引きの公平性

10本のくじの中に当たりが2本あります。A, B, Cの順にくじを引きます（引いたくじは戻さない）。

(1) Aが当たる確率
(2) Bが当たる確率
(3) Cが当たる確率

くじを引く順番で有利不利はありますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) Aが当たる確率**

$$P(A当たり) = \frac{2}{10} = 0.2$$

**(2) Bが当たる確率**

場合分け：
- Aが当たり → Bは残り9本中1本当たり：$\frac{2}{10} \times \frac{1}{9}$
- Aがはずれ → Bは残り9本中2本当たり：$\frac{8}{10} \times \frac{2}{9}$

$$P(B当たり) = \frac{2}{10} \times \frac{1}{9} + \frac{8}{10} \times \frac{2}{9} = \frac{2}{90} + \frac{16}{90} = \frac{18}{90} = 0.2$$

**(3) Cが当たる確率**

同様に計算すると：

$$P(C当たり) = 0.2$$

**答え：全員の当たる確率は等しく0.2（20%）**

**結論：くじを引く順番による有利不利はない**

</details>

## 問題7：条件付き期待値

サイコロを振り、出た目の数だけコインを投げます。表が出たコインの枚数の期待値を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

条件付き期待値の公式：$E[Y] = E[E[Y|X]]$

サイコロの目がkのとき、コインをk回投げて表が出る回数の期待値：
$$E[Y|X=k] = \frac{k}{2}$$

$$E[Y] = \sum_{k=1}^{6} P(X=k) \times E[Y|X=k] = \sum_{k=1}^{6} \frac{1}{6} \times \frac{k}{2}$$

$$= \frac{1}{12} \times (1 + 2 + 3 + 4 + 5 + 6) = \frac{1}{12} \times 21 = 1.75$$

**答え：1.75枚**

</details>

## 問題8：包除原理

1から100までの整数のうち、2または3または5で割り切れる数はいくつありますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

包除原理：$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$

- |A| = 2の倍数 = 50個
- |B| = 3の倍数 = 33個
- |C| = 5の倍数 = 20個
- |A∩B| = 6の倍数 = 16個
- |B∩C| = 15の倍数 = 6個
- |C∩A| = 10の倍数 = 10個
- |A∩B∩C| = 30の倍数 = 3個

$$|A \cup B \cup C| = 50 + 33 + 20 - 16 - 6 - 10 + 3 = 74$$

**答え：74個**

</details>

## 問題9：ギャンブラーの誤謬

コインを10回投げて、すべて表が出ました。次に投げたとき、裏が出る確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**答え：1/2（50%）**

公正なコインであれば、過去の結果に関係なく、次の投げの確率は常に1/2です。

**ギャンブラーの誤謬：**
「表が続いたから、そろそろ裏が出るはず」と考えるのは誤りです。

- 各試行は独立
- コインには記憶がない
- 過去の結果は将来に影響しない

**注意点：**
もし本当に10回連続で表が出たなら、「コインが公正でない」可能性を疑うべきです。

公正なコインで10回連続表の確率：$(0.5)^{10} = \frac{1}{1024} \approx 0.1\%$

</details>

## 問題10：確率の乗法定理の応用

5枚のカード（1,2,3,4,5）から3枚を順に引きます（戻さない）。

(1) 引いた順に1,2,3となる確率
(2) 引いた3枚が1,2,3である確率（順序は問わない）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 順に1,2,3**

$$P(1,2,3の順) = \frac{1}{5} \times \frac{1}{4} \times \frac{1}{3} = \frac{1}{60}$$

**答え：1/60**

**(2) 1,2,3が出る（順序自由）**

3枚を選ぶ組み合わせ数：$\binom{5}{3} = 10$

1,2,3の組み合わせは1通り

$$P = \frac{1}{10}$$

または、(1)の結果を使って：
1,2,3の並び方は3! = 6通り

$$P = \frac{1}{60} \times 6 = \frac{1}{10}$$

**答え：1/10**

</details>

## 問題11：条件付き確率の連鎖

3つの箱があります。
- 箱1：赤2個、白3個
- 箱2：赤3個、白2個
- 箱3：赤4個、白1個

サイコロを振り、1-2なら箱1、3-4なら箱2、5-6なら箱3から玉を1個取り出します。赤玉が出たとき、箱3から取り出された確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

ベイズの定理を適用：

**事前確率：** 各箱を選ぶ確率はすべて1/3

**尤度（赤を引く確率）：**
- $P(赤|箱1) = \frac{2}{5}$
- $P(赤|箱2) = \frac{3}{5}$
- $P(赤|箱3) = \frac{4}{5}$

**赤が出る確率：**
$$P(赤) = \frac{1}{3} \times \frac{2}{5} + \frac{1}{3} \times \frac{3}{5} + \frac{1}{3} \times \frac{4}{5} = \frac{1}{3} \times \frac{9}{5} = \frac{3}{5}$$

**ベイズの定理：**
$$P(箱3|赤) = \frac{P(箱3) \times P(赤|箱3)}{P(赤)} = \frac{\frac{1}{3} \times \frac{4}{5}}{\frac{3}{5}} = \frac{\frac{4}{15}}{\frac{3}{5}} = \frac{4}{15} \times \frac{5}{3} = \frac{4}{9}$$

**答え：4/9**

</details>

## 問題12：複合問題

ある地域で、晴れの日の翌日も晴れる確率は0.8、雨の日の翌日も雨が続く確率は0.6です。今日が晴れのとき、3日後に晴れている確率を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

マルコフ連鎖の問題です。

遷移確率：
- 晴→晴：0.8、晴→雨：0.2
- 雨→雨：0.6、雨→晴：0.4

**1日後：**
- P(晴) = 0.8
- P(雨) = 0.2

**2日後：**
- P(晴) = 0.8×0.8 + 0.2×0.4 = 0.64 + 0.08 = 0.72
- P(雨) = 0.8×0.2 + 0.2×0.6 = 0.16 + 0.12 = 0.28

**3日後：**
- P(晴) = 0.72×0.8 + 0.28×0.4 = 0.576 + 0.112 = 0.688

**答え：0.688（約68.8%）**

</details>
