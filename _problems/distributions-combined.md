# 確率分布の総合問題

二項分布、ポアソン分布、正規分布などを比較・応用する総合問題です。

---

## 問題1：分布の選択

以下の状況に最も適した確率分布を選び、理由を説明してください。

(a) 1日にコンビニに来店する客数
(b) 100回コインを投げたときの表の回数
(c) 成人男性の身長
(d) 製品が故障するまでの時間

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(a) コンビニの来店客数 → ポアソン分布**

理由：
- 単位時間あたりの発生回数
- 各来店は独立
- 平均発生率が一定

**(b) コイン投げの表の回数 → 二項分布**

理由：
- 固定回数の試行
- 各試行は独立
- 成功確率が一定

**(c) 成人男性の身長 → 正規分布**

理由：
- 連続変数
- 多くの要因の累積効果
- 平均付近に集中、左右対称

**(d) 故障までの時間 → 指数分布**

理由：
- 連続変数（時間）
- メモリレス性（故障率一定）
- ポアソン過程の待ち時間

</details>

## 問題2：二項分布とポアソン分布の比較

不良率1%の製品を200個検査します。

(1) 不良品が3個以上見つかる確率（二項分布で計算）
(2) 同じ確率をポアソン近似で計算
(3) 両者を比較してください

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 二項分布**

n=200, p=0.01

$$P(X \geq 3) = 1 - P(X \leq 2)$$

$$P(X=0) = (0.99)^{200} \approx 0.134$$
$$P(X=1) = 200 \times 0.01 \times (0.99)^{199} \approx 0.271$$
$$P(X=2) = \binom{200}{2}(0.01)^2(0.99)^{198} \approx 0.273$$

$$P(X \geq 3) \approx 1 - 0.678 = 0.322$$

**(2) ポアソン近似**

$\lambda = np = 200 \times 0.01 = 2$

$$P(X=0) = e^{-2} \approx 0.135$$
$$P(X=1) = 2e^{-2} \approx 0.271$$
$$P(X=2) = \frac{4e^{-2}}{2} \approx 0.271$$

$$P(X \geq 3) \approx 1 - 0.677 = 0.323$$

**(3) 比較**

二項分布：0.322、ポアソン近似：0.323

差は0.1%未満で、非常に良い近似。n≥20かつp≤0.05なら近似可能。

</details>

## 問題3：正規近似と連続性補正

二項分布B(100, 0.4)に従うXについて、P(35 ≤ X ≤ 45)を：

(1) 正規近似（補正なし）
(2) 正規近似（連続性補正あり）
で求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$\mu = np = 40$、$\sigma = \sqrt{np(1-p)} = \sqrt{24} \approx 4.90$

**(1) 補正なし**

$$z_1 = \frac{35 - 40}{4.90} \approx -1.02$$
$$z_2 = \frac{45 - 40}{4.90} \approx 1.02$$

$P(-1.02 \leq Z \leq 1.02) \approx 0.692$

**(2) 連続性補正あり**

離散を連続に：P(35 ≤ X ≤ 45) → P(34.5 ≤ X ≤ 45.5)

$$z_1 = \frac{34.5 - 40}{4.90} \approx -1.12$$
$$z_2 = \frac{45.5 - 40}{4.90} \approx 1.12$$

$P(-1.12 \leq Z \leq 1.12) \approx 0.737$

**真の値（二項分布）：約0.729**

連続性補正ありの方が精度が高い。

</details>

## 問題4：中心極限定理の応用

一様分布U(0, 12)から100個のサンプルを抽出します。

(1) 標本平均の分布
(2) 標本平均が5.5以下になる確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

一様分布U(0, 12)の特性：
- $\mu = 6$
- $\sigma^2 = \frac{12^2}{12} = 12$、$\sigma = \sqrt{12} \approx 3.46$

**(1) 標本平均の分布**

中心極限定理より：
$$\bar{X} \sim N\left(6, \frac{12}{100}\right) = N(6, 0.12)$$

標準誤差 = $\frac{3.46}{\sqrt{100}} = 0.346$

**(2) P(X̄ ≤ 5.5)**

$$z = \frac{5.5 - 6}{0.346} \approx -1.45$$

$P(Z \leq -1.45) \approx 0.074$

**答え：約7.4%**

</details>

## 問題5：混合分布

2つの機械AとBが製品を生産します。
- 機械A（全体の60%）：平均100g、標準偏差5g
- 機械B（全体の40%）：平均105g、標準偏差8g

製品全体の平均と分散を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**全体の平均：**
$$E[X] = 0.6 \times 100 + 0.4 \times 105 = 60 + 42 = 102$$

**全体の分散：**
$$Var(X) = E[X^2] - (E[X])^2$$

$$E[X^2] = 0.6 \times (100^2 + 5^2) + 0.4 \times (105^2 + 8^2)$$
$$= 0.6 \times 10025 + 0.4 \times 11089 = 6015 + 4435.6 = 10450.6$$

$$Var(X) = 10450.6 - 102^2 = 10450.6 - 10404 = 46.6$$

**答え：平均102g、分散46.6、標準偏差約6.8g**

</details>

## 問題6：確率分布のモーメント

ポアソン分布Poi(λ)について：

(1) E[X(X-1)]を求めてください
(2) これを使ってVar(X)=λを示してください

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) E[X(X-1)]**

$$E[X(X-1)] = \sum_{k=0}^{\infty} k(k-1) \frac{\lambda^k e^{-\lambda}}{k!}$$

$k=0,1$の項は0なので：
$$= \sum_{k=2}^{\infty} k(k-1) \frac{\lambda^k e^{-\lambda}}{k!} = \sum_{k=2}^{\infty} \frac{\lambda^k e^{-\lambda}}{(k-2)!}$$

$m = k-2$と置換：
$$= \lambda^2 \sum_{m=0}^{\infty} \frac{\lambda^m e^{-\lambda}}{m!} = \lambda^2 \times 1 = \lambda^2$$

**(2) 分散の導出**

$$E[X(X-1)] = E[X^2] - E[X] = \lambda^2$$

$$E[X^2] = \lambda^2 + E[X] = \lambda^2 + \lambda$$

$$Var(X) = E[X^2] - (E[X])^2 = \lambda^2 + \lambda - \lambda^2 = \lambda$$

**証明完了：Var(X) = λ**

</details>

## 問題7：複合ポアソン過程

店舗Aには1時間に平均5人、店舗Bには1時間に平均3人の客が来ます（独立）。

(1) 両店合わせて1時間に来る客数の分布
(2) 両店の客数の差が2以上になる確率（近似）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 合計の分布**

独立なポアソン分布の和はポアソン分布：
$$X_A + X_B \sim Poi(5 + 3) = Poi(8)$$

**答え：ポアソン分布（λ=8）**

**(2) 差が2以上**

$D = X_A - X_B$ の分布を正規近似：

$E[D] = 5 - 3 = 2$
$Var(D) = Var(X_A) + Var(X_B) = 5 + 3 = 8$
$\sigma_D = \sqrt{8} \approx 2.83$

$P(|D| \geq 2) = P(D \geq 2) + P(D \leq -2)$

$$P(D \geq 2) = P\left(Z \geq \frac{2-2}{2.83}\right) = P(Z \geq 0) = 0.5$$

$$P(D \leq -2) = P\left(Z \leq \frac{-2-2}{2.83}\right) = P(Z \leq -1.41) \approx 0.079$$

$$P(|D| \geq 2) \approx 0.5 + 0.079 = 0.579$$

**答え：約57.9%**

</details>

## 問題8：変数変換

X〜N(0, 1)のとき、Y = X²の分布（カイ二乗分布）の期待値と分散を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**E[Y] = E[X²]：**

標準正規分布では $E[X] = 0$、$Var(X) = 1$

$$E[X^2] = Var(X) + (E[X])^2 = 1 + 0 = 1$$

**E[Y²] = E[X⁴]：**

標準正規分布のモーメント：$E[X^4] = 3$

**Var(Y)：**
$$Var(Y) = E[Y^2] - (E[Y])^2 = 3 - 1 = 2$$

**答え：E[Y] = 1、Var(Y) = 2**

これは自由度1のカイ二乗分布$\chi^2(1)$の特性と一致。
一般に$\chi^2(k)$ではE = k、Var = 2k

</details>

## 問題9：信頼性理論

システムが3つの部品で構成され、各部品の故障時間は指数分布Exp(λ)に従います（独立）。

(1) 直列システム（全部品が動作必要）の故障時間の分布
(2) 並列システム（1つでも動作すればOK）の平均寿命

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 直列システム**

$T = \min(T_1, T_2, T_3)$

指数分布の最小値は指数分布：
$$P(T > t) = P(T_1 > t)P(T_2 > t)P(T_3 > t) = e^{-\lambda t} \times e^{-\lambda t} \times e^{-\lambda t} = e^{-3\lambda t}$$

**答え：Exp(3λ)（故障率が3倍）**

**(2) 並列システム**

$T = \max(T_1, T_2, T_3)$

$$P(T \leq t) = P(T_1 \leq t)P(T_2 \leq t)P(T_3 \leq t) = (1 - e^{-\lambda t})^3$$

期待値：
$$E[T] = \int_0^\infty P(T > t) dt = \int_0^\infty [1 - (1-e^{-\lambda t})^3] dt$$

計算すると：
$$E[T] = \frac{1}{\lambda}\left(1 + \frac{1}{2} + \frac{1}{3}\right) = \frac{11}{6\lambda}$$

**答え：11/(6λ)**

（単独の平均寿命1/λの約1.83倍）

</details>

## 問題10：順序統計量

一様分布U(0, 1)から5個のサンプルを抽出します。中央値（3番目に大きい値）の期待値を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

一様分布U(0,1)からn個抽出したとき、k番目に小さい値$X_{(k)}$の期待値：

$$E[X_{(k)}] = \frac{k}{n+1}$$

n=5、k=3（中央値）：

$$E[X_{(3)}] = \frac{3}{6} = 0.5$$

**答え：0.5**

一般に、一様分布からの順序統計量は等間隔に配置され、対称性から中央値の期待値は0.5となる。

</details>

## 問題11：分布の識別

以下のデータの特徴から、適切な分布を推定してください。

| 統計量 | 値 |
|--------|-----|
| 平均 | 5.2 |
| 分散 | 5.0 |
| 歪度 | 0.44 |
| 尖度 | 3.2 |

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**分析：**

1. **平均 ≈ 分散**：ポアソン分布の特徴（E = Var = λ）
2. **正の歪度**：右に裾が長い（ポアソンと一致）
3. **尖度約3**：正規分布と同程度（λが大きいポアソンは正規に近い）

**結論：ポアソン分布 Poi(5)が最も適切**

検証：
- Poi(λ)の歪度 = $1/\sqrt{\lambda} = 1/\sqrt{5} \approx 0.45$ ✓
- Poi(λ)の尖度 = $3 + 1/\lambda = 3.2$ ✓

</details>

## 問題12：分布の比較問題

顧客のクレーム数について、部門Aは平均5件/日、部門Bは平均3件/日（ともにポアソン分布）。1週間（5日）の合計クレーム数がAよりBの方が多くなる確率を正規近似で求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

1週間の合計：
- 部門A：$X_A \sim Poi(25)$
- 部門B：$X_B \sim Poi(15)$

$D = X_B - X_A$ を考える：

$E[D] = 15 - 25 = -10$
$Var(D) = 15 + 25 = 40$
$\sigma_D = \sqrt{40} \approx 6.32$

正規近似：$D \sim N(-10, 40)$

$$P(D > 0) = P\left(Z > \frac{0-(-10)}{6.32}\right) = P(Z > 1.58) \approx 0.057$$

**答え：約5.7%**

</details>
