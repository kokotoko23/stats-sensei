# 推定と検定の総合演習

推定と検定の理解を深める総合的な問題です。

---

## 問題1：点推定量の性質

良い推定量の3つの性質（不偏性、一致性、効率性）を説明してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**1. 不偏性（Unbiasedness）**
- E[θ̂] = θ
- 推定量の期待値が真の値に等しい
- 例：標本平均 x̄ は母平均 μ の不偏推定量

**2. 一致性（Consistency）**
- n → ∞ で θ̂ → θ（確率収束）
- サンプルサイズが大きくなると真の値に近づく

**3. 効率性（Efficiency）**
- 分散が最小
- 同じ不偏推定量の中で最も精度が高い
- クラメール・ラオの下限に達する推定量

</details>

## 問題2：最尤推定

コインを10回投げて7回表が出ました。表が出る確率pの最尤推定値を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**尤度関数：**
$$L(p) = \binom{10}{7} p^7 (1-p)^3$$

**対数尤度：**
$$\ln L(p) = \ln \binom{10}{7} + 7\ln p + 3\ln(1-p)$$

**微分して0とおく：**
$$\frac{d \ln L}{dp} = \frac{7}{p} - \frac{3}{1-p} = 0$$

$$7(1-p) = 3p$$
$$7 = 10p$$
$$p = 0.7$$

**答え：p̂ = 0.7（最尤推定値）**

一般に二項分布では p̂ = x/n

</details>

## 問題3：信頼区間の幅

95%信頼区間の幅を半分にしたい場合、サンプルサイズをどうすべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**信頼区間の幅：**
$$幅 = 2 \times z_{\alpha/2} \times \frac{\sigma}{\sqrt{n}}$$

幅は √n に反比例する。

**幅を半分にするには：**
$$\frac{1}{\sqrt{n_2}} = \frac{1}{2} \times \frac{1}{\sqrt{n_1}}$$

$$\sqrt{n_2} = 2\sqrt{n_1}$$

$$n_2 = 4n_1$$

**答え：サンプルサイズを4倍にする**

</details>

## 問題4：検定の過誤

ある検定で「有意水準5%で帰無仮説を棄却した」とき、以下は正しいですか？

(1) 帰無仮説が正しい確率は5%以下
(2) 第一種の過誤の確率は5%
(3) この結果が偶然である確率は5%以下

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 誤り**
有意水準は「帰無仮説が正しいときに棄却する確率」であり、「帰無仮説が正しい確率」ではない。

**(2) 正しい**
有意水準 = 第一種の過誤の確率（帰無仮説が正しいのに棄却）

**(3) 誤り**
p値の誤解。p値は「帰無仮説が正しいと仮定したとき、観測値以上に極端な値が得られる確率」

**重要：**
有意水準や p値は「仮説が正しい確率」ではない

</details>

## 問題5：検出力の計算

母平均μ=100、σ=20の母集団から n=25 のサンプルを取ります。H₀: μ=100 vs H₁: μ>100 を有意水準5%で検定するとき、真のμ=108での検出力は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**標準誤差：**
$$SE = \frac{20}{\sqrt{25}} = 4$$

**棄却域（H₀下）：**
$$\bar{x} > 100 + 1.645 \times 4 = 106.58$$

**検出力（真のμ=108での確率）：**
$$z = \frac{106.58 - 108}{4} = -0.355$$

$$検出力 = P(Z > -0.355) = 0.639$$

**答え：約64%**

効果量 d = (108-100)/20 = 0.4 の中程度の効果

</details>

## 問題6：両側検定と片側検定

研究者が「新薬は従来薬より効果がある」ことを示したいとき、両側検定と片側検定のどちらを使うべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**片側検定が適切**

理由：
- 研究仮説は「新薬 > 従来薬」という方向性を持つ
- 「効果が低い」ことを示す意義はない

**帰無仮説と対立仮説：**
- H₀: μ新薬 ≤ μ従来薬
- H₁: μ新薬 > μ従来薬

**注意：**
- 片側検定は検出力が高いが、反対方向の差は検出できない
- 事前に方向を決めておく必要がある
- 事後的に片側に変更するのは問題

</details>

## 問題7：対応のある検定

ダイエットプログラムの効果を調べるため、10人の体重を開始時と3ヶ月後に測定しました。差の平均は-2.5kg、差の標準偏差は3.0kgでした。効果があったと言えますか？（有意水準5%）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**対応のあるt検定**

**仮説：**
- H₀: μd = 0（変化なし）
- H₁: μd ≠ 0（変化あり）

**t統計量：**
$$t = \frac{\bar{d} - 0}{s_d/\sqrt{n}} = \frac{-2.5}{3.0/\sqrt{10}} = \frac{-2.5}{0.949} = -2.63$$

**判定：**
- 自由度 df = 9
- 臨界値 t₀.₀₂₅,₉ = 2.262
- |t| = 2.63 > 2.262

**答え：有意水準5%で効果があったと言える**

</details>

## 問題8：比率の検定

製品の不良率が従来の2%から変化したか検定します。500個中15個が不良でした。（有意水準5%）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**仮説：**
- H₀: p = 0.02
- H₁: p ≠ 0.02

**標本比率：**
$$\hat{p} = \frac{15}{500} = 0.03$$

**z統計量：**
$$z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1-p_0)}{n}}} = \frac{0.03 - 0.02}{\sqrt{\frac{0.02 \times 0.98}{500}}}$$

$$= \frac{0.01}{0.00626} = 1.60$$

**判定：**
- |z| = 1.60 < 1.96

**答え：有意水準5%で不良率が変化したとは言えない**

</details>

## 問題9：等分散の検定

2つのグループの分散が等しいか検定するF検定で、F = 2.5、df₁ = 15、df₂ = 20 でした。等分散の仮定は妥当ですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**F検定（等分散性）**

**仮説：**
- H₀: σ₁² = σ₂²
- H₁: σ₁² ≠ σ₂²

**臨界値（両側5%）：**
- F₀.₀₂₅,₁₅,₂₀ ≈ 2.57（上側）
- F₀.₉₇₅,₁₅,₂₀ ≈ 0.41（下側）

**判定：**
- F = 2.5 は 0.41 < 2.5 < 2.57 の範囲内

**答え：等分散の仮定は棄却されない（妥当と考えられる）**

ただし、F検定は正規性の仮定に敏感なので、Levene検定なども検討。

</details>

## 問題10：サンプルサイズの設計

母平均の95%信頼区間の幅を±3以内にしたい。σ=15と推定されるとき、必要なサンプルサイズは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**信頼区間の誤差幅：**
$$E = z_{\alpha/2} \times \frac{\sigma}{\sqrt{n}}$$

$$3 = 1.96 \times \frac{15}{\sqrt{n}}$$

$$\sqrt{n} = \frac{1.96 \times 15}{3} = 9.8$$

$$n = 96.04$$

**答え：n = 97（切り上げ）**

</details>

## 問題11：多重比較補正

4つのグループを比較する場合、ペアワイズ比較は何通りあり、ボンフェローニ補正後の有意水準は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**比較の数：**
$$\binom{4}{2} = \frac{4!}{2! \times 2!} = 6通り$$

**ボンフェローニ補正：**
$$\alpha' = \frac{0.05}{6} = 0.0083$$

**各比較の有意水準：0.83%**

より穏やかな補正法：
- Holm法
- Benjamini-Hochberg法（FDR制御）

</details>

## 問題12：効果量の解釈

2群比較でt(58)=2.8、p=0.007という結果が得られました。Cohenのdを計算し、効果の大きさを解釈してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**tからdへの変換（等サンプルサイズの場合）：**

n₁ = n₂ = 30と仮定

$$d = t \times \sqrt{\frac{1}{n_1} + \frac{1}{n_2}} = 2.8 \times \sqrt{\frac{2}{30}}$$

$$= 2.8 \times 0.258 = 0.72$$

**解釈：**
- d = 0.72 は中〜大の効果
- Cohen基準：0.2（小）、0.5（中）、0.8（大）

**注意：**
統計的に有意（p=0.007）でも、効果量を見て実践的意義を判断

</details>

## 問題13：検定の前提条件

t検定を使う前に確認すべき前提条件を3つ挙げてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**1. 正規性**
- データが正規分布に従う（または n が大きい）
- 確認：ヒストグラム、Q-Qプロット、Shapiro-Wilk検定

**2. 等分散性（2群比較の場合）**
- 2群の分散が等しい
- 確認：F検定、Levene検定
- 満たさない場合：Welchのt検定を使用

**3. 独立性**
- 観測値が互いに独立
- 確認：データ収集方法の確認
- 対応のあるデータには対応のあるt検定を使用

**nが十分大きければ（30以上）、正規性の仮定は緩和される**

</details>
