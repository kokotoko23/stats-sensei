# 正規分布の応用演習

正規分布を使った様々な計算問題です。

---

## 問題1：標準化の基本

X ~ N(100, 25) のとき、P(X > 110) を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**標準化：**
$$z = \frac{110 - 100}{\sqrt{25}} = \frac{10}{5} = 2$$

**確率計算：**
$$P(X > 110) = P(Z > 2) = 1 - 0.9772 = 0.0228$$

**答え：約2.28%**

</details>

## 問題2：区間の確率

X ~ N(50, 100) のとき、P(40 < X < 60) は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$z_1 = \frac{40-50}{10} = -1, \quad z_2 = \frac{60-50}{10} = 1$$

$$P(40 < X < 60) = P(-1 < Z < 1)$$

$$= P(Z < 1) - P(Z < -1) = 0.8413 - 0.1587 = 0.6826$$

**答え：約68.26%**

これは「平均±1σの範囲に約68%」という法則。

</details>

## 問題3：パーセンタイル点

X ~ N(70, 16) で、上位10%に入るには何点以上必要？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

上位10% = 90パーセンタイル

標準正規分布の90パーセンタイル：z = 1.28

$$x = \mu + z \times \sigma = 70 + 1.28 \times 4 = 75.12$$

**答え：約75点以上**

</details>

## 問題4：2つの正規分布の比較

男性の身長 X ~ N(170, 36)、女性の身長 Y ~ N(158, 25)。
ランダムに選んだ女性が、ランダムに選んだ男性より背が高い確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

D = Y - X とおく（独立を仮定）

**Dの分布：**
$$E[D] = E[Y] - E[X] = 158 - 170 = -12$$
$$Var(D) = Var(Y) + Var(X) = 25 + 36 = 61$$

D ~ N(-12, 61)

**P(D > 0)：**
$$z = \frac{0 - (-12)}{\sqrt{61}} = \frac{12}{7.81} = 1.54$$

$$P(D > 0) = P(Z > 1.54) = 1 - 0.938 = 0.062$$

**答え：約6.2%**

</details>

## 問題5：正規分布の和

X ~ N(100, 16), Y ~ N(80, 9)（独立）のとき、X + Y の分布は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**正規分布の再生性：**
独立な正規分布の和は正規分布

$$E[X+Y] = 100 + 80 = 180$$
$$Var(X+Y) = 16 + 9 = 25$$

**答え：X + Y ~ N(180, 25)**

標準偏差は5

</details>

## 問題6：標本平均の分布

X ~ N(50, 100) から n=25 の標本を取るとき、標本平均 X̄ の分布は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**標本平均の分布：**
$$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right)$$

$$\bar{X} \sim N\left(50, \frac{100}{25}\right) = N(50, 4)$$

**答え：X̄ ~ N(50, 4)**

標準誤差 = 10/5 = 2

</details>

## 問題7：品質管理

製品の重量が X ~ N(500, 100) に従う。規格は480g以上520g以下。規格外品の割合は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$z_1 = \frac{480-500}{10} = -2, \quad z_2 = \frac{520-500}{10} = 2$$

$$P(480 \leq X \leq 520) = P(-2 \leq Z \leq 2) = 0.9544$$

$$P(規格外) = 1 - 0.9544 = 0.0456$$

**答え：約4.56%が規格外**

</details>

## 問題8：正規分布のフィッティング

データの平均が75、標準偏差が12のとき、90点以上の人は何%いると予想されますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

正規分布を仮定：X ~ N(75, 144)

$$z = \frac{90-75}{12} = 1.25$$

$$P(X \geq 90) = P(Z \geq 1.25) = 1 - 0.8944 = 0.1056$$

**答え：約10.6%**

</details>

## 問題9：信頼区間の幅

X ~ N(μ, 100) から n=64 の標本を取る。標本平均の95%信頼区間の幅は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**標準誤差：**
$$SE = \frac{10}{\sqrt{64}} = 1.25$$

**95%信頼区間の幅：**
$$幅 = 2 \times 1.96 \times SE = 2 \times 1.96 \times 1.25 = 4.9$$

**答え：約4.9**

</details>

## 問題10：正規分布の積率

X ~ N(0, 1) のとき、E[X⁴] は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

標準正規分布の4次モーメント：

**公式：** E[Z²ⁿ] = (2n-1)!! = 1×3×5×...×(2n-1)

n=2 の場合：
$$E[Z^4] = 3!! = 1 \times 3 = 3$$

**答え：E[X⁴] = 3**

（尖度の計算に使用）

</details>

## 問題11：標本サイズの決定

母平均を95%信頼区間で誤差±2以内に推定したい。σ=10のとき、必要なサンプルサイズは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$E = z_{\alpha/2} \times \frac{\sigma}{\sqrt{n}}$$

$$2 = 1.96 \times \frac{10}{\sqrt{n}}$$

$$\sqrt{n} = \frac{1.96 \times 10}{2} = 9.8$$

$$n = 96.04$$

**答え：n = 97（切り上げ）**

</details>

## 問題12：チェビシェフとの比較

X ~ N(100, 25) で、P(|X - 100| > 10) は？
チェビシェフの不等式による上界と比較してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**正規分布による計算：**
$$P(|X-100| > 10) = P(|Z| > 2) = 2 \times 0.0228 = 0.0456$$

**チェビシェフの不等式：**
k = 10/5 = 2（標準偏差の2倍）
$$P(|X-\mu| > k\sigma) \leq \frac{1}{k^2} = \frac{1}{4} = 0.25$$

**比較：**
- 正規分布：4.56%
- チェビシェフ：25%以下

チェビシェフは分布を仮定しないので緩い上界。

</details>
