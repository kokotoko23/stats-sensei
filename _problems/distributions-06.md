# 中心極限定理の応用

中心極限定理を活用した問題です。

## 問題1：中心極限定理の基本

一様分布 U(0, 1) から100個のサンプルを取るとき、標本平均の近似的な分布は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**U(0,1)の母数：**
- E[X] = 1/2
- Var(X) = 1/12

**中心極限定理より：**
$$\bar{X} \sim N\left(\frac{1}{2}, \frac{1/12}{100}\right) = N\left(0.5, 0.000833\right)$$

標準偏差 = √(1/1200) ≈ 0.0289

**答え：X̄ ≈ N(0.5, 0.000833)**

</details>

## 問題2：標本比率の分布

n=400で標本比率p̂=0.6のとき、母比率pの95%信頼区間は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**標本比率の標準誤差：**
$$SE = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = \sqrt{\frac{0.6 \times 0.4}{400}} = \sqrt{0.0006} = 0.0245$$

**95%信頼区間：**
$$\hat{p} \pm 1.96 \times SE = 0.6 \pm 1.96 \times 0.0245$$
$$= 0.6 \pm 0.048 = [0.552, 0.648]$$

**答え：[0.552, 0.648]**

</details>

## 問題3：ポアソン分布の正規近似

X ~ Pois(100) のとき、P(X > 110) を正規近似で求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**ポアソン分布の性質：**
- E[X] = λ = 100
- Var(X) = λ = 100

**正規近似（連続性補正付き）：**
$$z = \frac{110.5 - 100}{\sqrt{100}} = \frac{10.5}{10} = 1.05$$

$$P(X > 110) \approx P(Z > 1.05) = 1 - 0.8531 = 0.147$$

**答え：約14.7%**

</details>

## 問題4：二項分布の正規近似

コインを400回投げて220回以上表が出る確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

X ~ Bin(400, 0.5)

**パラメータ：**
- μ = np = 200
- σ = √(np(1-p)) = √100 = 10

**正規近似（連続性補正）：**
$$z = \frac{219.5 - 200}{10} = 1.95$$

$$P(X \geq 220) \approx P(Z \geq 1.95) = 1 - 0.9744 = 0.0256$$

**答え：約2.56%**

</details>

## 問題5：平均の差の分布

独立な2つの母集団から標本を取る。
- n₁=50, X̄₁=100, s₁=15
- n₂=50, X̄₂=95, s₂=12

X̄₁ - X̄₂ の標準誤差は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$SE_{\bar{X}_1 - \bar{X}_2} = \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}$$

$$= \sqrt{\frac{225}{50} + \frac{144}{50}} = \sqrt{4.5 + 2.88} = \sqrt{7.38} = 2.72$$

**答え：約2.72**

</details>

## 問題6：大数の法則との関係

サイコロを n 回振るとき、出た目の平均が3.4から3.6の間に入る確率は n が大きくなるとどうなりますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**大数の法則：**
n → ∞ で X̄ → μ = 3.5（確率収束）

**中心極限定理による計算：**
$$P(3.4 < \bar{X} < 3.6) = P\left(\frac{3.4-3.5}{\sigma/\sqrt{n}} < Z < \frac{3.6-3.5}{\sigma/\sqrt{n}}\right)$$

n が大きくなると z の範囲が広がり、確率は1に近づく。

**答え：n → ∞ で確率 → 1**

</details>

## 問題7：標本分散の分布

X ~ N(μ, σ²) から n 個のサンプルを取るとき、(n-1)s²/σ² はどんな分布に従いますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\frac{(n-1)s^2}{\sigma^2} \sim \chi^2(n-1)$$

**答え：自由度 n-1 のカイ二乗分布**

この性質は：
- 母分散の区間推定
- 分散の検定
に使用される。

</details>

## 問題8：有限母集団補正

N=1000の母集団からn=100のサンプルを非復元抽出するとき、標本平均の標準誤差はどう修正されますか？（母標準偏差σ=20）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**有限母集団補正：**
$$SE = \frac{\sigma}{\sqrt{n}} \times \sqrt{\frac{N-n}{N-1}}$$

$$= \frac{20}{\sqrt{100}} \times \sqrt{\frac{900}{999}} = 2 \times 0.949 = 1.90$$

**補正なしの場合：** SE = 2

**答え：約1.90（補正なしより約5%小さい）**

</details>

## 問題9：スチューデントのt分布

標本サイズn=10、標本平均X̄=50、標本標準偏差s=8のとき、母平均の95%信頼区間は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

小標本なのでt分布を使用。

**自由度：** df = n-1 = 9
**t値：** t₀.₀₂₅,₉ = 2.262

$$\bar{X} \pm t \times \frac{s}{\sqrt{n}} = 50 \pm 2.262 \times \frac{8}{\sqrt{10}}$$

$$= 50 \pm 2.262 \times 2.53 = 50 \pm 5.72$$

**答え：[44.28, 55.72]**

</details>

## 問題10：比率の差の検定

2つのグループ：
- グループA：n₁=200, p̂₁=0.45
- グループB：n₂=200, p̂₂=0.35

比率に差があるか検定（α=0.05）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**プールした比率：**
$$\hat{p} = \frac{0.45 \times 200 + 0.35 \times 200}{400} = 0.40$$

**標準誤差：**
$$SE = \sqrt{\hat{p}(1-\hat{p})\left(\frac{1}{n_1}+\frac{1}{n_2}\right)}$$
$$= \sqrt{0.40 \times 0.60 \times \frac{2}{200}} = \sqrt{0.0024} = 0.049$$

**z統計量：**
$$z = \frac{0.45-0.35}{0.049} = 2.04$$

|z| = 2.04 > 1.96

**答え：有意水準5%で差がある（棄却）**

</details>

## 問題11：収束の速さ

中心極限定理の収束の速さは母集団の分布によって異なります。どのような分布で収束が遅いですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**収束が遅い分布：**
1. 歪度が大きい分布（指数分布など）
2. 尖度が大きい分布（重い裾）
3. 離散的で値が少ない分布

**目安：**
- 正規分布に近い：n ≥ 30
- 対称的な分布：n ≥ 30
- 歪んだ分布：n ≥ 50〜100

**Berry-Esseen定理：**
収束速度は1/√n のオーダー

</details>

## 問題12：モンテカルロシミュレーション

中心極限定理を検証するため、一様分布から100回サンプリングして平均を取る実験を1000回行います。その平均の分布はどうなりますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**理論値：**
- E[X̄] = 0.5
- Var(X̄) = (1/12)/100 = 1/1200
- SD(X̄) = 1/√1200 ≈ 0.0289

**シミュレーション結果の予想：**
- 平均：0.5に近い
- 標準偏差：0.0289に近い
- 分布の形状：正規分布に近い

n=100は十分大きいので、中心極限定理がよく成り立つ。

</details>
