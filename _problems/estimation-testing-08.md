# 区間推定の実践演習

区間推定の理解を深める実践的な問題です。

---

## 問題1：母平均の信頼区間（大標本）

n=100、x̄=75、s=15のデータから母平均の95%信頼区間を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

大標本なのでz分布を使用。

$$\bar{x} \pm z_{\alpha/2} \times \frac{s}{\sqrt{n}}$$

$$= 75 \pm 1.96 \times \frac{15}{\sqrt{100}}$$

$$= 75 \pm 1.96 \times 1.5 = 75 \pm 2.94$$

**答え：[72.06, 77.94]**

</details>

---

## 問題2：母比率の信頼区間

500人中320人が「はい」と回答。母比率の95%信頼区間は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\hat{p} = \frac{320}{500} = 0.64$$

$$SE = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = \sqrt{\frac{0.64 \times 0.36}{500}} = 0.0215$$

$$0.64 \pm 1.96 \times 0.0215 = 0.64 \pm 0.042$$

**答え：[0.598, 0.682]（59.8%〜68.2%）**

</details>

## 問題3：信頼区間の解釈

「95%信頼区間は[10, 20]」の正しい解釈は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**正しい解釈：**
同じ方法で100回サンプリングすると、約95回の信頼区間が真の母数を含む。

**よくある誤解：**
- ✗ 母数が10〜20にある確率が95%
- ✗ サンプルの95%が10〜20にある

**重要：**
母数は固定値。信頼区間が「母数を含むか含まないか」は確率的に決まるのは区間の方。

</details>

## 問題4：母分散の信頼区間

n=20、s²=25のとき、母分散の95%信頼区間は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

カイ二乗分布を使用。

$$\frac{(n-1)s^2}{\chi^2_{upper}} \leq \sigma^2 \leq \frac{(n-1)s^2}{\chi^2_{lower}}$$

df = 19
- χ²₀.₀₂₅,₁₉ = 32.85
- χ²₀.₉₇₅,₁₉ = 8.91

$$\frac{19 \times 25}{32.85} \leq \sigma^2 \leq \frac{19 \times 25}{8.91}$$

$$14.46 \leq \sigma^2 \leq 53.31$$

**答え：[14.46, 53.31]**

</details>

## 問題5：2つの母平均の差

独立な2群：
- グループA：n₁=30, x̄₁=50, s₁=8
- グループB：n₂=35, x̄₂=45, s₂=10

母平均の差の95%信頼区間は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$SE = \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}} = \sqrt{\frac{64}{30} + \frac{100}{35}} = \sqrt{5.00} = 2.24$$

$$(\bar{x}_1 - \bar{x}_2) \pm z \times SE = 5 \pm 1.96 \times 2.24$$

$$= 5 \pm 4.39$$

**答え：[0.61, 9.39]**

0を含まないので、差は統計的に有意。

</details>

## 問題6：必要サンプルサイズ（比率）

選挙調査で支持率を±3%の精度で推定したい。95%信頼水準で必要なサンプルサイズは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

p = 0.5（最も保守的な仮定）

$$n = \left(\frac{z}{E}\right)^2 \times p(1-p)$$

$$= \left(\frac{1.96}{0.03}\right)^2 \times 0.25 = 4268.44 \times 0.25 = 1067.1$$

**答え：1068人以上**

</details>

## 問題7：ブートストラップ信頼区間

ブートストラップ法による信頼区間の利点は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**利点：**

1. **分布の仮定不要**
   - 正規性を仮定しない
   - 任意の統計量に適用可能

2. **小標本でも使用可能**
   - t分布の仮定も不要

3. **複雑な統計量にも対応**
   - 中央値、四分位範囲など
   - 比率の差など

**手順：**
1. 元データから復元抽出でリサンプリング
2. 各リサンプルで統計量を計算
3. 統計量の分布から区間を求める

</details>

## 問題8：信頼区間の幅

99%信頼区間は95%信頼区間より広いか狭いか？理由は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**答え：広い**

**理由：**
- 99%信頼区間：z = 2.576
- 95%信頼区間：z = 1.96

信頼水準を上げる → より確実に母数を含みたい → 区間を広くする必要がある

**トレードオフ：**
- 高い信頼水準 → 広い区間 → 精度が低い
- 低い信頼水準 → 狭い区間 → 含まないリスク増

</details>

## 問題9：一側信頼区間

ある機械の故障率の上限を知りたい。100回中3回故障。95%信頼水準での上側信頼限界は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

p̂ = 0.03

片側信頼区間なので z = 1.645

$$p_{upper} = \hat{p} + z \times \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

$$= 0.03 + 1.645 \times \sqrt{\frac{0.03 \times 0.97}{100}}$$

$$= 0.03 + 1.645 \times 0.017 = 0.03 + 0.028 = 0.058$$

**答え：故障率は95%の確信で5.8%以下**

</details>

## 問題10：信頼区間と検定の関係

「95%信頼区間が[2, 8]で0を含まない」とき、α=0.05の両側検定の結果は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**答え：帰無仮説を棄却（p < 0.05）**

**関係：**
- 95%信頼区間が H₀の値を含まない → 5%水準で有意
- 95%信頼区間が H₀の値を含む → 5%水準で有意でない

信頼区間と両側検定は表裏一体の関係。

</details>

## 問題11：対応のあるデータの信頼区間

ペアデータの差：d = [3, -1, 5, 2, 4, 0]
差の平均の95%信頼区間は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

- n = 6
- d̄ = 13/6 = 2.17
- sd = 2.14

t₀.₀₂₅,₅ = 2.571

$$\bar{d} \pm t \times \frac{s_d}{\sqrt{n}} = 2.17 \pm 2.571 \times \frac{2.14}{\sqrt{6}}$$

$$= 2.17 \pm 2.25$$

**答え：[-0.08, 4.42]**

0を含むので、差は有意でない。

</details>

## 問題12：調整済み信頼区間

同時に複数の信頼区間を作るとき、ボンフェローニ補正をどう適用しますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**ボンフェローニ補正：**

k個の信頼区間を作る場合：
- 各区間の信頼水準 = 1 - α/k

**例：**
- 3つの信頼区間、全体で95%信頼
- 各区間：1 - 0.05/3 = 98.3%信頼区間

**理由：**
複数の区間のうち少なくとも1つが母数を外す確率を制御

**注意：**
保守的（区間が広くなりすぎる）なので、他の方法（Tukeyなど）も検討

</details>

## 問題13：有限母集団補正

母集団N=500から n=100を非復元抽出。信頼区間はどう変わる？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**有限母集団補正係数：**
$$fpc = \sqrt{\frac{N-n}{N-1}} = \sqrt{\frac{400}{499}} = 0.895$$

標準誤差に0.895を掛ける → 区間が狭くなる

**理由：**
- 母集団の20%もサンプリングしている
- 情報量が多いので精度が上がる

**適用条件：**
n/N > 0.05 のとき補正を検討

</details>
