# 二項分布とポアソン分布の演習

離散型確率分布の計算練習問題です。

## 問題1：二項分布の確率計算

成功確率0.3の試行を5回行うとき、ちょうど2回成功する確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$P(X=2) = \binom{5}{2}(0.3)^2(0.7)^3$$

$$= 10 \times 0.09 \times 0.343 = 0.3087$$

**答え：約30.9%**

</details>

## 問題2：二項分布の期待値と分散

n=20、p=0.4の二項分布について、期待値と標準偏差を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**期待値：**
$$E[X] = np = 20 \times 0.4 = 8$$

**分散：**
$$Var(X) = np(1-p) = 20 \times 0.4 \times 0.6 = 4.8$$

**標準偏差：**
$$\sigma = \sqrt{4.8} \approx 2.19$$

**答え：期待値8、標準偏差約2.19**

</details>

## 問題3：二項分布の累積確率

コインを10回投げるとき、表が3回以下になる確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$P(X \leq 3) = P(X=0) + P(X=1) + P(X=2) + P(X=3)$$

$$P(X=0) = \binom{10}{0}(0.5)^{10} = 0.00098$$

$$P(X=1) = \binom{10}{1}(0.5)^{10} = 0.00977$$

$$P(X=2) = \binom{10}{2}(0.5)^{10} = 0.04395$$

$$P(X=3) = \binom{10}{3}(0.5)^{10} = 0.11719$$

$$P(X \leq 3) = 0.1719$$

**答え：約17.2%**

</details>

## 問題4：ポアソン分布の確率

1時間あたり平均4件の電話がかかってきます。1時間に6件以上かかってくる確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

λ=4のポアソン分布

$$P(X \geq 6) = 1 - P(X \leq 5)$$

$$P(X=k) = \frac{e^{-4} \times 4^k}{k!}$$

| k | P(X=k) |
|---|--------|
| 0 | 0.0183 |
| 1 | 0.0733 |
| 2 | 0.1465 |
| 3 | 0.1954 |
| 4 | 0.1954 |
| 5 | 0.1563 |

$$P(X \leq 5) = 0.7852$$

$$P(X \geq 6) = 1 - 0.7852 = 0.2148$$

**答え：約21.5%**

</details>

## 問題5：ポアソン分布の期待値

交差点で1日平均2件の事故が起きます。1週間（7日間）で事故が10件以上起きる確率を求める際に使う分布のパラメータは？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

1日あたりλ=2

1週間：$\lambda_{週} = 2 \times 7 = 14$

**答え：ポアソン分布 Poi(14)を使用**

この分布で P(X ≥ 10) を計算すればよい。

</details>

## 問題6：二項分布からポアソン近似

不良率1%の製品を500個検査するとき、不良品が5個以下である確率をポアソン近似で求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$\lambda = np = 500 \times 0.01 = 5$

$$P(X \leq 5) = \sum_{k=0}^{5} \frac{e^{-5} \times 5^k}{k!}$$

| k | P(X=k) |
|---|--------|
| 0 | 0.0067 |
| 1 | 0.0337 |
| 2 | 0.0842 |
| 3 | 0.1404 |
| 4 | 0.1755 |
| 5 | 0.1755 |

$$P(X \leq 5) = 0.616$$

**答え：約61.6%**

</details>

## 問題7：ポアソン分布の性質

Poi(3)とPoi(5)が独立のとき、それらの和の分布は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

独立なポアソン分布の和はポアソン分布に従う：

$$Poi(3) + Poi(5) = Poi(3+5) = Poi(8)$$

**答え：Poi(8)**

期待値：8、分散：8

</details>

## 問題8：二項分布の応用

製品の合格率は80%です。10個の製品を検査するとき、8個以上合格する確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$P(X \geq 8) = P(X=8) + P(X=9) + P(X=10)$$

$$P(X=8) = \binom{10}{8}(0.8)^8(0.2)^2 = 45 \times 0.1678 \times 0.04 = 0.302$$

$$P(X=9) = \binom{10}{9}(0.8)^9(0.2)^1 = 10 \times 0.1342 \times 0.2 = 0.268$$

$$P(X=10) = \binom{10}{10}(0.8)^{10} = 0.107$$

$$P(X \geq 8) = 0.302 + 0.268 + 0.107 = 0.677$$

**答え：約67.7%**

</details>

## 問題9：待ち時間の確率

顧客が平均10分に1人来店します。20分間に誰も来ない確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

20分間の平均来客数：$\lambda = 2$

$$P(X=0) = \frac{e^{-2} \times 2^0}{0!} = e^{-2} \approx 0.135$$

**答え：約13.5%**

</details>

## 問題10：二項分布の正規近似

n=100、p=0.5の二項分布で、P(45 ≤ X ≤ 55)を正規近似で求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$\mu = np = 50$
$\sigma = \sqrt{np(1-p)} = \sqrt{25} = 5$

連続性補正：P(44.5 ≤ X ≤ 55.5)

$$z_1 = \frac{44.5 - 50}{5} = -1.1$$
$$z_2 = \frac{55.5 - 50}{5} = 1.1$$

$$P(-1.1 \leq Z \leq 1.1) \approx 0.729$$

**答え：約72.9%**

</details>

## 問題11：ポアソン分布の逆問題

1時間にコールセンターに電話がλ件かかってきます。電話が1件もこない確率が1%以下になるのは、λがいくつ以上のとき？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$P(X=0) = e^{-\lambda} \leq 0.01$$

$$e^{-\lambda} \leq 0.01$$

$$-\lambda \leq \ln(0.01) = -4.605$$

$$\lambda \geq 4.605$$

**答え：λ ≥ 4.61（約5件/時間以上）**

</details>

## 問題12：総合問題

ある工場で1日に平均3件の設備故障が発生します。

(1) 1日に故障が発生しない確率
(2) 1週間（5日稼働）で故障が10件以下の確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 1日に故障なし**

$$P(X=0) = e^{-3} = 0.0498$$

**答え：約5.0%**

**(2) 1週間で10件以下**

週のλ = 3 × 5 = 15

$$P(X \leq 10) = \sum_{k=0}^{10} \frac{e^{-15} \times 15^k}{k!}$$

計算すると：

$$P(X \leq 10) \approx 0.118$$

**答え：約11.8%**

（1週間で10件以下は珍しい）

</details>
