## 問題1：標準誤差の計算

母集団の標準偏差が $\sigma = 12$ のとき、以下のサンプルサイズにおける標準誤差を求めてください。

(1) $n = 9$

(2) $n = 36$

(3) $n = 144$

<details markdown="1">
<summary>解答を見る</summary>

### 解答

標準誤差の公式：$SE = \frac{\sigma}{\sqrt{n}}$

**(1) n = 9**

$$SE = \frac{12}{\sqrt{9}} = \frac{12}{3} = 4$$

**答え：4**

**(2) n = 36**

$$SE = \frac{12}{\sqrt{36}} = \frac{12}{6} = 2$$

**答え：2**

**(3) n = 144**

$$SE = \frac{12}{\sqrt{144}} = \frac{12}{12} = 1$$

**答え：1**

### 解説

サンプルサイズが4倍になると、標準誤差は半分になります。これは $\sqrt{4} = 2$ で割るためです。

</details>

## 問題2：母分散既知の区間推定

ある機械で生産される製品の長さは、標準偏差 $\sigma = 0.5$ cm であることが分かっています。25個のサンプルを測定したところ、平均は $\bar{x} = 10.2$ cm でした。

母平均の95%信頼区間を求めてください。（$z_{0.025} = 1.96$）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**与えられた値**
- $\bar{x} = 10.2$ cm
- $\sigma = 0.5$ cm
- $n = 25$
- $z_{0.025} = 1.96$

**標準誤差**

$$SE = \frac{0.5}{\sqrt{25}} = \frac{0.5}{5} = 0.1$$

**信頼区間**

$$10.2 \pm 1.96 \times 0.1 = 10.2 \pm 0.196$$

**答え：10.004 cm から 10.396 cm**

（または約 10.0 cm から 10.4 cm）

</details>

## 問題3：母分散未知の区間推定

ある学校の生徒20人の身長を測定したところ、平均 $\bar{x} = 165$ cm、標本標準偏差 $s = 6$ cm でした。

母平均の95%信頼区間を求めてください。（$t_{0.025}(19) = 2.093$）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**与えられた値**
- $\bar{x} = 165$ cm
- $s = 6$ cm
- $n = 20$
- 自由度 $df = 19$
- $t_{0.025}(19) = 2.093$

**標準誤差**

$$SE = \frac{6}{\sqrt{20}} = \frac{6}{4.47} \approx 1.34$$

**信頼区間**

$$165 \pm 2.093 \times 1.34 = 165 \pm 2.80$$

**答え：162.2 cm から 167.8 cm**

</details>

## 問題4：信頼係数の比較

あるデータから計算した標本平均は $\bar{x} = 50$、標準誤差は $SE = 2$ でした。

(1) 90%信頼区間を求めてください（$z = 1.645$）

(2) 95%信頼区間を求めてください（$z = 1.96$）

(3) 99%信頼区間を求めてください（$z = 2.576$）

(4) 信頼係数と区間の幅の関係を説明してください

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 90%信頼区間**

$$50 \pm 1.645 \times 2 = 50 \pm 3.29$$

**答え：46.71 から 53.29**

**(2) 95%信頼区間**

$$50 \pm 1.96 \times 2 = 50 \pm 3.92$$

**答え：46.08 から 53.92**

**(3) 99%信頼区間**

$$50 \pm 2.576 \times 2 = 50 \pm 5.15$$

**答え：44.85 から 55.15**

**(4) 関係の説明**

信頼係数が高いほど、信頼区間の幅は広くなります。

| 信頼係数 | 区間の幅 |
|---------|---------|
| 90% | 6.58 |
| 95% | 7.84 |
| 99% | 10.30 |

高い信頼を得るためには、より広い区間で推定する必要があります。

</details>

## 問題5：必要サンプルサイズの計算

母集団の標準偏差が $\sigma = 10$ と推定されています。95%信頼区間の幅を $\pm 2$ 以内にしたい場合、最低何個のサンプルが必要ですか？（$z_{0.025} = 1.96$）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

必要サンプルサイズの公式：

$$n = \left(\frac{z_{\alpha/2} \cdot \sigma}{E}\right)^2$$

ここで $E = 2$（許容誤差）

$$n = \left(\frac{1.96 \times 10}{2}\right)^2 = \left(\frac{19.6}{2}\right)^2 = 9.8^2 = 96.04$$

サンプルサイズは整数なので、切り上げて

**答え：97個**

### 解説

96.04を96に切り捨てると、誤差が2をわずかに超えてしまう可能性があるため、切り上げて97個とします。

</details>

## 問題6：総合問題

ある会社で従業員の1日の通勤時間を調査しました。36人を無作為抽出して調べたところ、平均45分、標本標準偏差18分でした。

(1) 標準誤差を求めてください

(2) 母平均の95%信頼区間を求めてください（サンプルサイズが大きいので $z = 1.96$ を使用）

(3) この結果から「全従業員の平均通勤時間は40分以下である」と言えますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 標準誤差**

$$SE = \frac{s}{\sqrt{n}} = \frac{18}{\sqrt{36}} = \frac{18}{6} = 3 \text{ 分}$$

**答え：3分**

**(2) 95%信頼区間**

$$45 \pm 1.96 \times 3 = 45 \pm 5.88$$

**答え：39.12分 から 50.88分**

**(3) 考察**

95%信頼区間は 39.12分 から 50.88分 です。

40分という値はこの区間内に含まれているため、「母平均が40分である」可能性は否定できません。

しかし、区間の大部分（40分〜50.88分）は40分より大きいため、**「平均通勤時間は40分以下である」とは言えません**。

より正確には、信頼区間の下限が39.12分なので、40分以下である可能性はあるものの、40分以上である可能性の方が高いと考えられます。

</details>
