# 確率の基本計算問題

確率の基本を確認する問題です。[理論編：確率の基本概念]({{ site.baseurl }}/theory/probability-basics/)を学んでから取り組みましょう。

---

## 問題1：古典的確率

サイコロを1回振るとき、以下の確率を求めてください。

(1) 3が出る確率

(2) 3以下が出る確率

(3) 奇数が出る確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

標本空間：$\Omega = \{1, 2, 3, 4, 5, 6\}$（6通り）

**(1) 3が出る確率**

事象：$\{3\}$（1通り）

$$P(3) = \frac{1}{6}$$

**答え：$\frac{1}{6}$**

**(2) 3以下が出る確率**

事象：$\{1, 2, 3\}$（3通り）

$$P(3以下) = \frac{3}{6} = \frac{1}{2}$$

**答え：$\frac{1}{2}$**

**(3) 奇数が出る確率**

事象：$\{1, 3, 5\}$（3通り）

$$P(奇数) = \frac{3}{6} = \frac{1}{2}$$

**答え：$\frac{1}{2}$**

</details>

## 問題2：余事象

52枚のトランプから1枚引くとき、以下の確率を求めてください。

(1) スペードを引く確率

(2) スペード以外を引く確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) スペードを引く確率**

スペードは13枚

$$P(\text{スペード}) = \frac{13}{52} = \frac{1}{4}$$

**答え：$\frac{1}{4}$**

**(2) スペード以外を引く確率**

余事象を使う：

$$P(\text{スペード以外}) = 1 - P(\text{スペード}) = 1 - \frac{1}{4} = \frac{3}{4}$$

**答え：$\frac{3}{4}$**

</details>

## 問題3：加法定理

52枚のトランプから1枚引くとき、「ダイヤまたはエース」を引く確率を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

- ダイヤ：13枚
- エース：4枚
- ダイヤかつエース（ダイヤのエース）：1枚

加法定理より：

$$P(\text{ダイヤまたはエース}) = P(\text{ダイヤ}) + P(\text{エース}) - P(\text{ダイヤかつエース})$$

$$= \frac{13}{52} + \frac{4}{52} - \frac{1}{52} = \frac{16}{52} = \frac{4}{13}$$

**答え：$\frac{4}{13}$**

### 解説

「ダイヤのエース」を二重に数えてしまうので、加法定理で引く必要があります。

</details>

## 問題4：独立事象

コインを3回投げるとき、以下の確率を求めてください。

(1) 3回とも表が出る確率

(2) 少なくとも1回は表が出る確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

各回のコイン投げは独立。

**(1) 3回とも表が出る確率**

$$P(\text{3回とも表}) = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$$

**答え：$\frac{1}{8}$**

**(2) 少なくとも1回は表が出る確率**

余事象「3回とも裏」を使う：

$$P(\text{3回とも裏}) = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$$

$$P(\text{少なくとも1回表}) = 1 - \frac{1}{8} = \frac{7}{8}$$

**答え：$\frac{7}{8}$**

### 解説

「少なくとも1回」の問題は、余事象を使うと簡単に解けます。

</details>

## 問題5：条件付き確率

ある学校の生徒200人を調査したところ、以下の結果が得られました。

|  | 数学が好き | 数学が嫌い | 合計 |
|---|-----------|-----------|------|
| 理系 | 60 | 20 | 80 |
| 文系 | 40 | 80 | 120 |
| 合計 | 100 | 100 | 200 |

(1) ランダムに1人選んだとき、その人が理系である確率

(2) ランダムに1人選んだとき、その人が数学好きである確率

(3) 数学好きの生徒の中から1人選んだとき、その人が理系である確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 理系である確率**

$$P(\text{理系}) = \frac{80}{200} = \frac{2}{5} = 0.4$$

**答え：0.4（40%）**

**(2) 数学好きである確率**

$$P(\text{数学好き}) = \frac{100}{200} = \frac{1}{2} = 0.5$$

**答え：0.5（50%）**

**(3) 数学好きのうち理系である確率（条件付き確率）**

$$P(\text{理系}|\text{数学好き}) = \frac{P(\text{理系かつ数学好き})}{P(\text{数学好き})}$$

$$= \frac{60/200}{100/200} = \frac{60}{100} = 0.6$$

**答え：0.6（60%）**

### 解説

条件付き確率は「条件を満たすグループの中での割合」と考えると分かりやすいです。数学好き100人のうち理系は60人なので、60/100 = 0.6 です。

</details>

## 問題6：総合問題

袋の中に赤玉3個、白玉2個が入っています。この袋から玉を1個ずつ2回取り出します（取り出した玉は戻さない）。

(1) 1個目が赤玉である確率

(2) 1個目が赤玉、2個目も赤玉である確率

(3) 2個とも同じ色である確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 1個目が赤玉である確率**

$$P(\text{1個目赤}) = \frac{3}{5}$$

**答え：$\frac{3}{5}$**

**(2) 1個目赤、2個目も赤の確率**

乗法定理を使う：

$$P(\text{1個目赤かつ2個目赤}) = P(\text{1個目赤}) \times P(\text{2個目赤}|\text{1個目赤})$$

1個目に赤を取った後、残りは赤2個、白2個の計4個

$$= \frac{3}{5} \times \frac{2}{4} = \frac{3}{5} \times \frac{1}{2} = \frac{3}{10}$$

**答え：$\frac{3}{10}$**

**(3) 2個とも同じ色である確率**

「2個とも赤」または「2個とも白」（排反事象）

$$P(\text{2個とも白}) = \frac{2}{5} \times \frac{1}{4} = \frac{2}{20} = \frac{1}{10}$$

$$P(\text{同じ色}) = P(\text{2個とも赤}) + P(\text{2個とも白})$$

$$= \frac{3}{10} + \frac{1}{10} = \frac{4}{10} = \frac{2}{5}$$

**答え：$\frac{2}{5}$**

</details>
