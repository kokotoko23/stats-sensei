## 問題7：ベイズの定理（基本）

ある病気の検査キットがあります。
- 実際に病気の人が陽性になる確率（感度）：95%
- 実際に健康な人が陰性になる確率（特異度）：90%
- この病気の有病率：1%

陽性反応が出た場合、実際に病気である確率を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

ベイズの定理：$P(病気|陽性) = \frac{P(陽性|病気) \times P(病気)}{P(陽性)}$

$P(陽性)$ を求める（全確率の公式）：
$$P(陽性) = P(陽性|病気) \times P(病気) + P(陽性|健康) \times P(健康)$$
$$= 0.95 \times 0.01 + 0.10 \times 0.99$$
$$= 0.0095 + 0.099 = 0.1085$$

ベイズの定理より：
$$P(病気|陽性) = \frac{0.95 \times 0.01}{0.1085} = \frac{0.0095}{0.1085} \approx 0.088$$

**答え：約8.8%**

### 解説

驚くべきことに、陽性反応が出ても実際に病気である確率は約9%しかありません。これは：
- 有病率が低い（1%）
- 偽陽性（健康なのに陽性）が比較的多い

という条件が組み合わさった結果です。

</details>

## 問題8：期待値の計算

あるゲームで、サイコロを1回振り、出た目の数×100円がもらえます。ただし、1が出たら500円を払います。

このゲームの期待値を計算し、参加すべきかどうか判断してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

各目の確率は $\frac{1}{6}$

$$E[X] = -500 \times \frac{1}{6} + 200 \times \frac{1}{6} + 300 \times \frac{1}{6} + 400 \times \frac{1}{6} + 500 \times \frac{1}{6} + 600 \times \frac{1}{6}$$

$$= \frac{-500 + 200 + 300 + 400 + 500 + 600}{6} = \frac{1500}{6} = 250$$

**答え：期待値250円（参加すべき）**

長期的には1回あたり平均250円の利益が期待できます。

</details>

## 問題9：条件付き期待値

箱Aには赤玉3個、白玉2個、箱Bには赤玉1個、白玉4個が入っています。

コインを投げて、表なら箱A、裏なら箱Bから玉を1個取り出します。赤玉が出たときの賞金は1000円です。

賞金の期待値を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$P(赤|A) = \frac{3}{5}$、$P(赤|B) = \frac{1}{5}$

$P(A) = P(B) = \frac{1}{2}$

$P(赤) = P(赤|A) \times P(A) + P(赤|B) \times P(B)$
$= \frac{3}{5} \times \frac{1}{2} + \frac{1}{5} \times \frac{1}{2}$
$= \frac{3}{10} + \frac{1}{10} = \frac{4}{10} = 0.4$

$$E[賞金] = 1000 \times 0.4 + 0 \times 0.6 = 400$$

**答え：400円**

</details>

## 問題10：分散の計算

確率変数Xが以下の確率分布に従うとき、期待値 $E[X]$ と分散 $Var(X)$ を求めてください。

| X | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P(X) | 0.1 | 0.3 | 0.4 | 0.2 |

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**期待値**
$$E[X] = 0 \times 0.1 + 1 \times 0.3 + 2 \times 0.4 + 3 \times 0.2$$
$$= 0 + 0.3 + 0.8 + 0.6 = 1.7$$

**E[X²]**
$$E[X^2] = 0^2 \times 0.1 + 1^2 \times 0.3 + 2^2 \times 0.4 + 3^2 \times 0.2$$
$$= 0 + 0.3 + 1.6 + 1.8 = 3.7$$

**分散**
$$Var(X) = E[X^2] - (E[X])^2 = 3.7 - 1.7^2 = 3.7 - 2.89 = 0.81$$

**答え：E[X] = 1.7、Var(X) = 0.81**

</details>

## 問題11：複合事象

3人の候補者A、B、Cがいます。
- Aが勝つ確率：50%
- Bが勝つ確率：30%
- Cが勝つ確率：20%

(1) AまたはBが勝つ確率
(2) Aが勝たない確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) AまたはBが勝つ確率**

A、B、Cは互いに排反（同時に勝てない）なので：

$$P(A \cup B) = P(A) + P(B) = 0.5 + 0.3 = 0.8$$

**答え：80%**

**(2) Aが勝たない確率**

$$P(\bar{A}) = 1 - P(A) = 1 - 0.5 = 0.5$$

または $P(B) + P(C) = 0.3 + 0.2 = 0.5$

**答え：50%**

</details>

## 問題12：独立でない事象

袋に赤玉2個、青玉3個が入っています。玉を**戻さずに**2個取り出すとき：

(1) 1個目が赤で、2個目も赤の確率
(2) 2個とも同じ色の確率
(3) 少なくとも1個は赤の確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 2個とも赤**

$$P(1個目赤) = \frac{2}{5}$$

1個目が赤の後、残りは赤1個、青3個の計4個

$$P(2個目赤|1個目赤) = \frac{1}{4}$$

$$P(2個とも赤) = \frac{2}{5} \times \frac{1}{4} = \frac{2}{20} = \frac{1}{10}$$

**答え：1/10（10%）**

**(2) 2個とも同じ色**

2個とも青の確率：
$$P(2個とも青) = \frac{3}{5} \times \frac{2}{4} = \frac{6}{20} = \frac{3}{10}$$

$$P(同じ色) = P(2個とも赤) + P(2個とも青) = \frac{1}{10} + \frac{3}{10} = \frac{4}{10} = \frac{2}{5}$$

**答え：2/5（40%）**

**(3) 少なくとも1個は赤**

余事象「2個とも青」を使う：

$$P(少なくとも1個赤) = 1 - P(2個とも青) = 1 - \frac{3}{10} = \frac{7}{10}$$

**答え：7/10（70%）**

</details>

## 問題13：組合せと確率

10人から3人を選ぶとき：

(1) 選び方は何通りありますか？

(2) 10人中3人が女性の場合、選んだ3人のうち少なくとも1人が女性である確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 選び方**

$$\binom{10}{3} = \frac{10!}{3!7!} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = \frac{720}{6} = 120$$

**答え：120通り**

**(2) 少なくとも1人女性**

余事象「3人とも男性」を使う

男性は7人なので：
$$P(3人とも男性) = \frac{\binom{7}{3}}{\binom{10}{3}} = \frac{35}{120} = \frac{7}{24}$$

$$P(少なくとも1人女性) = 1 - \frac{7}{24} = \frac{17}{24} \approx 0.708$$

**答え：約70.8%**

</details>

## 問題14：誕生日のパラドックス

クラスに23人の生徒がいます。少なくとも2人が同じ誕生日である確率は約何%ですか？

ヒント：余事象「全員の誕生日が異なる」確率を計算

<details markdown="1">
<summary>解答を見る</summary>

### 解答

全員の誕生日が異なる確率：

1人目：365/365 = 1
2人目：364/365（1人目と違う日）
3人目：363/365
...
23人目：343/365

$$P(全員異なる) = \frac{365}{365} \times \frac{364}{365} \times \frac{363}{365} \times ... \times \frac{343}{365}$$

$$= \frac{365 \times 364 \times 363 \times ... \times 343}{365^{23}} \approx 0.493$$

$$P(同じ誕生日ペアあり) = 1 - 0.493 = 0.507$$

**答え：約50.7%**

### 解説

直感に反して、たった23人で同じ誕生日のペアがいる確率は50%を超えます。これは「誕生日のパラドックス」として知られています。

- 30人：約70%
- 50人：約97%
- 70人：約99.9%

</details>

## 問題15：モンティ・ホール問題

3つのドアがあり、1つだけに賞品があります。

1. あなたがドアAを選ぶ
2. 司会者がハズレのドアCを開けて見せる（司会者は正解を知っている）
3. 「ドアBに変更しますか？」と聞かれる

変更すべきですか？変更した場合と変更しない場合、それぞれ当たる確率を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**変更しない場合**

最初に選んだAに賞品がある確率 = $\frac{1}{3}$

**変更する場合**

賞品がBにある確率 = $\frac{2}{3}$

**答え：変更すべき。変更すると当たる確率は2/3（約67%）**

### 解説

なぜ変更が有利なのか：

1. 最初にAを選んだとき、Aに賞品がある確率は1/3
2. つまり、B or Cに賞品がある確率は2/3
3. 司会者がCを開けた後、「B or Cに賞品」はそのまま「Bに賞品」に集約される
4. したがって、Bに賞品がある確率は2/3

これは「モンティ・ホール問題」として有名で、多くの人が「1/2ずつ」と誤解します。

</details>
