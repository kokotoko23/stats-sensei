# 代表値の計算問題

平均、中央値、最頻値を計算する問題です。[理論編：平均・中央値・最頻値]({{ site.baseurl }}/theory/mean-median-mode/)を学んでから取り組みましょう。

---

## 問題1：平均の計算

あるクラスの生徒10人が数学のテストを受けました。点数は以下の通りです。

**データ：65, 72, 78, 80, 85, 88, 90, 92, 95, 100**

このクラスの平均点を求めてください。

<details>
<summary>解答を見る</summary>

### 解答

$$\bar{x} = \frac{65 + 72 + 78 + 80 + 85 + 88 + 90 + 92 + 95 + 100}{10}$$

$$= \frac{845}{10} = 84.5$$

**答え：84.5点**

### 解説

平均は「全てのデータの合計 / データ数」で求めます。
- データの合計：845点
- データの個数：10個
- 平均：845 / 10 = 84.5点

</details>

## 問題2：中央値の計算（奇数個）

以下のデータの中央値を求めてください。

**データ：23, 45, 12, 67, 34, 89, 56**

<details>
<summary>解答を見る</summary>

### 解答

まず、データを小さい順に並べます。

**12, 23, 34, 45, 56, 67, 89**

データは7個（奇数）なので、真ん中（4番目）の値が中央値です。

**答え：45**

### 解説

中央値を求める手順：
1. データを昇順に並べる：12, 23, 34, **45**, 56, 67, 89
2. データ数が7個（奇数）なので、(7+1)/2 = 4番目の値が中央値
3. 4番目の値は45

</details>

## 問題3：中央値の計算（偶数個）

以下のデータの中央値を求めてください。

**データ：18, 25, 32, 41, 55, 63**

<details>
<summary>解答を見る</summary>

### 解答

データは既に小さい順に並んでいます。

**18, 25, 32, 41, 55, 63**

データは6個（偶数）なので、真ん中の2つ（3番目と4番目）の平均が中央値です。

$$\text{中央値} = \frac{32 + 41}{2} = \frac{73}{2} = 36.5$$

**答え：36.5**

### 解説

データ数が偶数の場合：
1. 中央の2つの値を見つける（3番目：32、4番目：41）
2. その平均を計算する：(32 + 41) / 2 = 36.5

</details>

## 問題4：最頻値の計算

以下のデータの最頻値を求めてください。

**データ：3, 5, 7, 5, 8, 5, 9, 7, 5, 3, 7, 5**

<details>
<summary>解答を見る</summary>

### 解答

各値の出現回数を数えます。

| 値 | 出現回数 |
|----|----------|
| 3 | 2回 |
| 5 | 5回 |
| 7 | 3回 |
| 8 | 1回 |
| 9 | 1回 |

最も出現回数が多いのは5（5回）です。

**答え：5**

### 解説

最頻値は最も頻繁に出現する値です。表にして数えると確実に求められます。

</details>

## 問題5：総合問題

ある店舗の1週間の来客数は以下の通りでした。

| 曜日 | 来客数 |
|------|--------|
| 月 | 45 |
| 火 | 52 |
| 水 | 48 |
| 木 | 52 |
| 金 | 65 |
| 土 | 120 |
| 日 | 98 |

以下の問いに答えてください。

(1) 1日あたりの平均来客数を求めてください。

(2) 来客数の中央値を求めてください。

(3) このデータの場合、平均と中央値のどちらがより「典型的な」来客数を表していると考えられますか？

<details>
<summary>解答を見る</summary>

### 解答

**(1) 平均**

$$\bar{x} = \frac{45 + 52 + 48 + 52 + 65 + 120 + 98}{7} = \frac{480}{7} \approx 68.6$$

**答え：約68.6人**

**(2) 中央値**

データを昇順に並べます：45, 48, 52, 52, 65, 98, 120

7個のデータの中央値は4番目の値です。

**答え：52人**

**(3) 考察**

**中央値（52人）の方がより典型的な来客数を表している**と考えられます。

理由：
- 土曜日（120人）と日曜日（98人）が外れ値として大きい
- 平日の来客数は45〜65人の範囲にある
- 平均（68.6人）は週末の大きな値に引っ張られて高くなっている
- 中央値（52人）は平日の典型的な来客数をよく表している

このように、分布が偏っている場合は中央値の方が代表値として適切なことがあります。

</details>
