## 問題1：重回帰の基本

以下の重回帰式を解釈してください。

売上 = 100 + 5×広告費 + 2×店舗数

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**切片（100）：**
広告費0、店舗数0のときの売上ベースライン

**広告費の係数（5）：**
店舗数を一定に保ったとき、広告費1単位増で売上5単位増

**店舗数の係数（2）：**
広告費を一定に保ったとき、店舗1増で売上2単位増

**注意：**
- 「他の変数を一定に保ったとき」の効果（偏回帰係数）
- 係数の大きさは単位に依存

</details>

## 問題2：係数の比較

問題1で、広告費と店舗数のどちらが売上に大きく影響していますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**非標準化係数では比較できない**

理由：単位が異なる
- 広告費：万円？
- 店舗数：店

**比較には標準化係数が必要：**

$$\beta^* = b \times \frac{SD(x)}{SD(y)}$$

例えば：
- 広告費のSD=20、店舗数のSD=10、売上のSD=50なら
- 広告費の標準化係数：5×20/50 = 2.0
- 店舗数の標準化係数：2×10/50 = 0.4

この場合、広告費の方が影響大。

</details>

## 問題3：自由度調整済みR²

R² = 0.85、サンプルサイズ n = 50、変数の数 k = 5 のとき、自由度調整済みR²を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$R^2_{adj} = 1 - \frac{(1-R^2)(n-1)}{n-k-1}$$

$$= 1 - \frac{(1-0.85)(50-1)}{50-5-1}$$

$$= 1 - \frac{0.15 \times 49}{44}$$

$$= 1 - 0.167 = 0.833$$

**答え：調整済みR² = 0.833**

変数を増やすとR²は必ず上がるが、調整済みR²は下がることもある。

</details>

## 問題4：VIFの解釈

以下のVIF値から多重共線性を判断してください。

| 変数 | VIF |
|------|-----|
| X1 | 1.5 |
| X2 | 12.3 |
| X3 | 15.8 |
| X4 | 2.1 |

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**VIFの基準：**
- VIF < 5：問題なし
- 5 ≤ VIF < 10：注意
- VIF ≥ 10：多重共線性あり

**判断：**
- X1, X4：問題なし
- **X2, X3：多重共線性あり**

**対策：**
- X2とX3は互いに強く相関している可能性
- どちらかを除外
- 合成変数を作る
- リッジ回帰を使用

</details>

## 問題5：ダミー変数

「季節」を重回帰に含めたい場合、何個のダミー変数が必要ですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

季節は4カテゴリ（春夏秋冬）

**必要なダミー変数：3個**

1つを基準カテゴリとして省略（例：冬）

| 季節 | D_春 | D_夏 | D_秋 |
|------|------|------|------|
| 春 | 1 | 0 | 0 |
| 夏 | 0 | 1 | 0 |
| 秋 | 0 | 0 | 1 |
| 冬 | 0 | 0 | 0 |

4つ全部入れると多重共線性が発生（ダミー変数の罠）。

</details>

## 問題6：交互作用

以下のモデルの交互作用項を解釈してください。

y = 10 + 2x₁ + 3x₂ + 0.5x₁x₂

<details markdown="1">
<summary>解答を見る</summary>

### 解答

x₁の効果：$\frac{\partial y}{\partial x_1} = 2 + 0.5x_2$

**解釈：**
- x₂=0のとき、x₁の効果は2
- x₂=10のとき、x₁の効果は2 + 5 = 7

**交互作用（0.5）の意味：**
- x₂が大きいほど、x₁の効果も大きくなる
- x₁とx₂には相乗効果がある

例：広告(x₁)と店舗数(x₂)に交互作用があれば、店舗が多いほど広告効果が高い。

</details>

## 問題7：F検定

重回帰モデル全体の有意性を検定するF値の公式を説明してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$F = \frac{SS_{回帰}/k}{SS_{残差}/(n-k-1)} = \frac{MS_{回帰}}{MS_{残差}}$$

- k：説明変数の数
- n：サンプルサイズ
- 自由度：(k, n-k-1)

**帰無仮説：** 全ての係数が0
**対立仮説：** 少なくとも1つは0でない

F値が大きい → 帰無仮説を棄却 → モデルは有意

</details>

## 問題8：変数選択

ステップワイズ法の3つの種類を説明してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**1. 前進選択法（Forward Selection）**
- 変数0個から開始
- 最も有意な変数を1つずつ追加
- 有意な変数がなくなったら終了

**2. 後退消去法（Backward Elimination）**
- 全変数から開始
- 最も有意でない変数を1つずつ除去
- 全て有意になったら終了

**3. ステップワイズ法（Stepwise）**
- 前進選択と後退消去を組み合わせ
- 変数を追加・除去を繰り返す

**注意：** これらは探索的手法であり、過学習や偽陽性のリスクがある。

</details>

## 問題9：残差診断

残差プロットで以下のパターンが見られたとき、何を示唆していますか？

(1) 扇形（漏斗状）
(2) 曲線パターン
(3) 外れ値

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 扇形パターン → 分散不均一性**
- 予測値が大きいほど残差のばらつきも大きい
- 対策：対数変換、加重回帰

**(2) 曲線パターン → 非線形性**
- 線形モデルでは捉えきれない関係
- 対策：2次項追加、変数変換

**(3) 外れ値 → 異常データまたはモデル不適合**
- 1-2点が大きく外れている
- 対策：データ確認、頑健回帰、外れ値除外

</details>

## 問題10：予測区間と信頼区間

新しいデータ点に対する「信頼区間」と「予測区間」の違いは何ですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**信頼区間（平均の区間）：**
- その x における y の**平均値**の区間
- 回帰直線の不確実性を表す

**予測区間（個別値の区間）：**
- その x における**個々の y 値**が入る区間
- 回帰直線の不確実性 + 個体差を含む

**常に：予測区間 > 信頼区間**

例：身長170cmの人の体重
- 信頼区間：平均的に65-67kgくらい
- 予測区間：個人は55-77kgくらいの幅に入る

</details>

## 問題11：標準化係数

非標準化係数b=3、xのSD=10、yのSD=15のとき、標準化係数β*は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$\beta^* = b \times \frac{SD(x)}{SD(y)} = 3 \times \frac{10}{15} = 2.0$$

**答え：β* = 2.0**

xが1標準偏差増えると、yが2標準偏差増える。

</details>

## 問題12：総合問題

以下の回帰分析結果を解釈してください。

```
従属変数：年収（万円）
n = 100, R² = 0.65, F = 59.3 (p < 0.001)

          係数    標準誤差   t値    p値
切片       200      50      4.0    0.001
学歴(年)    30       8      3.75   0.001
経験(年)    15       5      3.0    0.003
性別(女=1) -50      20     -2.5    0.014
```

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**モデル全体：**
- R²=0.65：年収変動の65%を説明
- F検定有意：モデルは統計的に有意

**各変数の解釈：**

1. **学歴（30万円/年, p=0.001）**
   - 学歴1年増で年収30万円増
   - 統計的に有意

2. **経験（15万円/年, p=0.003）**
   - 経験1年増で年収15万円増
   - 統計的に有意

3. **性別（-50万円, p=0.014）**
   - 同じ学歴・経験でも女性は50万円低い
   - 賃金格差の存在を示唆

**注意点：**
- これは相関関係であり、因果関係とは限らない
- 交絡変数（職種など）が考慮されていない可能性

</details>
