# 正規分布の確率計算問題

正規分布を使った確率計算の問題です。[理論編：正規分布]({{ site.baseurl }}/theory/normal-distribution/)を学んでから取り組みましょう。

---

## 問題1：標準化（z値の計算）

ある試験の点数は平均60点、標準偏差10点の正規分布に従います。以下の点数のz値を求めてください。

(1) 70点

(2) 45点

(3) 60点

<details markdown="1">
<summary>解答を見る</summary>

### 解答

標準化の公式：$z = \frac{x - \mu}{\sigma}$

**(1) 70点**

$$z = \frac{70 - 60}{10} = 1.0$$

**答え：z = 1.0**

**(2) 45点**

$$z = \frac{45 - 60}{10} = -1.5$$

**答え：z = -1.5**

**(3) 60点**

$$z = \frac{60 - 60}{10} = 0$$

**答え：z = 0**（平均点なのでz値は0）

</details>

## 問題2：確率の計算（標準正規分布表を使用）

標準正規分布表を使って、以下の確率を求めてください。

（参考：$P(Z < 1) = 0.8413$、$P(Z < 1.5) = 0.9332$、$P(Z < 2) = 0.9772$）

(1) $P(Z < 1.5)$

(2) $P(Z > 1)$

(3) $P(-1 < Z < 1)$

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) P(Z < 1.5)**

標準正規分布表より：

**答え：0.9332**（約93.3%）

**(2) P(Z > 1)**

$$P(Z > 1) = 1 - P(Z < 1) = 1 - 0.8413 = 0.1587$$

**答え：0.1587**（約15.9%）

**(3) P(-1 < Z < 1)**

対称性を利用：

$$P(-1 < Z < 1) = P(Z < 1) - P(Z < -1)$$
$$= P(Z < 1) - (1 - P(Z < 1))$$
$$= 2 \times P(Z < 1) - 1$$
$$= 2 \times 0.8413 - 1 = 0.6826$$

**答え：0.6826**（約68.3%）

これが「68-95-99.7ルール」の68%に相当します。

</details>

## 問題3：正規分布の確率計算

ある工場で生産される製品の重量は、平均500g、標準偏差20gの正規分布に従います。

(1) 重量が520g以上になる確率

(2) 重量が480g以下になる確率

(3) 重量が470gから530gの間になる確率

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 520g以上**

$$z = \frac{520 - 500}{20} = 1.0$$

$$P(X > 520) = P(Z > 1) = 1 - 0.8413 = 0.1587$$

**答え：約15.9%**

**(2) 480g以下**

$$z = \frac{480 - 500}{20} = -1.0$$

$$P(X < 480) = P(Z < -1) = 1 - P(Z < 1) = 1 - 0.8413 = 0.1587$$

**答え：約15.9%**

**(3) 470gから530g**

$$z_1 = \frac{470 - 500}{20} = -1.5$$
$$z_2 = \frac{530 - 500}{20} = 1.5$$

$$P(470 < X < 530) = P(-1.5 < Z < 1.5)$$
$$= P(Z < 1.5) - P(Z < -1.5)$$
$$= 0.9332 - (1 - 0.9332) = 0.9332 - 0.0668 = 0.8664$$

**答え：約86.6%**

</details>

## 問題4：パーセンタイルの計算

ある大学の入試の点数は、平均500点、標準偏差100点の正規分布に従います。

(1) 上位10%に入るには何点以上必要ですか？（$z = 1.28$ で上位10%）

(2) 下位5%になるのは何点以下ですか？（$z = -1.645$ で下位5%）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

パーセンタイル計算：$x = \mu + z \cdot \sigma$

**(1) 上位10%**

上位10%ということは、$P(Z > z) = 0.10$、つまり $P(Z < z) = 0.90$

$z = 1.28$ のとき

$$x = 500 + 1.28 \times 100 = 500 + 128 = 628$$

**答え：628点以上**

**(2) 下位5%**

$z = -1.645$ のとき

$$x = 500 + (-1.645) \times 100 = 500 - 164.5 = 335.5$$

**答え：約336点以下**

</details>

## 問題5：正規分布の応用

ある会社の従業員の通勤時間は、平均40分、標準偏差15分の正規分布に従います。

(1) 通勤時間が1時間（60分）を超える従業員の割合

(2) 通勤時間が25分から55分の間の従業員の割合

(3) 通勤時間が短い方から20%に入る時間は何分以下？（$z = -0.84$ で下位20%）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 60分を超える割合**

$$z = \frac{60 - 40}{15} = 1.33$$

$P(Z < 1.33) \approx 0.908$ より

$$P(X > 60) = 1 - 0.908 = 0.092$$

**答え：約9.2%**

**(2) 25分から55分**

$$z_1 = \frac{25 - 40}{15} = -1.0$$
$$z_2 = \frac{55 - 40}{15} = 1.0$$

$$P(25 < X < 55) = P(-1 < Z < 1) \approx 0.6826$$

**答え：約68.3%**

**(3) 下位20%の時間**

$$x = 40 + (-0.84) \times 15 = 40 - 12.6 = 27.4$$

**答え：約27分以下**

</details>

## 問題6：68-95-99.7ルールの適用

IQスコアは平均100、標準偏差15の正規分布に従うとされています。

(1) IQが85から115の間の人の割合

(2) IQが130以上の人の割合

(3) IQが70以下または130以上の人の割合

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 85から115（平均±1標準偏差）**

$$85 = 100 - 15 = \mu - 1\sigma$$
$$115 = 100 + 15 = \mu + 1\sigma$$

68-95-99.7ルールより：

**答え：約68%**

**(2) 130以上**

$$130 = 100 + 30 = \mu + 2\sigma$$

95%が平均±2標準偏差に含まれるので、両側で5%が範囲外。

片側（130以上）は：

$$\frac{100\% - 95\%}{2} = 2.5\%$$

**答え：約2.5%**

**(3) 70以下または130以上（平均±2標準偏差の外）**

$$70 = 100 - 30 = \mu - 2\sigma$$
$$130 = 100 + 30 = \mu + 2\sigma$$

$$P(X < 70 \text{ または } X > 130) = 100\% - 95\% = 5\%$$

**答え：約5%**

</details>
