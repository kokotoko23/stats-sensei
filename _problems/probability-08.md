# 条件付き確率の演習

条件付き確率の理解を深める問題です。

## 問題1：基本的な条件付き確率

52枚のトランプから1枚引くとき、「ハートである」という条件のもとで「絵札（J,Q,K）である」確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**条件付き確率の公式：**
$$P(絵札|ハート) = \frac{P(絵札 \cap ハート)}{P(ハート)}$$

- P(ハート) = 13/52 = 1/4
- P(絵札 ∩ ハート) = 3/52（ハートのJ,Q,K）

$$P(絵札|ハート) = \frac{3/52}{13/52} = \frac{3}{13}$$

**答え：3/13（約23.1%）**

</details>

## 問題2：独立性の判定

サイコロを2回振るとき、「1回目が偶数」と「2回目が3以上」は独立ですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**独立の定義：** P(A∩B) = P(A)×P(B)

- P(1回目が偶数) = 3/6 = 1/2
- P(2回目が3以上) = 4/6 = 2/3
- P(両方) = (3/6) × (4/6) = 12/36 = 1/3

P(A)×P(B) = 1/2 × 2/3 = 1/3 = P(A∩B)

**答え：独立である**

別々の試行なので直感的にも独立。

</details>

## 問題3：ベイズの定理（基本）

ある病気の検査について：
- 病気の人が陽性になる確率：99%
- 健康な人が陽性になる確率：5%
- 人口の1%がこの病気

検査が陽性だった人が実際に病気である確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**ベイズの定理：**
$$P(病気|陽性) = \frac{P(陽性|病気) \times P(病気)}{P(陽性)}$$

**P(陽性)の計算（全確率の定理）：**
$$P(陽性) = P(陽性|病気)P(病気) + P(陽性|健康)P(健康)$$
$$= 0.99 \times 0.01 + 0.05 \times 0.99 = 0.0099 + 0.0495 = 0.0594$$

**ベイズの定理を適用：**
$$P(病気|陽性) = \frac{0.99 \times 0.01}{0.0594} = \frac{0.0099}{0.0594} = 0.167$$

**答え：約16.7%**

陽性でも病気である確率は意外と低い（偽陽性の影響）

</details>

## 問題4：全確率の定理

3つの工場A, B, Cがそれぞれ製品の30%, 50%, 20%を生産。不良率はA:2%, B:3%, C:1%。ランダムに選んだ製品が不良品である確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**全確率の定理：**
$$P(不良) = P(不良|A)P(A) + P(不良|B)P(B) + P(不良|C)P(C)$$

$$= 0.02 \times 0.30 + 0.03 \times 0.50 + 0.01 \times 0.20$$

$$= 0.006 + 0.015 + 0.002 = 0.023$$

**答え：2.3%**

</details>

## 問題5：ベイズの定理（続き）

前問で、不良品だったとき、それが工場Bで作られた確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$P(B|不良) = \frac{P(不良|B) \times P(B)}{P(不良)}$$

$$= \frac{0.03 \times 0.50}{0.023} = \frac{0.015}{0.023} = 0.652$$

**答え：約65.2%**

Bの生産量が多く不良率も高いので、不良品の多くがBから。

</details>

## 問題6：連続した条件付き確率

袋に赤玉3個、白玉2個が入っている。1個取り出して戻さずにもう1個取り出すとき、「2個とも赤」の確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**乗法定理：**
$$P(両方赤) = P(1個目赤) \times P(2個目赤|1個目赤)$$

- P(1個目赤) = 3/5
- P(2個目赤|1個目赤) = 2/4 = 1/2（残り4個中2個が赤）

$$P(両方赤) = \frac{3}{5} \times \frac{1}{2} = \frac{3}{10}$$

**答え：3/10（30%）**

</details>

## 問題7：条件の逆転

P(A|B) = 0.6, P(B) = 0.3, P(A) = 0.4 のとき、P(B|A)は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**ベイズの定理：**
$$P(B|A) = \frac{P(A|B) \times P(B)}{P(A)}$$

$$= \frac{0.6 \times 0.3}{0.4} = \frac{0.18}{0.4} = 0.45$$

**答え：P(B|A) = 0.45**

</details>

## 問題8：モンティ・ホール問題

3つのドアがあり、1つに賞品、2つにヤギがいます。あなたがドア1を選んだ後、司会者はヤギがいるドア3を開けました。ドアを変更すべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**答え：変更すべき**

**確率計算：**

選んだドア1に賞品がある確率 = 1/3（変わらない）

ドア2に賞品がある確率 = 2/3

司会者は必ずヤギのドアを開けるので、ドア3が開いてもドア1の確率は1/3のまま。残りの2/3がドア2に集中。

**結論：**
- 変えない：当たる確率 1/3
- 変える：当たる確率 2/3

</details>

## 問題9：多段階の確率

天気予報の的中率が80%。明日「晴れ」と予報が出ました。実際に晴れる確率は？（実際に晴れる日が全体の60%とする）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**設定：**
- P(予報晴れ|実際晴れ) = 0.8
- P(予報晴れ|実際雨) = 0.2（的中率80%の補数）
- P(実際晴れ) = 0.6

**P(予報晴れ)：**
$$P(予報晴れ) = 0.8 \times 0.6 + 0.2 \times 0.4 = 0.48 + 0.08 = 0.56$$

**ベイズの定理：**
$$P(実際晴れ|予報晴れ) = \frac{0.8 \times 0.6}{0.56} = \frac{0.48}{0.56} = 0.857$$

**答え：約85.7%**

</details>

## 問題10：感度と特異度

検査の感度（真陽性率）90%、特異度（真陰性率）95%。有病率5%の集団で、陰性だった人が実際に健康である確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**P(陰性)：**
$$P(陰性) = P(陰性|病気)P(病気) + P(陰性|健康)P(健康)$$
$$= 0.10 \times 0.05 + 0.95 \times 0.95 = 0.005 + 0.9025 = 0.9075$$

**P(健康|陰性)：**
$$P(健康|陰性) = \frac{P(陰性|健康) \times P(健康)}{P(陰性)}$$
$$= \frac{0.95 \times 0.95}{0.9075} = \frac{0.9025}{0.9075} = 0.994$$

**答え：約99.4%**

陰性なら99.4%の確率で本当に健康（陰性的中率）

</details>

## 問題11：樹形図による計算

2人の子供がいる家庭で、少なくとも1人が男の子であることがわかっているとき、2人とも男の子である確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**全ての可能性：**
- 男男
- 男女
- 女男
- 女女

**「少なくとも1人が男」の条件：**
女女を除く → 男男、男女、女男 の3通り

$$P(両方男|少なくとも1人男) = \frac{1}{3}$$

**答え：1/3**

「長男が男」なら1/2だが、「少なくとも1人」なら1/3

</details>

## 問題12：複合的な問題

2つの独立した試験A, Bがあります。Aに合格する確率0.7、Bに合格する確率0.6。少なくとも1つに合格する確率は？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**余事象を使う方法：**
$$P(少なくとも1つ合格) = 1 - P(両方不合格)$$

$$= 1 - P(A不合格) \times P(B不合格)$$

$$= 1 - 0.3 \times 0.4 = 1 - 0.12 = 0.88$$

**答え：88%**

**直接計算の確認：**
$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
$$= 0.7 + 0.6 - 0.42 = 0.88$$

</details>
