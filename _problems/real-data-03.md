## ケース1：ECサイトのコンバージョン改善

**背景：** あなたはECサイトのデータアナリストです。マーケティングチームから「購入完了率を上げたい」と相談されました。

**データ：**
- 月間訪問者：100,000人
- カート追加率：15%
- カートから購入率：20%
- 購入完了率：3%（=15%×20%）

(1) どの段階の改善が最も効果的か分析してください
(2) カート追加率を18%に上げた場合の購入完了率の変化

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) ボトルネック分析**

| ステージ | 率 | 離脱率 |
|----------|-----|--------|
| サイト訪問 → カート追加 | 15% | 85% |
| カート追加 → 購入完了 | 20% | 80% |

両方とも離脱率が高いが、**カート追加後の購入率（20%）** がより低い。

カートを追加した人は購入意欲があるはずなので、ここを改善する価値が高い。

**改善施策例：**
- チェックアウトプロセスの簡略化
- 送料無料の閾値設定
- カート放棄メールの送信
- 決済方法の多様化

**(2) カート追加率18%の場合**

$$購入完了率 = 18\% \times 20\% = 3.6\%$$

**増加率：** (3.6-3)/3 = 20%増

**売上影響：**（客単価5,000円の場合）
- 現状：100,000 × 3% × 5,000 = 1,500万円
- 改善後：100,000 × 3.6% × 5,000 = 1,800万円
- 差額：**+300万円/月**

</details>

## ケース2：製造ラインの品質管理

**背景：** 工場の品質管理担当です。製品の重量規格は 100g ± 5g です。

**データ：** 100個のサンプル測定結果
- 平均：101.2g
- 標準偏差：2.5g

(1) 工程能力指数（Cpk）を計算してください
(2) 規格外となる製品の割合を推定してください
(3) 改善提案をしてください

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 工程能力指数**

規格上限（USL）= 105g、規格下限（LSL）= 95g

$$Cp = \frac{USL - LSL}{6\sigma} = \frac{105 - 95}{6 \times 2.5} = \frac{10}{15} = 0.67$$

$$Cpk = \min\left(\frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma}\right)$$

$$= \min\left(\frac{105 - 101.2}{7.5}, \frac{101.2 - 95}{7.5}\right) = \min(0.51, 0.83) = 0.51$$

**答え：Cpk = 0.51**（目標は1.33以上）

**(2) 規格外の割合**

上限超え：$z = \frac{105 - 101.2}{2.5} = 1.52$ → P(Z > 1.52) ≈ 6.4%

下限未満：$z = \frac{95 - 101.2}{2.5} = -2.48$ → P(Z < -2.48) ≈ 0.7%

**答え：約7.1%が規格外**

**(3) 改善提案**

1. **平均値の調整**：目標100gに近づける設定変更
2. **ばらつきの低減**：標準偏差を小さくする
   - Cpk=1.33達成には σ < 1.25g が必要
3. **原因調査**：なぜ平均が1.2g高いか調査

</details>

## ケース3：顧客満足度調査の分析

**背景：** 顧客満足度調査（5段階評価）を実施しました。

**データ：**
| 評価 | 昨年 | 今年 |
|------|------|------|
| 5（非常に満足） | 120 | 150 |
| 4（満足） | 200 | 180 |
| 3（普通） | 150 | 120 |
| 2（不満） | 80 | 70 |
| 1（非常に不満） | 50 | 80 |
| 計 | 600 | 600 |

(1) 各年の平均満足度を計算してください
(2) 有意な変化があったか検定してください
(3) 結果を経営陣にどう報告しますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 平均満足度**

昨年：
$$\bar{x} = \frac{5(120) + 4(200) + 3(150) + 2(80) + 1(50)}{600} = \frac{1860}{600} = 3.10$$

今年：
$$\bar{x} = \frac{5(150) + 4(180) + 3(120) + 2(70) + 1(80)}{600} = \frac{1850}{600} = 3.08$$

**答え：昨年3.10、今年3.08（ほぼ同じ）**

**(2) 検定**

マン・ホイットニーのU検定または二標本t検定で平均の差を検定すると、差は有意ではない（p > 0.05）。

しかし、**分布の形状に変化がある**：
- 最高評価（5）が増加：120→150
- 最低評価（1）も増加：50→80
- 中間層が減少：350→300

**分散が増加している可能性**

**(3) 経営報告**

「平均満足度は昨年と同水準（3.1点）ですが、二極化が進んでいます。
- 非常に満足の顧客が25%増加（良い傾向）
- 非常に不満の顧客が60%増加（要対応）

対策として、不満顧客への個別フォローと原因分析を提案します。」

</details>

## ケース4：在庫最適化

**背景：** 倉庫の在庫管理を担当しています。

**データ：**
- 1日あたり平均需要：50個
- 需要の標準偏差：15個
- リードタイム：4日
- サービスレベル目標：95%

安全在庫量と発注点を計算してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**リードタイム中の需要分布：**

平均：$\mu_L = 50 \times 4 = 200$個

標準偏差：$\sigma_L = 15 \times \sqrt{4} = 30$個

**安全在庫（95%サービスレベル）：**

$z_{0.95} = 1.645$

$$安全在庫 = z \times \sigma_L = 1.645 \times 30 = 49.4 \approx 50個$$

**発注点：**

$$発注点 = \mu_L + 安全在庫 = 200 + 50 = 250個$$

**答え：**
- 安全在庫：50個
- 発注点：250個（在庫がこの水準に達したら発注）

**補足：** 99%サービスレベルなら安全在庫は約70個になる

</details>

## ケース5：従業員離職分析

**背景：** 人事部門で従業員の離職要因を分析します。

**データ：** ロジスティック回帰の結果

| 変数 | オッズ比 | 95%CI | p値 |
|------|---------|-------|------|
| 残業時間（10h増） | 1.35 | [1.15, 1.58] | 0.001 |
| 勤続年数（1年増） | 0.85 | [0.78, 0.93] | 0.003 |
| 給与水準（10万円増） | 0.92 | [0.82, 1.03] | 0.145 |
| 上司評価（1点増） | 0.70 | [0.55, 0.89] | 0.004 |

結果を解釈し、離職防止策を提案してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**オッズ比の解釈：**

1. **残業時間（OR=1.35, p<0.01）**
   - 残業10時間増で離職オッズが35%増加
   - **最も強い離職要因**

2. **勤続年数（OR=0.85, p<0.01）**
   - 勤続1年増で離職オッズが15%減少
   - 長く勤めるほど離職しにくい

3. **給与水準（OR=0.92, p=0.145）**
   - 統計的に有意でない
   - 給与だけでは離職を防げない可能性

4. **上司評価（OR=0.70, p<0.01）**
   - 評価1点上昇で離職オッズが30%減少
   - 良好な上司関係は重要

**離職防止策：**

1. **残業削減**（優先度：高）
   - 業務効率化、人員配置見直し
   - 残業上限の設定

2. **マネジメント研修**（優先度：高）
   - 上司のコミュニケーション力向上
   - 定期的な1on1の実施

3. **入社3年以内のフォロー**（優先度：中）
   - メンター制度
   - キャリア面談

</details>

## ケース6：価格弾力性分析

**背景：** 商品の価格設定を検討しています。

**データ：** 過去の価格変更と販売数量

| 価格 | 販売数量 |
|------|----------|
| 800円 | 1200個 |
| 900円 | 1000個 |
| 1000円 | 850個 |
| 1100円 | 720個 |
| 1200円 | 600個 |

(1) 価格弾力性を推定してください
(2) 売上を最大化する価格を求めてください

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 価格弾力性の推定**

対数線形モデル：$\log(Q) = a + b \times \log(P)$

| log(P) | log(Q) |
|--------|--------|
| 6.685 | 7.090 |
| 6.802 | 6.908 |
| 6.908 | 6.745 |
| 7.003 | 6.579 |
| 7.090 | 6.397 |

回帰分析により：$b \approx -1.7$

**答え：価格弾力性 ≈ -1.7**

（価格1%上昇で需要が1.7%減少）

**(2) 売上最大化価格**

売上 = P × Q(P)

弾力性が-1.7なので、|弾力性| > 1（弾力的）

売上 = P × Q の微分を0とおくと：

最適価格は弾力性の絶対値が1になる点だが、この関係では：

売上を計算：
| 価格 | 売上 |
|------|------|
| 800円 | 960,000円 |
| 900円 | 900,000円 |
| 1000円 | 850,000円 |
| 1100円 | 792,000円 |
| 1200円 | 720,000円 |

**答え：800円で売上最大**

ただし利益最大化は別に分析が必要（限界費用を考慮）

</details>

## ケース7：マーケティングミックスモデル

**背景：** 広告予算の配分を最適化したい。

**データ：** 重回帰分析結果

売上 = 1000 + 0.5×TV + 0.8×デジタル + 0.3×印刷

- TV広告：100万円で50万円の売上増
- デジタル広告：100万円で80万円の売上増
- 印刷広告：100万円で30万円の売上増

総予算300万円をどう配分すべきですか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**ROI分析：**

| メディア | 係数 | ROI |
|----------|------|-----|
| TV | 0.5 | 50% |
| デジタル | 0.8 | 80% |
| 印刷 | 0.3 | 30% |

**単純な最適化：** 全額をデジタルに投資

$$売上増加 = 0.8 \times 300 = 240万円$$

**ただし実務的な考慮：**

1. **逓減効果**：同じメディアに集中すると効果が減少
2. **到達率**：異なるメディアで異なる顧客層にリーチ
3. **シナジー効果**：複数メディアの組み合わせ効果

**提案配分：**
- デジタル：180万円（60%）
- TV：90万円（30%）
- 印刷：30万円（10%）

予想売上増加：$0.8 \times 180 + 0.5 \times 90 + 0.3 \times 30 = 144 + 45 + 9 = 198$万円

</details>

## ケース8：不正検知

**背景：** クレジットカードの不正利用を検知するモデルを評価します。

**データ：** 混同行列

|  | 予測：正常 | 予測：不正 |
|--|----------|----------|
| 実際：正常 | 9850 | 50 |
| 実際：不正 | 30 | 70 |

(1) 精度、再現率、F1スコアを計算してください
(2) このモデルの問題点を指摘してください
(3) 改善策を提案してください

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 評価指標**

**精度（Precision）：** 不正と予測した中で実際に不正
$$Precision = \frac{70}{70+50} = 0.583 (58.3\%)$$

**再現率（Recall）：** 実際の不正の中で検知できた割合
$$Recall = \frac{70}{70+30} = 0.70 (70\%)$$

**F1スコア：**
$$F1 = 2 \times \frac{0.583 \times 0.70}{0.583 + 0.70} = 0.636$$

**正解率（Accuracy）：**
$$Accuracy = \frac{9850+70}{10000} = 0.992 (99.2\%)$$

**(2) 問題点**

- 正解率99.2%は一見高いが、不正を「全て正常」と予測しても99%の正解率
- **再現率70%**：不正の30%（30件）を見逃している
- 偽陽性（正常を不正と判定）も50件ある → 顧客への影響

**(3) 改善策**

1. **閾値の調整**：再現率を上げる方向に調整
2. **コスト考慮学習**：不正見逃しのコストを高く設定
3. **アンサンブル**：複数モデルの組み合わせ
4. **特徴量エンジニアリング**：取引パターンの追加

**ビジネス判断：** 不正1件見逃しのコスト vs 誤検知1件のコスト を比較して最適化

</details>

## ケース9：コホート分析

**背景：** サブスクリプションサービスの継続率を分析します。

**データ：** 月次継続率

| 登録月 | 1ヶ月後 | 2ヶ月後 | 3ヶ月後 | 4ヶ月後 |
|--------|---------|---------|---------|---------|
| 1月 | 80% | 65% | 55% | 50% |
| 2月 | 85% | 70% | 60% | - |
| 3月 | 82% | 68% | - | - |
| 4月 | 78% | - | - | - |

結果を分析し、施策を提案してください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**分析結果：**

1. **最初の1ヶ月が最大の山場**
   - 全コホートで15-22%が初月で離脱
   - オンボーディングの改善が最重要

2. **2月登録コホートが最も良い**
   - 何か施策があったか確認
   - 成功要因を他に展開

3. **4月コホートの懸念**
   - 初月継続率78%は低め
   - 原因調査が必要

**LTV（顧客生涯価値）の推定：**

1月コホート：継続率が50%で安定と仮定
月額1,000円の場合：
$$LTV = 1000 \times \frac{1}{1-0.5} = 2,000円$$

**改善施策：**

1. **初月のエンゲージメント強化**
   - ウェルカムメール
   - 使い方ガイド
   - 早期の成功体験

2. **2ヶ月目の離脱防止**
   - 使用状況のモニタリング
   - 休眠ユーザーへのリマインド

3. **長期継続のインセンティブ**
   - 長期契約割引
   - ロイヤルティプログラム

</details>

## ケース10：実験計画法

(1) 完全実施計画だと何パターン必要ですか？
(2) より効率的な実験方法を提案してください

### 解答

**(1) 完全実施計画**

**(2) 効率的な方法**
