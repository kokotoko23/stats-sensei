# 仮説検定の問題

仮説検定の問題です。[理論編：仮説検定の基礎]({{ site.baseurl }}/theory/hypothesis-testing/)を学んでから取り組みましょう。

## 問題1：仮説の設定

以下の研究目的に対して、帰無仮説 $H_0$ と対立仮説 $H_1$ を設定してください。

(1) 新しい学習法が従来の方法より効果があるか調べたい

(2) ある製品の重量が規格値 100g と異なるか調べたい

(3) ダイエット後の体重が減少したか調べたい

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 新しい学習法の効果**

- $H_0$：新しい学習法と従来の方法に差がない（$\mu_{\text{新}} = \mu_{\text{従来}}$）
- $H_1$：新しい学習法の方が効果がある（$\mu_{\text{新}} > \mu_{\text{従来}}$）

→ **片側検定（右側）**

**(2) 製品の重量**

- $H_0$：製品の平均重量は 100g である（$\mu = 100$）
- $H_1$：製品の平均重量は 100g と異なる（$\mu \neq 100$）

→ **両側検定**

**(3) ダイエット効果**

- $H_0$：ダイエット前後で体重に変化がない（$\mu_{\text{後}} = \mu_{\text{前}}$）
- $H_1$：ダイエット後の体重が減少した（$\mu_{\text{後}} < \mu_{\text{前}}$）

→ **片側検定（左側）**

</details>

## 問題2：検定統計量の計算

母集団の標準偏差が $\sigma = 15$ であることが分かっています。25人のサンプルを調べたところ、平均 $\bar{x} = 108$ でした。

母平均が 100 かどうかを検定するとき、z値を求めてください。

<details markdown="1">
<summary>解答を見る</summary>

### 解答

$$z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}} = \frac{108 - 100}{15 / \sqrt{25}} = \frac{8}{15/5} = \frac{8}{3} \approx 2.67$$

**答え：z = 2.67**

</details>

## 問題3：仮説検定の実行（両側検定）

問題2の状況で、有意水準 5% で両側検定を行ってください。

（臨界値：$z = \pm 1.96$）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**仮説**
- $H_0$：$\mu = 100$
- $H_1$：$\mu \neq 100$

**検定統計量**

$z = 2.67$（問題2より）

**判定**

臨界値 $\pm 1.96$ に対して、$|2.67| > 1.96$ なので棄却域に入る。

**結論**

**帰無仮説を棄却する。** 母平均は 100 と異なると言える（$p < 0.05$）。

</details>

## 問題4：t検定

ある学校のクラス（12人）の数学テストの平均点は 72 点、標準偏差は 9 点でした。

全国平均が 68 点であるとき、このクラスの平均点は全国平均より高いと言えますか？有意水準 5% で片側検定を行ってください。

（$t_{0.05}(11) = 1.796$）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**仮説**
- $H_0$：$\mu = 68$（全国平均と同じ）
- $H_1$：$\mu > 68$（全国平均より高い）

**検定統計量**

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{72 - 68}{9 / \sqrt{12}} = \frac{4}{9/3.46} = \frac{4}{2.60} \approx 1.54$$

**判定**

片側検定（右側）の臨界値は $t_{0.05}(11) = 1.796$

$1.54 < 1.796$ なので棄却域に入らない。

**結論**

**帰無仮説を棄却しない。** このクラスの平均点が全国平均より高いとは言えない。

</details>

## 問題5：p値の解釈

以下のp値について、有意水準 $\alpha = 0.05$ での判定と解釈を答えてください。

(1) $p = 0.032$

(2) $p = 0.08$

(3) $p = 0.003$

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) p = 0.032**

$0.032 < 0.05$ なので **帰無仮説を棄却**

解釈：統計的に有意な差がある

**(2) p = 0.08**

$0.08 > 0.05$ なので **帰無仮説を棄却しない**

解釈：統計的に有意な差があるとは言えない

**(3) p = 0.003**

$0.003 < 0.05$（さらに $< 0.01$）なので **帰無仮説を棄却**

解釈：非常に強い証拠がある。高度に有意。

</details>

## 問題6：2種類の誤り

以下の状況は第1種の誤りと第2種の誤りのどちらですか？

(1) 実際には効果がない薬を「効果がある」と結論づけた

(2) 実際には効果がある薬を「効果があるとは言えない」と結論づけた

(3) 有意水準を 1% から 5% に変更すると、第1種の誤りの確率はどうなりますか？

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 効果がない薬を「効果がある」と判断**

**第1種の誤り（$\alpha$ エラー）**

帰無仮説（効果がない）が正しいのに、誤って棄却してしまった。

**(2) 効果がある薬を「効果があるとは言えない」と判断**

**第2種の誤り（$\beta$ エラー）**

帰無仮説が間違っているのに、棄却できなかった。

**(3) 有意水準の変更**

有意水準を 1% から 5% に**緩める**と：

- 第1種の誤りの確率は**増加**する（1% → 5%）
- 第2種の誤りの確率は**減少**する（検出力が上がる）

</details>

## 問題7：総合問題

ある菓子メーカーは、1袋あたり平均 200g のお菓子を製造しているとしています。消費者団体が 36 袋を無作為に購入して調べたところ、平均 197g、標準偏差 12g でした。

(1) 「実際の平均重量は 200g より少ない」かどうかを検定するための仮説を設定してください

(2) 検定統計量を計算してください

(3) 有意水準 5% で検定を行い、結論を述べてください（$z_{0.05} = 1.645$）

<details markdown="1">
<summary>解答を見る</summary>

### 解答

**(1) 仮説設定**

- $H_0$：$\mu = 200$（表示通り）
- $H_1$：$\mu < 200$（表示より少ない）

→ 片側検定（左側）

**(2) 検定統計量**

サンプルサイズが大きいので z 検定を使用：

$$z = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{197 - 200}{12 / \sqrt{36}} = \frac{-3}{12/6} = \frac{-3}{2} = -1.5$$

**答え：z = -1.5**

**(3) 判定と結論**

片側検定（左側）の臨界値：$-z_{0.05} = -1.645$

棄却域：$z < -1.645$

$-1.5 > -1.645$ なので棄却域に入らない。

**結論：帰無仮説を棄却しない。**

「実際の平均重量が 200g より少ない」とは統計的に言えない。

ただし、差（3g）は実用上意味がある可能性もあるため、サンプルサイズを増やした追加調査を検討する価値はある。

</details>
